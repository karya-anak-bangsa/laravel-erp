Sejauh ini, buku hanya bisa ditambahkan lewat Tinker. Materi ini membuat formulir tambah buku di peramban, memvalidasi isiannya dengan Form Request, lalu menyimpannya ke basis data.

Rute Formulir dan Penyimpanan

Menambah data membutuhkan dua rute: satu untuk menampilkan formulir dan satu untuk menerima kirimannya. Tambahkan keduanya di routes/web.php:

Route::get('/buku', [BukuController::class, 'index'])->name('buku.index');
Route::get('/buku/tambah', [BukuController::class, 'create'])->name('buku.create');
Route::post('/buku', [BukuController::class, 'store'])->name('buku.store');
Route::get('/buku/{buku}', [BukuController::class, 'show'])->name('buku.show');

Urutannya penting. Rute /buku/tambah harus ditulis sebelum /buku/{buku}. Bila tertukar, Laravel menganggap kata tambah sebagai id buku, lalu menampilkan halaman 404 karena buku itu tidak ada.

Membuat Formulir

Tambahkan method create() di BukuController:

public function create()
{
    return view('buku.create');
}

Buat tampilannya di resources/views/buku/create.blade.php:

@extends('layouts.app')

@section('judul', 'Tambah Buku')

@section('konten')
    <h1>Tambah Buku</h1>

    <form method="POST" action="{{ route('buku.store') }}">
        @csrf

        <p>
            <label for="judul">Judul</label>
            <input type="text" id="judul" name="judul" value="{{ old('judul') }}">
            @error('judul') <small>{{ $message }}</small> @enderror
        </p>
        <p>
            <label for="penulis">Penulis</label>
            <input type="text" id="penulis" name="penulis" value="{{ old('penulis') }}">
            @error('penulis') <small>{{ $message }}</small> @enderror
        </p>
        <p>
            <label for="tahun_terbit">Tahun Terbit</label>
            <input type="number" id="tahun_terbit" name="tahun_terbit" value="{{ old('tahun_terbit') }}">
            @error('tahun_terbit') <small>{{ $message }}</small> @enderror
        </p>

        <button type="submit">Simpan</button>
    </form>
@endsection

Tiga hal perlu diperhatikan pada formulir ini:

  • @csrf menyisipkan token tersembunyi. Laravel menolak kiriman POST tanpa token yang sah dengan galat 419 sehingga situs lain tidak bisa mengirim formulir atas nama pengunjung Anda.

  • old('judul') mengembalikan isian sebelumnya ketika validasi gagal. Pengunjung tidak perlu mengetik ulang semua isian.

  • @error menampilkan pesan galat untuk satu isian lewat variabel $message.

Tambahkan juga tautan <a href="{{ route('buku.create') }}">Tambah buku</a> di halaman daftar buku agar formulir ini mudah ditemukan.

Validasi dengan Form Request

Data dari formulir tidak boleh langsung dipercaya. Pengunjung bisa mengosongkan judul atau mengirim tahun berupa huruf. Laravel menyediakan Form Request, kelas khusus yang memvalidasi permintaan sebelum controller berjalan. Buat kelasnya:

php artisan make:request BukuRequest

Buka app/Http/Requests/BukuRequest.php dan isi method-nya seperti berikut:

public function authorize(): bool
{
    return true;
}

public function rules(): array
{
    return [
        'judul' => ['required', 'string', 'max:200'],
        'penulis' => ['required', 'string', 'max:100'],
        'tahun_terbit' => ['required', 'integer', 'min:1900', 'max:'.now()->year],
    ];
}

public function attributes(): array
{
    return [
        'judul' => 'judul',
        'penulis' => 'penulis',
        'tahun_terbit' => 'tahun terbit',
    ];
}

public function messages(): array
{
    return [
        'required' => 'Kolom :attribute wajib diisi.',
        'max' => 'Kolom :attribute paling banyak :max karakter.',
        'tahun_terbit.integer' => 'Tahun terbit harus berupa angka.',
        'tahun_terbit.min' => 'Tahun terbit paling awal :min.',
        'tahun_terbit.max' => 'Tahun terbit tidak boleh melewati :max.',
    ];
}

Method authorize() buatan Artisan mengembalikan false sehingga semua kiriman ditolak dengan galat 403. Ubah menjadi true karena aplikasi ini belum memiliki fitur login. Kelak, method ini menjadi tempat memeriksa hak akses pengguna.

Pesan galat bawaan Laravel berbahasa Inggris. Method messages() menggantinya dengan kalimat bahasa Indonesia, sedangkan attributes() menentukan nama isian yang muncul di tempat :attribute. Pesan khusus seperti tahun_terbit.max didahulukan daripada pesan umum max.

Menyimpan Data

Tambahkan use App\Http\Requests\BukuRequest; di bagian atas BukuController, lalu tambahkan method store():

public function store(BukuRequest $request)
{
    Buku::create($request->validated());

    return redirect()->route('buku.index')->with('status', 'Buku berhasil ditambahkan.');
}

Laravel menjalankan validasi begitu melihat BukuRequest di parameter method. Bila ada isian yang salah, pengunjung dikembalikan ke formulir beserta pesan galat dan isian lamanya. Isi store() sama sekali tidak dijalankan. Bila semuanya benar, validated() hanya berisi data yang lolos validasi, lalu Buku::create() menyimpannya.

Setelah menyimpan, aplikasi mengalihkan pengunjung ke daftar buku. Pola ini disebut Post/Redirect/Get. Bila pengunjung memuat ulang halaman, peramban hanya membuka ulang daftar buku dan tidak mengirim formulir dua kali.

Menampilkan Pesan Berhasil

with('status', ...) menyimpan pesan di sesi hanya untuk permintaan berikutnya. Tampilkan pesan itu di tata letak layouts/app.blade.php, tepat di dalam <main>, agar berlaku untuk semua halaman:

@if (session('status'))
    <p role="status">{{ session('status') }}</p>
@endif

Coba tambahkan buku baru, misalnya Cantik Itu Luka karya Eka Kurniawan yang terbit pada 2002. Kirim juga formulir kosong untuk melihat pesan validasinya. Pembahasan Form Request yang lebih mendalam ada di artikel Validasi Form dengan Form Request agar Controller Laravel Tetap Ramping.

Pada materi berikutnya, kita akan memakai ulang formulir dan Form Request yang sama untuk mengubah data buku.
