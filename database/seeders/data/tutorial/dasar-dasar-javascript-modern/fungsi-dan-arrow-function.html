Perhitungan subtotal dan diskon pada materi sebelumnya ditulis langsung di kode. Bila perhitungan yang sama dibutuhkan di banyak tempat, kita terpaksa menyalinnya berulang kali. Fungsi mengatasi masalah ini dengan membungkus sekumpulan perintah dalam satu nama yang bisa dipanggil kapan saja.

Membuat dan Memanggil Fungsi

Fungsi dibuat dengan kata kunci function, diikuti nama fungsi dan daftar parameternya:

function hitungSubtotal(harga, jumlah) {
  return harga * jumlah;
}

console.log(hitungSubtotal(85000, 3)); // 255000
console.log(hitungSubtotal(60000, 2)); // 120000

harga dan jumlah adalah parameter, yaitu nama sementara untuk nilai yang diterima fungsi. Nilai yang dikirim saat pemanggilan, seperti 85000 dan 3, disebut argumen. Kata kunci return mengembalikan hasil sekaligus menghentikan fungsi. Fungsi tanpa return tetap berjalan, tetapi hasilnya selalu undefined.

Nilai Bawaan Parameter

Parameter bisa diberi nilai bawaan yang dipakai saat argumennya tidak dikirim:

function hitungDiskon(total, persen = 5) {
  return total * persen / 100;
}

console.log(hitungDiskon(200000));     // 10000
console.log(hitungDiskon(200000, 10)); // 20000

Perlu diingat, JavaScript tidak memeriksa tipe argumen. Pemanggilan hitungSubtotal('85000', 3) tetap menghasilkan 255000 karena operator * mengubah string menjadi angka. Namun, operator + menyambung teks sehingga '85000' + 15000 menghasilkan '8500015000' tanpa pesan galat sedikit pun. Kelemahan ini menjadi salah satu alasan banyak proyek beralih ke TypeScript, seperti dibahas di artikel Mengenal TypeScript: Kapan Proyek JavaScript Perlu Beralih?

Ekspresi Fungsi dan Arrow Function

Fungsi juga bisa disimpan di variabel sebagai ekspresi fungsi, seperti hitungOngkir di bawah ini. Bentuk yang lebih ringkas adalah arrow function yang ditulis dengan tanda =>:

const hitungOngkir = function (berat) {
  return berat * 10000;
};

const formatRupiah = (angka) => `Rp${angka.toLocaleString('id-ID')}`;

console.log(hitungOngkir(2));      // 20000
console.log(formatRupiah(255000)); // Rp255.000

Bila isi arrow function hanya satu ekspresi, kurung kurawal dan return boleh dihilangkan karena hasil ekspresinya otomatis dikembalikan. Tanda kurung di sekitar parameter tunggal juga boleh dihilangkan, misalnya angka => angka * 2. Adapun toLocaleString('id-ID') menulis angka dengan pemisah ribuan sesuai format Indonesia.

Bila isinya lebih dari satu perintah, kurung kurawal dan return tetap diperlukan:

const hitungTotal = (harga, jumlah, persenDiskon = 0) => {
  const subtotal = hitungSubtotal(harga, jumlah);
  const potongan = hitungDiskon(subtotal, persenDiskon);
  return subtotal - potongan;
};

console.log(formatRupiah(hitungTotal(85000, 3, 10))); // Rp229.500

Arrow function tidak memiliki this sendiri. Perbedaan ini baru terasa saat fungsi dipakai sebagai method objek, jadi untuk sekarang keduanya bisa dianggap setara.

Fungsi sebagai Argumen

Di JavaScript, fungsi adalah nilai biasa sehingga bisa dikirim ke fungsi lain. Fungsi yang dikirim seperti ini disebut callback:

function prosesPesanan(total, setelahSelesai) {
  console.log(`Memproses pesanan ${formatRupiah(total)}`);
  setelahSelesai();
}

prosesPesanan(229500, () => console.log('Pesanan siap dikirim.'));

setTimeout(() => console.log('Jangan lupa cek status pengiriman.'), 2000);

prosesPesanan() memanggil callback setelah tugas utamanya selesai. Fungsi bawaan setTimeout() bekerja dengan cara serupa: callback di atas dijalankan setelah 2000 milidetik atau dua detik. Pola callback akan sering muncul saat Anda menangani klik tombol di halaman web.

Cakupan Variabel

Variabel yang dibuat dengan let atau const di dalam fungsi hanya berlaku di dalam fungsi itu:

function hitungPoin(total) {
  const poin = Math.floor(total / 10000);
  return poin;
}

console.log(hitungPoin(229500)); // 22
console.log(poin); // ReferenceError: poin is not defined

Batasan ini disebut cakupan (scope). Berkat cakupan, variabel di dalam fungsi tidak bertabrakan dengan variabel bernama sama di bagian kode lain.

Pada materi berikutnya, kita akan menyimpan banyak buku sekaligus di dalam array dan objek, lalu mengolahnya dengan fungsi seperti formatRupiah().
