Program jarang berjalan lurus dari atas ke bawah. Toko buku perlu memberi diskon hanya untuk belanja dengan nilai tertentu dan menghitung total dari banyak buku sekaligus. Materi ini membahas percabangan untuk membuat keputusan dan perulangan untuk mengulang perintah.

Percabangan dengan if dan else

Pernyataan if menjalankan blok kode hanya bila kondisinya bernilai true. Tambahkan else if dan else untuk menangani kemungkinan lain:

const totalBelanja = 255000;
let persenDiskon;

if (totalBelanja >= 200000) {
  persenDiskon = 10;
} else if (totalBelanja >= 100000) {
  persenDiskon = 5;
} else {
  persenDiskon = 0;
}

console.log(`Diskon ${persenDiskon}%`); // Diskon 10%

JavaScript memeriksa kondisi dari atas. Begitu satu kondisi terpenuhi, blok lainnya dilewati. Oleh karena itu, kondisi yang paling ketat ditulis lebih dulu. Bila urutannya dibalik, belanja Rp255.000 hanya mendapat diskon 5% karena kondisi totalBelanja >= 100000 sudah terpenuhi lebih dulu.

Operator Kondisional dan switch

Keputusan dengan dua kemungkinan bisa ditulis dalam satu baris memakai operator kondisional ? : yang sering disebut operator ternary:

const ongkosKirim = totalBelanja >= 150000 ? 0 : 15000;
console.log(ongkosKirim); // 0

Bagian sebelum ? adalah kondisi. Nilai setelah ? dipakai bila kondisinya benar, sedangkan nilai setelah : dipakai bila kondisinya salah. Saat satu nilai dibandingkan dengan banyak pilihan tetap, switch lebih mudah dibaca:

const metodeBayar = 'transfer';

switch (metodeBayar) {
  case 'transfer':
    console.log('Kirim pembayaran ke rekening toko.');
    break;
  case 'tunai':
    console.log('Bayar saat buku diterima.');
    break;
  default:
    console.log('Metode bayar tidak dikenal.');
}

Jangan lupa menulis break di akhir setiap case. Tanpa break, JavaScript ikut menjalankan case di bawahnya. Blok default dijalankan bila tidak ada case yang cocok.

Nilai Truthy dan Falsy

Kondisi if tidak harus berupa boolean. Nilai yang dianggap salah (falsy) antara lain false, 0, '', null, undefined, dan NaN. Nilai lain, termasuk string '0' dan array kosong, dianggap benar (truthy).

const catatanPembeli = '';

if (catatanPembeli) {
  console.log(`Catatan: ${catatanPembeli}`);
} else {
  console.log('Tidak ada catatan.');
}

String kosong termasuk falsy sehingga kode di atas menampilkan Tidak ada catatan. Pola ini sering dipakai untuk memeriksa apakah sebuah isian sudah diisi.

Perulangan dengan for

Perulangan for cocok bila jumlah putarannya sudah diketahui:

for (let i = 1; i <= 3; i++) {
  console.log(`Buku ke-${i} dibungkus`);
}

Bagian di dalam tanda kurung terdiri atas tiga hal: nilai awal let i = 1, kondisi i <= 3 yang diperiksa sebelum setiap putaran, dan i++ yang menambah i sebesar satu setelah setiap putaran. Hasilnya tiga baris, dari Buku ke-1 dibungkus sampai Buku ke-3 dibungkus.

Saat menelusuri setiap isi sebuah daftar, for...of lebih ringkas karena tidak memerlukan penghitung:

const daftarHarga = [85000, 60000, 30000];
let total = 0;

for (const harga of daftarHarga) {
  total += harga;
}

console.log(total); // 175000

total += harga adalah cara singkat menulis total = total + harga. Daftar dalam tanda kurung siku ini disebut array dan akan dibahas lengkap di materi keempat.

Perulangan dengan while

Perulangan while terus berjalan selama kondisinya benar. Bentuk ini cocok bila jumlah putarannya belum pasti:

let stok = 3;

while (stok > 0) {
  console.log(`Sisa stok: ${stok}`);
  stok--;
}

console.log('Stok habis.');

Pastikan kondisinya suatu saat bernilai false. Tanpa stok--, perulangan tidak pernah berhenti dan tab peramban akan macet. Di dalam semua jenis perulangan, perintah break menghentikan perulangan lebih awal, sedangkan continue melompati sisa putaran saat itu.

Pada materi berikutnya, kita akan membungkus perhitungan seperti subtotal dan diskon ke dalam fungsi agar bisa dipakai berulang kali.
