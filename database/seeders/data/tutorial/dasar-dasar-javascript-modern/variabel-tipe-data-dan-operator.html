JavaScript adalah bahasa pemrograman yang menghidupkan halaman web, mulai dari tombol yang menanggapi klik hingga formulir yang memeriksa isiannya sendiri. Bahasa ini juga bisa berjalan di luar peramban lewat Node.js, misalnya untuk membuat server atau alat bantu pengembang.

Materi pertama ini membahas cara menjalankan kode JavaScript, menyimpan nilai di variabel, mengenal tipe data dasar, dan mengolah nilai dengan operator. Contoh sepanjang seri ini memakai data toko buku sederhana.

Menjalankan Kode JavaScript

Cara tercepat mencoba JavaScript adalah lewat konsol peramban. Buka Chrome, Edge, atau Firefox, tekan F12 (di macOS, Cmd+Option+I) untuk membuka DevTools, lalu pilih tab Console. Ketik kode berikut dan tekan Enter:

console.log('Halo, JavaScript!');

console.log() menampilkan nilai di konsol. Fungsi ini akan sering kita pakai untuk melihat isi variabel dan hasil perhitungan.

Cara kedua adalah Node.js. Pasang versi Long Term Support (LTS) dari situs resminya, simpan kode tadi di berkas latihan.js, lalu jalankan perintah berikut di terminal dari folder yang sama:

node latihan.js

Teks Halo, JavaScript! akan tampil di terminal. Semua contoh di materi ini bisa dijalankan dengan kedua cara tersebut.

Menyimpan Nilai dengan let dan const

Variabel adalah wadah bernama untuk menyimpan nilai. JavaScript modern menyediakan dua kata kunci untuk membuatnya:

const namaToko = 'Toko Buku Nusantara';
let jumlahBeli = 2;

jumlahBeli = 3;
console.log(namaToko, jumlahBeli); // Toko Buku Nusantara 3

const dipakai untuk nilai yang tidak akan diganti, sedangkan let dipakai untuk nilai yang bisa berubah, seperti jumlahBeli. Bila Anda mencoba mengganti nilai namaToko, JavaScript menghentikan kode dengan galat TypeError. Biasakan memakai const lebih dulu, lalu beralih ke let hanya bila nilainya memang perlu diganti.

Anda mungkin juga menemukan kata kunci var di kode lama. Perbedaannya dibahas di artikel Perbedaan var, let, dan const di JavaScript dan Kapan Memakainya. Nama variabel di JavaScript lazim ditulis dengan gaya camelCase, yaitu kata pertama berhuruf kecil dan kata berikutnya diawali huruf kapital.

Tipe Data Dasar

Setiap nilai memiliki tipe. Operator typeof menunjukkan tipe sebuah nilai:

const judulBuku = 'Laskar Pelangi';
const hargaBuku = 85000;
const tersedia = true;
let catatan;

console.log(typeof judulBuku); // string
console.log(typeof hargaBuku); // number
console.log(typeof tersedia);  // boolean
console.log(typeof catatan);   // undefined

Berikut tipe data dasar yang paling sering dipakai:

  • string untuk teks, ditulis di antara tanda petik tunggal, tanda petik ganda, atau tanda petik terbalik (`).

  • number untuk angka. Tipe ini tidak membedakan bilangan bulat dan pecahan, jadi 85000 dan 4.5 bertipe sama.

  • boolean hanya bernilai true atau false dan menjadi dasar setiap keputusan di kode.

  • undefined menandakan variabel yang belum diberi nilai, seperti catatan di atas.

  • null menandakan nilai yang sengaja dikosongkan. Uniknya, typeof null menghasilkan 'object' karena kekeliruan pada versi awal JavaScript yang dipertahankan agar kode lama tetap berjalan.

Tanda petik terbalik membentuk template literal yang bisa menyisipkan nilai variabel lewat ${...}:

const pesan = `${judulBuku} seharga Rp${hargaBuku}`;
console.log(pesan); // Laskar Pelangi seharga Rp85000

Operator Aritmetika

Operator aritmetika bekerja seperti di matematika: +, -, *, /, dan % untuk sisa bagi.

const subtotal = hargaBuku * jumlahBeli;
console.log(subtotal);     // 255000
console.log(subtotal / 2); // 127500
console.log(17 % 5);       // 2
console.log('5' + 3);      // 53 (string)
console.log('5' - 3);      // 2 (number)

Perhatikan dua baris terakhir. Bila salah satu nilainya string, operator + menyambung teks alih-alih menjumlahkan, sedangkan - mengubah string menjadi angka lebih dulu. Ubah isian dari pengguna menjadi angka dengan Number() sebelum dihitung agar hasilnya tidak mengejutkan.

Operator Perbandingan dan Logika

Operator perbandingan menghasilkan nilai boolean dan sering digabung dengan operator logika:

console.log(5 == '5');                       // true
console.log(5 === '5');                      // false
console.log(hargaBuku >= 50000 && tersedia); // true
console.log(jumlahBeli > 5 || tersedia);     // true
console.log(!tersedia);                      // false

Operator == menyamakan tipe nilai sebelum membandingkan sehingga angka 5 dianggap sama dengan string '5'. Operator === membandingkan nilai sekaligus tipenya. Selalu gunakan === dan !== agar hasil perbandingan mudah ditebak.

Operator logika menggabungkan beberapa kondisi: && bernilai true bila kedua sisinya benar, || bernilai true bila salah satu sisinya benar, dan ! membalik nilai boolean.

Pada materi berikutnya, kita akan memakai operator perbandingan dan logika ini untuk membuat keputusan lewat percabangan serta mengulang perintah dengan perulangan.
