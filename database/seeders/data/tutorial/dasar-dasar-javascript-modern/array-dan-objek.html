Toko buku menyimpan banyak judul dan setiap judul memiliki penulis serta harga. Data seperti ini ditampung dengan dua struktur yang paling sering dipakai di JavaScript, yaitu array dan objek. Materi terakhir seri ini membahas keduanya, lalu menggabungkannya menjadi keranjang belanja.

Menyimpan Daftar dengan Array

Array menyimpan banyak nilai secara berurutan di dalam tanda kurung siku:

const daftarJudul = ['Laskar Pelangi', 'Bumi Manusia', 'Ronggeng Dukuh Paruk'];

console.log(daftarJudul[0]);     // Laskar Pelangi
console.log(daftarJudul.length); // 3

daftarJudul.push('Cantik Itu Luka');
console.log(daftarJudul.includes('Bumi Manusia'));   // true
console.log(daftarJudul.indexOf('Cantik Itu Luka')); // 3

Setiap isi array memiliki indeks yang dimulai dari 0, jadi isi terakhir berada di indeks length - 1. push() menambahkan isi di akhir array, includes() memeriksa keberadaan sebuah nilai, dan indexOf() mencari indeksnya.

Perhatikan bahwa daftarJudul dibuat dengan const, tetapi isinya tetap bisa ditambah. const hanya melarang variabel diisi ulang dengan nilai lain dan tidak melarang perubahan isi array atau objek yang disimpannya.

Mengelompokkan Data dengan Objek

Objek mengelompokkan beberapa nilai yang saling berkaitan di dalam kurung kurawal:

const buku = {
  judul: 'Laskar Pelangi',
  penulis: 'Andrea Hirata',
  harga: 85000,
  tersedia: true,
};

console.log(buku.judul);      // Laskar Pelangi
console.log(buku['penulis']); // Andrea Hirata

buku.harga = 80000;
buku.tahunTerbit = 2005;
delete buku.tersedia;

Setiap pasangan nama dan nilai di dalam objek disebut properti. Properti dibaca dengan titik, seperti buku.judul, atau dengan tanda kurung siku bila namanya tersimpan di variabel. Menulis properti yang belum ada akan menambahkannya, sedangkan delete menghapusnya. Properti yang berisi fungsi disebut method, misalnya push() pada array tadi.

Array Berisi Objek

Keranjang belanja cocok disimpan sebagai array yang setiap isinya berupa objek:

const keranjang = [
  { judul: 'Laskar Pelangi', harga: 85000, jumlah: 2 },
  { judul: 'Bumi Manusia', harga: 60000, jumlah: 1 },
  { judul: 'Ronggeng Dukuh Paruk', harga: 30000, jumlah: 1 },
];

for (const item of keranjang) {
  console.log(`${item.judul} x${item.jumlah}`);
}

Bentuk ini akan sering Anda temui, termasuk pada data yang dikirim server. Setiap item memiliki properti yang sama sehingga mudah diolah dengan perulangan.

Mengolah Array dengan map, filter, dan reduce

Array memiliki banyak method bawaan yang menerima callback dan menjalankannya untuk setiap item:

const formatRupiah = (angka) => `Rp${angka.toLocaleString('id-ID')}`;

const judulSaja = keranjang.map((item) => item.judul);
const bukuMurah = keranjang.filter((item) => item.harga < 70000);
const bukuBumi = keranjang.find((item) => item.judul === 'Bumi Manusia');
const totalBelanja = keranjang.reduce((total, item) => total + item.harga * item.jumlah, 0);

console.log(judulSaja);                  // ['Laskar Pelangi', 'Bumi Manusia', 'Ronggeng Dukuh Paruk']
console.log(bukuMurah.length);           // 2
console.log(bukuBumi.harga);             // 60000
console.log(formatRupiah(totalBelanja)); // Rp260.000

  • map() membuat array baru dari hasil callback, misalnya judulnya saja.

  • filter() membuat array baru berisi item yang membuat callback bernilai true.

  • find() mengembalikan item pertama yang cocok, atau undefined bila tidak ada yang cocok.

  • reduce() meringkas semua item menjadi satu nilai. Argumen 0 adalah nilai awal total.

Keempat method ini tidak mengubah keranjang sehingga data aslinya tetap utuh. Dengan aturan diskon dari materi kedua, belanja Rp260.000 ini berhak atas diskon 10%.

Membongkar dan Menyalin Data

Ada dua penulisan singkat yang akan sering Anda jumpai di kode JavaScript modern:

const { judul, harga } = keranjang[0];
console.log(judul, harga); // Laskar Pelangi 85000

const itemBaru = { ...keranjang[0], jumlah: 3 };
const keranjangBaru = [...keranjang, { judul: 'Cantik Itu Luka', harga: 95000, jumlah: 1 }];

Baris pertama mengambil properti judul dan harga ke dalam variabel bernama sama. Teknik ini disebut destructuring. Tanda tiga titik atau operator spread menyalin seluruh isi objek atau array ke wadah baru. Pada objek, properti yang ditulis setelahnya menimpa nilai lama sehingga itemBaru berisi jumlah: 3. Pada array, isi baru ditambahkan di akhir salinan. Hasilnya, keranjang asli tetap tidak berubah.
