CNN yang dilatih dari nol dengan sekitar 3.000 foto memberikan hasil yang terbatas. Transfer learning menawarkan jalan pintas: kita memakai model praterlatih, yaitu model yang sudah dilatih pada dataset raksasa, lalu menyesuaikannya dengan kasus kita. Materi ini memakai MobileNetV2, model ringan yang sudah dilatih dengan lebih dari satu juta foto ImageNet dalam 1.000 kategori.

Lanjutkan berkas bunga.py. Kode dataset dan lapisan augmentasi tetap dipakai, sedangkan model CNN dari materi sebelumnya sebaiknya dihapus agar tidak ikut dilatih ulang.

Memuat MobileNetV2 tanpa Lapisan Atas

model_dasar = keras.applications.MobileNetV2(
    input_shape=ukuran_gambar + (3,),
    include_top=False,
    weights="imagenet",
)
model_dasar.trainable = False

Argumen weights="imagenet" mengunduh bobot hasil pelatihan ImageNet saat pertama dijalankan. include_top=False membuang lapisan klasifikasi aslinya yang berisi 1.000 kelas karena kita hanya membutuhkan lima. Bagian yang tersisa mengubah foto 160 × 160 menjadi feature map berukuran 5 × 5 dengan 1.280 kanal. Baris trainable = False membekukan seluruh bobotnya agar pengetahuan yang sudah ada tidak rusak saat lapisan baru mulai dilatih.

Menyusun Model Baru

Kali ini kita menyusun model dengan cara fungsional: setiap lapisan dipanggil seperti fungsi, lalu hasilnya diteruskan ke lapisan berikutnya. Cara ini dibutuhkan karena preprocess_input bukan lapisan, melainkan fungsi biasa yang tidak bisa dimasukkan ke daftar keras.Sequential.

masukan = keras.Input(shape=ukuran_gambar + (3,))
x = augmentasi(masukan)
x = keras.applications.mobilenet_v2.preprocess_input(x)
x = model_dasar(x)
x = keras.layers.GlobalAveragePooling2D()(x)
x = keras.layers.Dropout(0.2)(x)
keluaran = keras.layers.Dense(len(nama_kelas), activation="softmax")(x)

model = keras.Model(masukan, keluaran)

preprocess_input mengubah nilai piksel dari 0–255 menjadi −1 sampai 1, sesuai dengan format data saat MobileNetV2 dilatih. Langkah ini menggantikan Rescaling di materi sebelumnya. GlobalAveragePooling2D merata-ratakan setiap feature map 5 × 5 menjadi satu angka sehingga lapisan Dense terakhir menerima 1.280 fitur. Terakhir, keras.Model() menyatukan rangkaian itu menjadi satu model.

Melatih Lapisan Baru

model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"],
)

riwayat = model.fit(data_latih, validation_data=data_validasi, epochs=10)

Hanya 6.405 parameter di lapisan Dense terakhir yang dilatih. Akurasi validasi biasanya sudah melampaui 80 persen sejak epoch pertama dan mendekati 90 persen di akhir pelatihan, jauh di atas CNN buatan sendiri.

Fine-Tuning Singkat

Setelah lapisan baru stabil, buka sebagian lapisan atas MobileNetV2 agar ikut menyesuaikan diri dengan foto bunga:

model_dasar.trainable = True
for lapisan in model_dasar.layers[:100]:
    lapisan.trainable = False
for lapisan in model_dasar.layers:
    if isinstance(lapisan, keras.layers.BatchNormalization):
        lapisan.trainable = False

model.compile(
    optimizer=keras.optimizers.Adam(learning_rate=1e-5),
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"],
)

riwayat_lanjutan = model.fit(data_latih, validation_data=data_validasi, epochs=5)

MobileNetV2 terdiri atas 154 lapisan. Kode di atas membuka semuanya, membekukan kembali 100 lapisan pertama yang mengenali pola dasar, lalu tetap membekukan semua lapisan BatchNormalization. Lapisan ini menyimpan statistik data ImageNet; bila ikut dilatih dengan batch kecil, statistiknya bergeser dan akurasi bisa turun tajam. Model wajib dikompilasi ulang setiap kali status trainable berubah. Learning rate dibuat sangat kecil agar bobot yang sudah bagus hanya bergeser sedikit. Tanpa itu, fine-tuning justru bisa merusak hasil pelatihan sebelumnya. Dengan pengaturan ini, akurasi validasi biasanya naik lagi hingga sekitar 90 persen.

Menyimpan Model dan Memprediksi Foto Baru

model.save("model_bunga.keras")

Berkas .keras menyimpan susunan, bobot, dan pengaturan model dalam satu berkas. Buat skrip baru prediksi.py yang memuat model itu dan menebak jenis bunga pada satu foto:

import keras
import numpy as np

nama_kelas = ["daisy", "dandelion", "roses", "sunflowers", "tulips"]
model = keras.models.load_model("model_bunga.keras")

gambar = keras.utils.load_img("foto_bunga.jpg", target_size=(160, 160))
x = keras.utils.img_to_array(gambar)
x = np.expand_dims(x, axis=0)

prediksi = model.predict(x)
indeks = np.argmax(prediksi[0])
print(f"{nama_kelas[indeks]} ({prediksi[0][indeks]:.1%})")

Ganti foto_bunga.jpg dengan foto bunga milik Anda yang tidak termasuk dalam dataset. load_img() membaca foto tersebut sekaligus mengubah ukurannya menjadi 160 × 160. Fungsi ini memakai pustaka Pillow yang ikut terpasang bersama Matplotlib; bila belum ada, jalankan pip install pillow. expand_dims() menambahkan dimensi batch, sedangkan np.argmax() memilih kelas dengan peluang tertinggi. Normalisasi tidak perlu ditulis ulang karena preprocess_input sudah menjadi bagian dari model.
