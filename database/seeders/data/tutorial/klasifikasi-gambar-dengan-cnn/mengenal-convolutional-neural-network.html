Seri ini mengajak Anda membangun model yang mengenali jenis bunga dari foto dengan Convolutional Neural Network (CNN), jenis jaringan saraf tiruan yang dirancang khusus untuk gambar. Anda cukup menguasai dasar Python, sudah memasang TensorFlow, dan mengenal lapisan Dense serta method compile() dan fit() di Keras. Semua itu dibahas di tutorial Pengantar Deep Learning dengan Keras.

Materi pertama ini membahas konsep di balik CNN, yaitu konvolusi, kernel, feature map, dan pooling. Contoh kodenya hanya memakai NumPy agar setiap langkah perhitungan bisa diamati langsung.

Keterbatasan Lapisan Dense untuk Gambar

Model pengenal angka tulisan tangan di tutorial pengantar memakai Flatten untuk meratakan gambar menjadi deretan piksel. Cara ini membuang informasi letak: model tidak tahu piksel mana yang bersebelahan. Jumlah bobotnya juga membengkak. Foto berwarna berukuran 160 × 160 piksel dengan tiga kanal warna berisi 76.800 nilai. Satu lapisan Dense berisi 128 neuron saja sudah membutuhkan lebih dari 9,8 juta bobot.

Konvolusi dan Kernel

CNN menempuh cara lain. Sebuah filter kecil, biasanya berukuran 3 × 3, digeser di atas gambar. Pada setiap posisi, nilai piksel dikalikan dengan nilai filter, lalu dijumlahkan menjadi satu angka. Operasi ini disebut konvolusi. Matriks bobot pada filter itu disebut kernel.

Contoh berikut memakai kernel pendeteksi tepi tegak pada gambar 5 × 5 yang bagian kirinya gelap (0) dan bagian kanannya terang (9):

import numpy as np

gambar = np.array([
    [0, 0, 0, 9, 9],
    [0, 0, 0, 9, 9],
    [0, 0, 0, 9, 9],
    [0, 0, 0, 9, 9],
    [0, 0, 0, 9, 9],
])
kernel = np.array([
    [-1, 0, 1],
    [-1, 0, 1],
    [-1, 0, 1],
])

hasil = np.zeros((3, 3))
for i in range(3):
    for j in range(3):
        hasil[i, j] = np.sum(gambar[i:i + 3, j:j + 3] * kernel)

print(hasil)

Perulangan tersebut mengambil potongan 3 × 3 dari gambar di setiap posisi, mengalikannya dengan kernel, lalu menjumlahkan hasilnya. Keluarannya:

[[ 0. 27. 27.]
 [ 0. 27. 27.]
 [ 0. 27. 27.]]

Gambar 5 × 5 menyusut menjadi 3 × 3 karena kernel 3 × 3 hanya muat di sembilan posisi. Nilai besar muncul di posisi yang mencakup peralihan dari gelap ke terang, sedangkan daerah yang seragam bernilai nol. Dengan kata lain, kernel ini menyorot tepi tegak.

Feature Map dan Lapisan Bertingkat

Hasil konvolusi disebut feature map, yaitu peta yang menunjukkan letak sebuah pola di gambar. Di CNN, kita tidak menulis nilai kernel sendiri. Model mempelajarinya selama pelatihan, sama seperti bobot lapisan Dense. Lapisan Conv2D(32, 3) di Keras berisi 32 kernel berukuran 3 × 3 sehingga menghasilkan 32 feature map sekaligus.

Lapisan konvolusi pertama biasanya belajar mengenali tepi dan warna. Lapisan berikutnya menggabungkan feature map itu menjadi tekstur dan bentuk. Lapisan yang lebih dalam kemudian mengenali bagian utuh, seperti kelopak atau tangkai bunga.

Meringkas dengan Pooling

Pooling memperkecil feature map sambil mempertahankan informasi terpenting. Jenis yang paling umum, max pooling 2 × 2, membagi feature map menjadi kotak-kotak 2 × 2 dan hanya mengambil nilai terbesar dari setiap kotak. Contohnya, kotak berisi 1, 3, 4, dan 2 diringkas menjadi 4.

Lebar dan tinggi feature map pun menyusut separuh sehingga perhitungan di lapisan berikutnya lebih ringan. Model juga menjadi lebih tahan terhadap pergeseran kecil karena posisi pola tidak harus tepat sama. Di Keras, lapisan ini bernama MaxPooling2D.

Alasan CNN Cocok untuk Gambar

  • Bobot dipakai bersama. Kernel yang sama digeser ke seluruh gambar. Lapisan Conv2D(32, 3) pada foto berwarna hanya memiliki 896 parameter, jauh lebih sedikit daripada 9,8 juta bobot lapisan Dense tadi.

  • Letak piksel diperhatikan. Setiap kernel melihat piksel yang bersebelahan sehingga pola lokal seperti tepi dan sudut mudah dikenali.

  • Pola dikenali di mana pun. Bunga di pojok kiri dan bunga di tengah foto memicu kernel yang sama.
