Sebelum melatih CNN, kita perlu menyusun foto dan memuatnya dalam format yang dipahami Keras. Materi ini membahas struktur folder per kelas, cara memuat foto dengan keras.utils.image_dataset_from_directory, serta cara mempercepat pembacaan data selama pelatihan.

Struktur Folder per Kelas

Keras mengenali kelas dari nama folder. Setiap kelas memiliki satu folder berisi foto-fotonya. Semua folder kelas berada di dalam satu folder induk:

flower_photos/
    daisy/
    dandelion/
    roses/
    sunflowers/
    tulips/

Nama berkas fotonya bebas. Bila memakai foto sendiri, buat susunan yang sama, misalnya folder hewan/kucing/ dan hewan/anjing/. Usahakan setiap kelas berisi setidaknya beberapa ratus foto dengan jumlah yang tidak terlalu timpang antarkelas.

Mengunduh Contoh Dataset

Unduh berkas foto bunga lewat peramban dari alamat berikut, lalu simpan di folder proyek, misalnya belajar-keras:

https://storage.googleapis.com/download.tensorflow.org/example_images/flower_photos.tgz

Buka terminal di folder yang sama, lalu ekstrak berkasnya. Perintah tar sudah tersedia di Windows 10 dan 11, macOS, serta Linux:

tar -xzf flower_photos.tgz

Hasilnya adalah folder flower_photos berisi lima folder kelas dan satu berkas lisensi. Berkas yang tidak berada di dalam folder kelas akan diabaikan Keras. Pengguna Colab bisa menjalankan kedua langkah ini di sel notebook dengan perintah !wget dan !tar.

Memuat Foto dengan image_dataset_from_directory

Buat berkas bunga.py di folder proyek. Berkas ini akan terus dilanjutkan sampai materi terakhir:

import keras
import tensorflow as tf

folder_data = "flower_photos"
ukuran_gambar = (160, 160)

data_latih, data_validasi = keras.utils.image_dataset_from_directory(
    folder_data,
    validation_split=0.2,
    subset="both",
    seed=123,
    image_size=ukuran_gambar,
    batch_size=32,
)

nama_kelas = data_latih.class_names
print(nama_kelas)

Fungsi ini mendata semua foto, memberi label sesuai nama folder, dan mengubah ukuran setiap foto menjadi 160 × 160 piksel saat dibaca. Parameter validation_split=0.2 bersama subset="both" membagi foto menjadi 80 persen data latih dan 20 persen data validasi. Nilai seed membuat pembagian itu tetap sama setiap kali skrip dijalankan. Foto juga dikelompokkan per batch berisi 32 foto. Keluarannya:

Found 3670 files belonging to 5 classes.
Using 2936 files for training.
Using 734 files for validation.
['daisy', 'dandelion', 'roses', 'sunflowers', 'tulips']

Urutan nama_kelas mengikuti abjad nama folder: label 0 berarti daisy, label 1 berarti dandelion, dan seterusnya. Simpan daftar ini sekarang karena atribut class_names tidak lagi tersedia setelah dataset diolah lebih lanjut.

Melihat Isi Satu Batch

for gambar, label in data_latih.take(1):
    print(gambar.shape)
    print(label.numpy())

take(1) mengambil satu batch saja. Bentuk (32, 160, 160, 3) berarti 32 foto berukuran 160 × 160 dengan tiga kanal warna, sedangkan label berupa 32 bilangan bulat antara 0 dan 4. Nilai pikselnya masih 0 sampai 255. Normalisasinya akan dilakukan di dalam model pada materi berikutnya.

Mempercepat dengan cache dan prefetch

AUTOTUNE = tf.data.AUTOTUNE

data_latih = data_latih.cache().shuffle(1000).prefetch(buffer_size=AUTOTUNE)
data_validasi = data_validasi.cache().prefetch(buffer_size=AUTOTUNE)

Dataset buatan Keras ini berupa objek tf.data.Dataset milik TensorFlow. Itulah alasan kita mengimpor tensorflow di awal berkas.

  • cache() menyimpan foto yang sudah dibaca di memori selama epoch pertama sehingga epoch berikutnya tidak perlu membuka berkas foto lagi.

  • shuffle(1000) mengacak urutan batch di setiap epoch karena isi cache selalu keluar dalam urutan yang sama.

  • prefetch() menyiapkan batch berikutnya selagi model mengolah batch yang sedang berjalan. Nilai AUTOTUNE membiarkan TensorFlow menentukan jumlah batch yang disiapkan.

Seluruh foto berukuran 160 × 160 ini membutuhkan sekitar 1 GB memori. Bila memori komputer Anda terbatas, tulis cache("cache_latih") dan cache("cache_validasi") agar cache disimpan di disk. Pada materi berikutnya, kita akan membangun CNN dengan lapisan Conv2D dan MaxPooling2D, lalu melatihnya dengan dataset ini.
