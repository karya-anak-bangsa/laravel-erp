Materi terakhir ini melengkapi aplikasi perpustakaan dengan fitur hapus. Kita akan membuat tombol hapus yang aman, mengenal soft delete agar data yang terhapus masih bisa dipulihkan, lalu merapikan semua rute buku menjadi satu baris.

Mengapa Hapus Tidak Memakai Tautan Biasa

Tautan biasa mengirim permintaan GET. Mesin pencari, ekstensi peramban, dan fitur prefetch bebas membuka tautan GET tanpa sepengetahuan pengguna. Bila alamat seperti /buku/2/hapus langsung menghapus data, buku bisa hilang hanya karena sebuah perayap menelusuri halaman. Oleh karena itu, penghapusan memakai permintaan DELETE yang dikirim lewat formulir bertoken CSRF.

Rute dan Tombol Hapus

Tambahkan rute berikut di routes/web.php:

Route::delete('/buku/{buku}', [BukuController::class, 'destroy'])->name('buku.destroy');

Tambahkan tombol hapus di show.blade.php, di bawah tautan ubah:

<form method="POST" action="{{ route('buku.destroy', $buku) }}"
    onsubmit="return confirm('Hapus buku ini?')">
    @csrf
    @method('DELETE')
    <button type="submit">Hapus buku</button>
</form>

Seperti pada formulir ubah, @method('DELETE') membuat Laravel memperlakukan kiriman POST ini sebagai DELETE. Fungsi confirm() meminta konfirmasi lebih dulu sehingga buku tidak terhapus karena salah klik.

Menghapus di Controller

Tambahkan method destroy() di BukuController:

public function destroy(Buku $buku)
{
    $buku->delete();

    return redirect()->route('buku.index')->with('status', 'Buku berhasil dihapus.');
}

Pengunjung dialihkan ke daftar buku karena halaman detail buku yang baru dihapus sudah tidak ada. Coba hapus satu buku. Pesan berhasil akan tampil dan buku itu hilang dari daftar.

Menyimpan Data Terhapus dengan Soft Delete

delete() di atas menghapus baris secara permanen. Pada aplikasi sungguhan, data yang terhapus kadang perlu dikembalikan. Soft delete mengatasinya: Laravel hanya mengisi kolom deleted_at dengan waktu penghapusan sehingga baris tersebut tidak lagi muncul di query biasa.

Tabel buku sudah berisi data, jadi tambahkan kolomnya lewat migrasi baru:

php artisan make:migration add_deleted_at_to_buku_table --table=buku

Isi kedua method migrasi tersebut:

public function up(): void
{
    Schema::table('buku', function (Blueprint $table) {
        $table->softDeletes();
    });
}

public function down(): void
{
    Schema::table('buku', function (Blueprint $table) {
        $table->dropSoftDeletes();
    });
}

Jalankan php artisan migrate, lalu pasang trait SoftDeletes di model Buku:

use Illuminate\Database\Eloquent\SoftDeletes;

#[Table('buku')]
#[Fillable(['judul', 'penulis', 'tahun_terbit'])]
class Buku extends Model
{
    use SoftDeletes;
}

Kode controller tidak perlu diubah. Kini $buku->delete() hanya menandai baris sebagai terhapus. Daftar buku dan route model binding otomatis melewatkan buku tersebut sehingga alamat detailnya menghasilkan halaman 404.

Data yang terhapus tetap bisa diakses bila diperlukan, misalnya lewat Tinker:

App\Models\Buku::onlyTrashed()->get();
App\Models\Buku::withTrashed()->find(2)->restore();
App\Models\Buku::withTrashed()->find(3)->forceDelete();

onlyTrashed() mengambil buku yang terhapus saja, restore() memulihkan buku, dan forceDelete() menghapus buku secara permanen. Soft delete bukan pengganti cadangan basis data, jadi biasakan juga mencadangkan basis data MySQL secara otomatis.

Merapikan Rute dengan Resource Controller

Lihat kembali routes/web.php. Kini ada tujuh rute buku dengan pola yang sangat umum: daftar, formulir tambah, simpan, detail, formulir ubah, simpan perubahan, dan hapus. Laravel menyebut kumpulan ini resource dan bisa mendaftarkan ketujuhnya dengan satu baris:

Route::resource('buku', BukuController::class);

Nama rute dan method yang dihasilkan sama persis dengan yang kita tulis, yaitu buku.index, buku.create, buku.store, buku.show, buku.edit, buku.update, dan buku.destroy. Bedanya hanya pada alamat formulir yang berbahasa Inggris, yaitu /buku/create dan /buku/{buku}/edit.

Alamat berbahasa Indonesia bisa dipertahankan dengan menambahkan kode berikut di method boot() pada app/Providers/AppServiceProvider.php:

use Illuminate\Support\Facades\Route;

public function boot(): void
{
    Route::resourceVerbs([
        'create' => 'tambah',
        'edit' => 'ubah',
    ]);
}

Hapus ketujuh rute lama, simpan berkasnya, lalu jalankan php artisan route:list --path=buku. Alamat dan nama rutenya sama dengan sebelumnya, tetapi kini cukup ditulis dalam satu baris.
