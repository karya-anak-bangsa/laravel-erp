Setiap kali peramban membuka sebuah alamat, Laravel mencari rute yang cocok, menjalankan kode penanganannya, lalu mengirim balik tampilan. Materi ini membahas ketiga bagian itu: rute, controller, dan templat Blade. Hasil akhirnya adalah halaman daftar buku pertama, meskipun datanya masih ditulis langsung di kode.

Rute Pertama

Buka routes/web.php. Di sana sudah ada rute bawaan yang menampilkan halaman sambutan:

Route::get('/', function () {
    return view('welcome');
});

Route::get() menerima dua hal, yaitu alamat dan kode yang dijalankan saat alamat itu dibuka dengan permintaan GET. Tambahkan rute percobaan di bawahnya:

Route::get('/halo', function () {
    return 'Halo dari Laravel 13!';
});

Buka http://perpustakaan.test/halo. Teks tersebut langsung tampil di peramban. Fungsi tanpa nama (closure) seperti ini cocok untuk percobaan, tetapi kode aplikasi sebaiknya ditaruh di controller agar routes/web.php tetap ringkas.

Membuat Controller

Buat controller untuk data buku lewat Artisan:

php artisan make:controller BukuController

Laravel membuat berkas app/Http/Controllers/BukuController.php. Ubah isinya menjadi seperti berikut agar method index() mengirim daftar judul ke tampilan:

<?php

namespace App\Http\Controllers;

class BukuController extends Controller
{
    public function index()
    {
        $daftarBuku = [
            'Laskar Pelangi',
            'Bumi Manusia',
            'Ronggeng Dukuh Paruk',
        ];

        return view('buku.index', ['daftarBuku' => $daftarBuku]);
    }
}

Fungsi view('buku.index', ...) memuat berkas resources/views/buku/index.blade.php. Titik pada nama view menandakan folder. Array kedua berisi data yang bisa dipakai di tampilan.

Hubungkan controller ini ke rute di routes/web.php, lalu hapus rute percobaan /halo:

use App\Http\Controllers\BukuController;

Route::get('/buku', [BukuController::class, 'index'])->name('buku.index');

name('buku.index') memberi nama pada rute. Di bagian kode lain, Anda cukup menulis route('buku.index') untuk mendapatkan alamatnya. Bila alamatnya kelak diubah, semua tautan ikut berubah tanpa perlu dicari satu per satu. Lihat semua rute yang terdaftar dengan php artisan route:list.

Tata Letak dengan Blade

Blade adalah mesin templat Laravel. Hampir semua halaman memakai kerangka HTML yang sama, jadi kita menulisnya sekali sebagai tata letak di resources/views/layouts/app.blade.php:

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>@yield('judul') | Perpustakaan</title>
</head>
<body>
    <main>
        @yield('konten')
    </main>
</body>
</html>

Direktif @yield menandai bagian yang isinya ditentukan setiap halaman. Sekarang buat resources/views/buku/index.blade.php:

@extends('layouts.app')

@section('judul', 'Daftar Buku')

@section('konten')
    <h1>Daftar Buku</h1>

    <ul>
        @foreach ($daftarBuku as $judul)
            <li>{{ $judul }}</li>
        @endforeach
    </ul>
@endsection

@extends memakai tata letak tadi, sedangkan @section mengisi bagian yang ditandai @yield. Direktif @foreach mengulang isi di dalamnya untuk setiap judul. Buka http://perpustakaan.test/buku dan ketiga judul buku akan tampil sebagai daftar.

Kegunaan Kurung Kurawal Ganda

Tanda {{ }} menampilkan isi variabel sekaligus mengubah karakter khusus HTML, seperti < dan >, menjadi entitas. Dengan begitu, teks berbahaya dari pengguna tampil sebagai teks biasa dan tidak dijalankan sebagai skrip. Perlindungan ini mencegah serangan Cross-Site Scripting (XSS).

Blade juga mengenal {!! !!} yang menampilkan HTML apa adanya. Pakai bentuk ini hanya untuk konten yang sudah pasti aman, misalnya HTML yang sudah disaring di server.

Langkah Berikutnya

Halaman daftar buku sudah tampil, tetapi datanya masih tertulis di controller. Pada materi berikutnya, kita akan membuat tabel buku di MySQL lewat migrasi dan mengaksesnya dengan model Eloquent.
