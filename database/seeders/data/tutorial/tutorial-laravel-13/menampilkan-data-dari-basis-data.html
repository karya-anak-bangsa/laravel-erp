Tabel buku sudah berisi tiga baris dari materi sebelumnya. Kini saatnya menampilkan data itu di peramban, yaitu halaman daftar berbentuk tabel dan halaman detail untuk setiap buku. Kita juga akan menambahkan pencarian sederhana.

Mengambil Data di Controller

Buka BukuController dan ganti daftar judul dengan query Eloquent:

<?php

namespace App\Http\Controllers;

use App\Models\Buku;

class BukuController extends Controller
{
    public function index()
    {
        $daftarBuku = Buku::orderBy('judul')->paginate(10);

        return view('buku.index', compact('daftarBuku'));
    }
}

orderBy('judul') mengurutkan buku menurut abjad, sedangkan paginate(10) mengambil paling banyak sepuluh buku per halaman. Tanpa paginasi, halaman akan memuat seluruh isi tabel sekaligus dan makin lambat seiring bertambahnya data. Fungsi compact('daftarBuku') adalah cara singkat menulis ['daftarBuku' => $daftarBuku].

Menampilkan Tabel di Blade

Ganti isi resources/views/buku/index.blade.php:

@extends('layouts.app')

@section('judul', 'Daftar Buku')

@section('konten')
    <h1>Daftar Buku</h1>

    @if ($daftarBuku->isEmpty())
        <p>Belum ada buku.</p>
    @else
        <table>
            <thead>
                <tr>
                    <th>Judul</th>
                    <th>Penulis</th>
                    <th>Tahun Terbit</th>
                </tr>
            </thead>
            <tbody>
                @foreach ($daftarBuku as $buku)
                    <tr>
                        <td><a href="{{ route('buku.show', $buku) }}">{{ $buku->judul }}</a></td>
                        <td>{{ $buku->penulis }}</td>
                        <td>{{ $buku->tahun_terbit }}</td>
                    </tr>
                @endforeach
            </tbody>
        </table>

        {{ $daftarBuku->links('pagination::bootstrap-5') }}
    @endif
@endsection

Setiap $buku di dalam @foreach adalah objek model Buku, jadi kolomnya dibaca sebagai properti, misalnya $buku->judul. Pesan "Belum ada buku." tampil bila tabel masih kosong.

links() menampilkan tautan ke halaman berikutnya begitu jumlah buku melebihi sepuluh. Tampilan bawaannya memakai kelas Tailwind CSS dan ikon SVG. Tata letak kita belum memuat CSS apa pun sehingga ikon panahnya bisa tampil sangat besar. Oleh karena itu, contoh di atas memakai tampilan pagination::bootstrap-5 yang hanya berisi daftar tautan biasa.

Halaman Detail Buku

Tautan pada judul buku mengarah ke rute buku.show yang belum ada. Tambahkan rutenya di routes/web.php:

Route::get('/buku', [BukuController::class, 'index'])->name('buku.index');
Route::get('/buku/{buku}', [BukuController::class, 'show'])->name('buku.show');

Bagian {buku} adalah parameter rute. Tambahkan method show() di BukuController:

public function show(Buku $buku)
{
    return view('buku.show', compact('buku'));
}

Perhatikan bahwa method ini tidak mencari bukunya sendiri. Fitur route model binding membaca angka di alamat, misalnya 2 pada /buku/2, lalu mengambil buku ber-id 2 dan memberikannya sebagai $buku. Syaratnya, nama parameter rute sama dengan nama variabel. Bila buku dengan id itu tidak ada, Laravel otomatis menampilkan halaman 404.

Buat tampilannya di resources/views/buku/show.blade.php:

@extends('layouts.app')

@section('judul', $buku->judul)

@section('konten')
    <h1>{{ $buku->judul }}</h1>

    <p>Penulis: {{ $buku->penulis }}</p>
    <p>Tahun terbit: {{ $buku->tahun_terbit }}</p>
    <p>Ditambahkan: {{ $buku->created_at->format('d-m-Y H:i') }}</p>

    <p><a href="{{ route('buku.index') }}">Kembali ke daftar buku</a></p>
@endsection

Kolom created_at otomatis berupa objek tanggal Carbon sehingga bisa diformat sesuai kebutuhan.

Menambahkan Pencarian Sederhana

Daftar buku yang panjang lebih mudah dipakai bila bisa dicari. Tambahkan use Illuminate\Http\Request; di bagian atas BukuController, lalu ubah method index() agar menerima kata kunci dari alamat, misalnya /buku?q=bumi:

public function index(Request $request)
{
    $q = $request->string('q')->trim()->value();

    $daftarBuku = Buku::query()
        ->when($q !== '', fn ($query) => $query->where('judul', 'like', "%{$q}%"))
        ->orderBy('judul')
        ->paginate(10)
        ->withQueryString();

    return view('buku.index', compact('daftarBuku', 'q'));
}

when() hanya menambahkan syarat where bila kata kunci diisi, sedangkan withQueryString() membawa kata kunci itu ke tautan halaman berikutnya. Eloquent mengirim nilai $q ke basis data sebagai parameter terpisah sehingga pencarian ini aman dari injeksi SQL.

Tambahkan formulir pencarian di atas tabel, tepat di bawah judul halaman:

<form method="GET" action="{{ route('buku.index') }}">
    <input type="search" name="q" value="{{ $q }}" placeholder="Cari judul buku">
    <button type="submit">Cari</button>
</form>

Coba cari kata bumi; hanya Bumi Manusia yang muncul di tabel. Data buku kini tampil langsung dari basis data. Pada materi berikutnya, kita akan membuat formulir untuk menambah buku baru lengkap dengan validasinya.
