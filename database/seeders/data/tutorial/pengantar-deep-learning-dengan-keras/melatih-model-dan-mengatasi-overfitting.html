Model dari materi sebelumnya sudah tersusun dan dikompilasi, tetapi bobotnya masih acak. Materi ini melatih model tersebut, membaca hasilnya, lalu mengatasi overfitting, yaitu kondisi saat model hafal data latih, tetapi gagal pada data baru. Lanjutkan kode di berkas mnist.py.

Melatih Model dengan fit()

Kode uji prediksi dari materi sebelumnya boleh dihapus. Tambahkan kode berikut di akhir berkas:

riwayat = model.fit(
    x_latih,
    y_latih,
    epochs=10,
    batch_size=32,
    validation_split=0.2,
)

Satu epoch berarti model sudah melihat seluruh data latih satu kali. Data diproses per batch berisi 32 gambar. Bobot diperbarui setiap kali satu batch selesai. Parameter validation_split=0.2 menyisihkan 20 persen data latih terakhir sebagai data validasi yang tidak ikut dipelajari. Sisa 48.000 gambar terbagi menjadi 1.500 batch per epoch. Keras menampilkan perkembangannya kira-kira seperti ini:

Membaca Riwayat Pelatihan

fit() mengembalikan objek yang atribut history-nya berisi nilai loss dan akurasi setiap epoch. Tambahkan import matplotlib.pyplot as plt di bagian atas berkas, lalu gambarkan riwayat itu sebagai grafik:

plt.plot(riwayat.history["loss"], label="data latih")
plt.plot(riwayat.history["val_loss"], label="data validasi")
plt.xlabel("epoch")
plt.ylabel("loss")
plt.legend()
plt.show()

plt.show() membuka jendela grafik. Tutup jendela itu agar skrip melanjutkan ke baris berikutnya. Di Colab, grafik langsung tampil di bawah sel.

Mengenali Overfitting

Pada grafik, garis loss data latih terus turun. Garis loss data validasi hanya turun pada beberapa epoch awal, kemudian mendatar atau malah naik. Celah yang melebar itu menandakan overfitting: model mulai menghafal kekhasan data latih alih-alih mempelajari pola umumnya. Kondisi ini mirip siswa yang menghafal kunci jawaban, tetapi kebingungan saat soalnya diganti.

Mengukur dengan Data Uji

loss_uji, akurasi_uji = model.evaluate(x_uji, y_uji)
print(f"Akurasi data uji: {akurasi_uji:.4f}")

evaluate() mengukur model pada 10.000 data uji yang tidak pernah dipakai, baik saat pelatihan maupun validasi. Angka inilah yang paling jujur menggambarkan kemampuan model pada data baru. Model sederhana kita biasanya mencapai akurasi sekitar 97–98 persen.

Mengatasi Overfitting dengan Dropout dan EarlyStopping

Tambahkan lapisan Dropout setelah lapisan tersembunyi pada susunan model di bagian atas berkas:

model = keras.Sequential([
    keras.Input(shape=(28, 28)),
    keras.layers.Flatten(),
    keras.layers.Dense(128, activation="relu"),
    keras.layers.Dropout(0.2),
    keras.layers.Dense(10, activation="softmax"),
])

Dropout(0.2) mematikan 20 persen keluaran neuron secara acak pada setiap langkah pelatihan sehingga model tidak bisa bergantung pada neuron tertentu. Lapisan ini hanya aktif saat pelatihan dan otomatis nonaktif saat evaluate() atau predict(). Setelah itu, ganti pemanggilan fit() dengan versi berikut:

henti_dini = keras.callbacks.EarlyStopping(
    monitor="val_loss",
    patience=3,
    restore_best_weights=True,
)

riwayat = model.fit(
    x_latih,
    y_latih,
    epochs=30,
    validation_split=0.2,
    callbacks=[henti_dini],
)

EarlyStopping adalah callback, yaitu objek yang dijalankan Keras di sela pelatihan. Objek ini memantau val_loss dan menghentikan pelatihan bila nilainya tidak membaik selama tiga epoch berturut-turut. Opsi restore_best_weights=True mengembalikan bobot dari epoch terbaik. Angka 30 hanya menjadi batas atas karena pelatihan biasanya berhenti jauh lebih awal.

Jalankan ulang berkasnya, lalu bandingkan grafik dan akurasinya dengan hasil sebelumnya. Pada MNIST, akurasi data uji mungkin hanya bergeser sedikit, tetapi celah antara data latih dan data validasi menyempit. Model pun lebih bisa diandalkan pada data yang belum pernah dilihatnya.
