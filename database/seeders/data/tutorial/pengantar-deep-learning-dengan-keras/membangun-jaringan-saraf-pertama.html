Lingkungan kerja sudah siap. Sekarang kita membangun model yang mengenali angka tulisan tangan dari dataset MNIST. Dataset ini berisi 70.000 gambar angka 0 sampai 9 berukuran 28 × 28 piksel dalam skala abu-abu, terdiri atas 60.000 data latih dan 10.000 data uji.

Tulis semua kode materi ini di satu berkas, misalnya mnist.py di folder belajar-keras, atau di satu notebook Colab. Materi berikutnya melanjutkan berkas yang sama.

Memuat Dataset MNIST

import keras

(x_latih, y_latih), (x_uji, y_uji) = keras.datasets.mnist.load_data()

print(x_latih.shape, y_latih.shape)
print(x_uji.shape, y_uji.shape)

Saat pertama dijalankan, Keras mengunduh MNIST dan menyimpannya di folder .keras/datasets di dalam folder pengguna sehingga pemanggilan berikutnya tidak perlu mengunduh lagi. Hasil cetaknya:

(60000, 28, 28) (60000,)
(10000, 28, 28) (10000,)

x_latih berisi 60.000 gambar berupa matriks 28 × 28, sedangkan y_latih berisi label angka untuk setiap gambar. Data uji disimpan terpisah dan baru dipakai setelah model selesai dilatih.

Normalisasi Data

Setiap piksel berupa bilangan bulat dari 0 (hitam) sampai 255 (putih). Jaringan saraf belajar lebih stabil bila masukannya bernilai kecil, jadi kita ubah rentangnya menjadi 0 sampai 1:

x_latih = x_latih.astype("float32") / 255
x_uji = x_uji.astype("float32") / 255

astype("float32") mengubah tipe data menjadi bilangan pecahan sebelum dibagi. Label tidak perlu diubah karena sudah berupa angka 0 sampai 9.

Menyusun Model dengan keras.Sequential

model = keras.Sequential([
    keras.Input(shape=(28, 28)),
    keras.layers.Flatten(),
    keras.layers.Dense(128, activation="relu"),
    keras.layers.Dense(10, activation="softmax"),
])

model.summary()

keras.Sequential menyusun lapisan secara berurutan dari atas ke bawah:

  • keras.Input(shape=(28, 28)) memberi tahu model bentuk satu data masukan. Keras tidak menghitungnya sebagai lapisan.

  • Flatten meratakan matriks 28 × 28 menjadi vektor berisi 784 nilai agar bisa diterima lapisan Dense.

  • Dense(128, activation="relu") adalah lapisan tersembunyi berisi 128 neuron dengan fungsi aktivasi ReLU.

  • Dense(10, activation="softmax") adalah lapisan keluaran. Setiap neuron mewakili satu angka, sedangkan softmax mengubah keluarannya menjadi peluang dengan total 1.

model.summary() menampilkan ringkasan lapisan beserta jumlah parameternya, yaitu 101.770 secara total. Lapisan Dense pertama saja memiliki 100.480 parameter, terdiri atas 784 × 128 bobot dan 128 bias. Seluruh parameter inilah yang akan diubah selama pelatihan.

Ringkasan tersebut juga menampilkan bentuk keluaran setiap lapisan. Keluaran lapisan tersembunyi, misalnya, berbentuk (None, 128). Nilai None mewakili jumlah data dalam satu batch yang baru diketahui saat model dipakai.

Kompilasi Model

Sebelum dilatih, model perlu dikompilasi untuk menentukan cara belajarnya:

model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"],
)

Optimizer Adam mengubah bobot sekaligus menyesuaikan besar langkahnya secara otomatis sehingga cocok sebagai pilihan awal. Fungsi loss sparse_categorical_crossentropy dipakai untuk klasifikasi banyak kelas dengan label berupa bilangan bulat. Bila label berbentuk one-hot, yaitu vektor yang bernilai 1 hanya di posisi kelasnya, gunakan categorical_crossentropy. Adapun metrics=["accuracy"] meminta Keras menampilkan akurasi selama pelatihan.

Menguji Prediksi Sebelum Pelatihan

prediksi = model.predict(x_uji[:1])
print(prediksi.round(2))
print("Label sebenarnya:", y_uji[0])

x_uji[:1] mengambil gambar uji pertama dalam bentuk batch berisi satu data karena predict() selalu menerima sekumpulan data. Keluarannya berupa sepuluh peluang, kira-kira seperti ini:

[[0.13 0.07 0.09 0.16 0.09 0.09 0.07 0.11 0.1  0.09]]
Label sebenarnya: 7

Bobot model masih acak sehingga peluangnya tersebar tanpa pola yang jelas, padahal gambar tersebut adalah angka 7. Model memang belum belajar apa pun. Pada materi berikutnya, kita akan melatih model ini dengan fit(), mengukur akurasinya pada data uji, dan mengatasi overfitting.
