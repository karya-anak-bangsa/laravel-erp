Keras adalah pustaka Python untuk menyusun dan melatih jaringan saraf tiruan dengan kode yang ringkas. Sejak Keras 3, pustaka ini bisa berjalan di atas beberapa mesin komputasi (backend), yaitu TensorFlow, JAX, dan PyTorch. Seri ini memakai TensorFlow karena Keras ikut terpasang bersamanya dan langsung memakainya sebagai backend bawaan.

Materi ini menyiapkan lingkungan kerja di komputer Anda, memeriksa apakah TensorFlow mengenali GPU, dan memperkenalkan Google Colab sebagai alternatif tanpa instalasi.

Membuat Lingkungan Virtual

Lingkungan virtual memisahkan pustaka proyek ini dari proyek Python lain sehingga versinya tidak saling bertabrakan. Pastikan dulu versi Python Anda termasuk yang didukung TensorFlow; daftarnya tercantum di halaman instalasi resmi TensorFlow. Setelah itu, jalankan perintah berikut di terminal untuk membuat folder proyek beserta lingkungan virtualnya:

mkdir belajar-keras
cd belajar-keras
python -m venv .venv

Aktifkan lingkungan virtual dengan perintah yang sesuai sistem operasi Anda:

# Windows (PowerShell atau Command Prompt)
.venv\Scripts\activate

# macOS dan Linux
source .venv/bin/activate

Tulisan (.venv) akan muncul di awal baris terminal. Bila PowerShell menolak menjalankan skrip aktivasi, jalankan Set-ExecutionPolicy RemoteSigned -Scope CurrentUser satu kali, lalu ulangi perintahnya. Panduan lebih lengkap tentang lingkungan virtual ada di artikel Belajar Python dari Nol: Instalasi, Virtual Environment, dan Program Pertama.

Memasang TensorFlow

Dengan lingkungan virtual yang masih aktif, jalankan dua perintah berikut:

python -m pip install --upgrade pip
pip install tensorflow matplotlib

Perintah pertama memperbarui pip karena versi lama kadang gagal menemukan paket TensorFlow yang sesuai. Perintah kedua memasang TensorFlow beserta Keras dan NumPy, ditambah Matplotlib untuk menggambar grafik di materi keempat. Ukuran unduhannya cukup besar sehingga prosesnya bisa memakan waktu beberapa menit.

Memeriksa Versi dan GPU

Buat berkas cek_lingkungan.py di folder belajar-keras:

import keras
import tensorflow as tf

print("TensorFlow:", tf.__version__)
print("Keras:", keras.__version__)
print("Backend:", keras.backend.backend())
print("GPU:", tf.config.list_physical_devices("GPU"))

Jalankan dengan python cek_lingkungan.py. Baris Backend seharusnya menampilkan tensorflow. Bila baris GPU berisi daftar kosong [], TensorFlow berjalan di Central Processing Unit (CPU). Kondisi ini tidak menjadi masalah di seri ini karena model MNIST cukup kecil dan selesai dilatih dalam hitungan menit.

TensorFlow juga sering mencetak beberapa baris informasi atau peringatan saat pertama dimuat. Selama skrip tetap mencetak keempat baris di atas, pesan tersebut aman diabaikan.

GPU di Windows

TensorFlow versi baru tidak lagi mendukung GPU di Windows secara langsung. Pengguna Windows yang memiliki GPU NVIDIA bisa memakai WSL2, fitur Windows untuk menjalankan Linux di dalam Windows. Di dalam WSL2 atau di Linux, pasang TensorFlow beserta pustaka CUDA dengan satu perintah:

pip install "tensorflow[and-cuda]"

Perintah ini membutuhkan driver NVIDIA yang sudah terpasang. Jika langkah tersebut terasa merepotkan, gunakan Google Colab.

Memakai Google Colab

Google Colab adalah layanan notebook Jupyter gratis yang berjalan di peramban. TensorFlow, Keras, dan Matplotlib sudah terpasang sehingga Anda bisa langsung menulis kode. Buka colab.research.google.com, masuk dengan akun Google, lalu buat notebook baru.

Pelatihan berjalan jauh lebih cepat dengan GPU. Buka menu Runtime › Change runtime type, lalu pilih salah satu GPU yang tersedia. Kuota GPU gratis terbatas, jadi akhiri sesi bila sudah selesai. Semua kode di seri ini berjalan sama, baik di komputer sendiri maupun di Colab.

Pada materi berikutnya, kita akan memuat dataset MNIST dan menyusun jaringan saraf pertama dengan Keras.
