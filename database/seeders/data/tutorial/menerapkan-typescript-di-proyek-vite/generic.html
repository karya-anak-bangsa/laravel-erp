Katalog kita akan berisi data pengguna, tetapi fungsi bantu seperti mengambil item pertama atau mencari data berdasarkan id juga berguna bagi produk, artikel, dan data lain. Generic memungkinkan Anda menulis fungsi dan tipe seperti itu sekali saja tanpa kehilangan informasi tipe. Kita menulis fungsi-fungsinya di berkas baru src/utilitas.ts.

Masalah Tipe yang Terlalu Longgar

Cara termudah membuat fungsi yang menerima data apa saja adalah memakai any. Contoh berikut cukup diamati, tidak perlu ditulis:

function ambilPertama(daftar: any[]): any {
  return daftar[0];
}

const pertama = ambilPertama(['Ani', 'Budi']);
pertama.toFixed(2); // lolos kompilasi, gagal saat berjalan

Fungsi ini berjalan, tetapi TypeScript tidak lagi tahu bahwa hasilnya berupa teks. Kesalahan memanggil toFixed() pada string baru ketahuan saat program berjalan.

Menulis Fungsi Generic

Ganti any dengan parameter tipe yang ditulis di antara tanda < dan >. Tulis versi yang benar di src/utilitas.ts:

export function ambilPertama<T>(daftar: T[]): T | undefined {
  return daftar[0];
}

Huruf T adalah parameter tipe, yaitu wadah bagi tipe yang baru diketahui saat fungsi dipanggil. Saat Anda memanggil ambilPertama(['Ani', 'Budi']), TypeScript menyimpulkan T sebagai string sehingga hasilnya bertipe string | undefined. Tipe undefined ikut disebut karena array kosong tidak memiliki item pertama. Anda juga bisa menyebut tipenya secara eksplisit, misalnya ambilPertama<number>([80, 95]).

Membatasi Parameter Tipe

Kadang fungsi generic perlu memastikan data memiliki properti tertentu. Batasi parameter tipenya dengan extends:

export function cariBerdasarkanId<T extends { id: number }>(daftar: T[], id: number): T | undefined {
  return daftar.find((item) => item.id === id);
}

Fungsi ini menerima array objek apa pun asalkan setiap objek memiliki id bertipe number. TypeScript menolak pemanggilan dengan ['Ani', 'Budi'] karena string tidak memiliki id. Tipe hasilnya tetap lengkap: bila yang dikirim data pengguna, yang kembali juga data pengguna beserta semua propertinya.

Interface Generic

Parameter tipe juga bisa dipakai pada interface. Tambahkan tipe halaman data dan fungsi pemotongnya:

export interface Halaman<T> {
  isi: T[];
  nomor: number;
  totalHalaman: number;
}

export function potongHalaman<T>(daftar: T[], nomor: number, ukuran: number): Halaman<T> {
  const awal = (nomor - 1) * ukuran;

  return {
    isi: daftar.slice(awal, awal + ukuran),
    nomor,
    totalHalaman: Math.ceil(daftar.length / ukuran),
  };
}

Tipe Halaman<Pengguna>, misalnya, berarti properti isi pada halaman itu berupa array Pengguna. Satu definisi itu berlaku bagi data jenis apa pun. Sebenarnya Anda sudah sering memakai tipe generic bawaan, misalnya Array<string>. Tipe Promise<T> akan kita pakai di materi terakhir, sedangkan document.querySelector<HTMLDivElement>() memberi tahu TypeScript jenis elemen yang dicari.

Mencoba di Halaman

Ganti isi src/main.ts dengan kode berikut, lalu buka konsol di alat pengembang peramban:

import './style.css';
import { ambilPertama, cariBerdasarkanId, potongHalaman } from './utilitas.ts';

const contohPengguna = [
  { id: 1, name: 'Leanne Graham' },
  { id: 2, name: 'Ervin Howell' },
  { id: 3, name: 'Clementine Bauch' },
];

const app = document.querySelector<HTMLDivElement>('#app');
const halamanPertama = potongHalaman(contohPengguna, 1, 2);

if (app) {
  app.innerHTML = '<h1>Katalog Pengguna</h1>';
}

console.log(ambilPertama(contohPengguna)?.name); // Leanne Graham
console.log(cariBerdasarkanId(contohPengguna, 3)?.name); // Clementine Bauch
console.log(halamanPertama.isi.length, halamanPertama.totalHalaman); // 2 2

Tanda ?. diperlukan karena ambilPertama() dan cariBerdasarkanId() bisa mengembalikan undefined. Pada materi berikutnya, kita akan membuat tipe Pengguna yang lengkap dan membentuk variasinya dengan utility types.
