Saatnya katalog menampilkan data sungguhan dari https://jsonplaceholder.typicode.com/users. Materi terakhir ini membahas cara memberi tipe pada hasil fetch(), alasan data dari luar program tidak bisa dipercaya begitu saja, dan cara memeriksanya dengan type guard.

Versi Pertama Fungsi Pengambil Data

Buat berkas src/api.ts:

import type { Pengguna } from './pengguna.ts';

const ALAMAT_API = 'https://jsonplaceholder.typicode.com/users';

export async function ambilPengguna(): Promise<Pengguna[]> {
  const respons = await fetch(ALAMAT_API);

  if (!respons.ok) {
    throw new Error(`Permintaan gagal dengan status ${respons.status}.`);
  }

  return respons.json();
}

Tipe Promise<Pengguna[]> adalah tipe generic dari materi kedua: fungsi ini menjanjikan array berisi Pengguna setelah selesai. Pemeriksaan respons.ok diperlukan karena fetch() tidak melempar galat untuk kode status seperti 404 atau 500. Bila async dan await masih terasa asing, baca artikel Memahami Async/Await di JavaScript lewat Contoh Sehari-hari.

Batas Pemeriksaan Tipe

Kode di atas lolos kompilasi, tetapi menyimpan celah. respons.json() mengembalikan Promise<any>. TypeScript menerima nilai any sebagai tipe apa pun tanpa memeriksanya. Bila suatu hari API mengganti name menjadi fullName, kompilasi tetap berhasil, tetapi katalog menampilkan undefined.

Ingat juga bahwa semua anotasi tipe dibuang sebelum kode dijalankan. TypeScript hanya memeriksa kode yang Anda tulis, bukan data yang baru datang saat program berjalan. Data dari luar, seperti respons API, masukan pengguna, atau isi localStorage, perlu Anda periksa sendiri.

Memeriksa Data Sebelum Dipakai

Langkah pertama adalah menyimpan hasil json() sebagai unknown. Ganti baris return respons.json(); dengan:

  const data: unknown = await respons.json();

  if (!Array.isArray(data) || !data.every(apakahPengguna)) {
    throw new Error('Format data pengguna tidak sesuai.');
  }

  return data;

Berbeda dengan any, nilai unknown tidak bisa dipakai sebelum diperiksa. Array.isArray() memastikan data berupa array, sedangkan every() menguji setiap isinya dengan fungsi apakahPengguna() yang akan kita tulis berikut ini.

Menulis Type Guard

Tambahkan fungsi berikut di atas ambilPengguna():

function apakahPengguna(nilai: unknown): nilai is Pengguna {
  return (
    typeof nilai === 'object' &&
    nilai !== null &&
    'id' in nilai &&
    typeof nilai.id === 'number' &&
    'name' in nilai &&
    typeof nilai.name === 'string' &&
    'email' in nilai &&
    typeof nilai.email === 'string' &&
    'website' in nilai &&
    typeof nilai.website === 'string'
  );
}

Tipe kembalian nilai is Pengguna menjadikan fungsi ini type guard: bila hasilnya true, TypeScript memperlakukan nilai sebagai Pengguna. Isinya memakai narrowing dari tutorial pertama. Operator in memastikan properti ada, lalu typeof memastikan tipenya.

Menampilkan Katalog

Ganti isi src/main.ts:

import './style.css';
import { ambilPengguna } from './api.ts';

async function tampilkanKatalog(wadah: HTMLDivElement): Promise<void> {
  wadah.textContent = 'Memuat data pengguna...';

  try {
    const judul = document.createElement('h1');
    const daftar = document.createElement('ul');

    judul.textContent = 'Katalog Pengguna';

    for (const pengguna of await ambilPengguna()) {
      const item = document.createElement('li');
      item.textContent = `${pengguna.name} (${pengguna.email})`;
      daftar.append(item);
    }

    wadah.replaceChildren(judul, daftar);
  } catch (galat) {
    wadah.textContent = galat instanceof Error ? galat.message : 'Terjadi galat.';
  }
}

const app = document.querySelector<HTMLDivElement>('#app');

if (app) {
  tampilkanKatalog(app);
}

Properti textContent menampilkan data sebagai teks biasa sehingga isi dari API tidak dijalankan sebagai HTML. Variabel galat di dalam catch bertipe unknown, jadi instanceof Error memastikan message benar-benar ada. Saat npm run dev berjalan, halaman menampilkan judul katalog dan sepuluh nama pengguna.
