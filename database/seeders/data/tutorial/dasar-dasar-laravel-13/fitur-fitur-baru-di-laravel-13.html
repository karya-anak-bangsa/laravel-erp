Laravel 13 dirilis pada 17 Maret 2026 dan melanjutkan jadwal rilis tahunan Laravel. Seri ini mengajak Anda mengenal versi terbaru tersebut sambil menyiapkan dasar aplikasi data buku sederhana, mulai dari instalasi, routing, dan Blade sampai migrasi dan model Eloquent.

Materi pertama ini belum menyentuh kode aplikasi. Kita akan melihat kebutuhan sistem, masa dukungan, dan fitur baru yang membedakan Laravel 13 dari versi sebelumnya. Dengan begitu, Anda tahu alasan memilih versi ini untuk proyek baru.

Kebutuhan Sistem dan Masa Dukungan

Laravel 13 membutuhkan minimal PHP 8.3 dan resmi mendukung PHP 8.3 hingga 8.5. Selain PHP, Anda memerlukan Composer untuk mengelola paket, serta Node.js dan npm untuk membangun aset tampilan lewat Vite. Materi berikutnya membahas cara menyiapkan semuanya.

Setiap rilis utama Laravel mendapat perbaikan bug selama 18 bulan dan perbaikan keamanan selama 2 tahun. Laravel 13 menerima perbaikan bug hingga kuartal ketiga 2027 dan perbaikan keamanan hingga 17 Maret 2028. Rentang ini cukup panjang untuk proyek yang dimulai sekarang.

Tim Laravel juga sengaja menekan perubahan yang merusak kompatibilitas (breaking changes). Sebagian besar aplikasi Laravel 12 bisa naik ke versi 13 tanpa banyak mengubah kode. Banyak fitur baru justru hadir bertahap sepanjang tahun lewat rilis minor yang tidak merusak aplikasi.

Laravel AI SDK

Fitur yang paling menonjol adalah Laravel AI SDK, software development kit (SDK) resmi untuk membangun fitur kecerdasan buatan. Satu API yang seragam melayani pembuatan teks, agen yang bisa memanggil fungsi aplikasi, embedding, audio, gambar, dan penyimpanan vektor. Anda bebas berganti penyedia model AI tanpa menulis ulang kode aplikasi.

use App\Ai\Agents\AsistenPenjualan;

$jawaban = AsistenPenjualan::make()->prompt('Ringkas transkrip percakapan penjualan ini...');

return (string) $jawaban;

Kelas AsistenPenjualan pada contoh di atas adalah agen buatan Anda sendiri. Pustaka yang sama juga bisa menghasilkan gambar lewat Image::of(...), suara lewat Audio::of(...), dan embedding langsung dari teks lewat Str::of(...)->toEmbeddings().

JSON:API Resources dan Pencarian Vektor

Laravel 13 kini membawa JSON:API resources bawaan. Fitur ini menghasilkan respons yang mengikuti spesifikasi JSON:API, termasuk relasi, pemilihan kolom (sparse fieldsets), tautan, dan header yang sesuai. Anda tidak perlu lagi memasang paket pihak ketiga demi API berformat standar.

Laravel juga memperdalam dukungan pencarian semantik. Query builder kini memiliki klausa kemiripan vektor sehingga Anda bisa mencari dokumen yang maknanya mirip, bukan sekadar yang kata-katanya sama. Fitur ini memakai PostgreSQL dengan ekstensi pgvector.

$dokumen = DB::table('dokumen')
    ->whereVectorSimilarTo('embedding', 'Kebun teh terbaik di Jawa Barat')
    ->limit(10)
    ->get();

Atribut PHP di Lebih Banyak Tempat

Atribut PHP memungkinkan pengaturan ditulis tepat di atas kelas atau method yang diaturnya. Laravel 13 memperluas pemakaiannya. Di controller, ada #[Middleware] untuk memasang middleware dan #[Authorize] untuk memeriksa izin. Di job antrean, ada #[Tries], #[Backoff], #[Timeout], dan #[FailOnTimeout].

use Illuminate\Routing\Attributes\Controllers\Middleware;

#[Middleware('auth')]
class LaporanController extends Controller
{
    #[Middleware('verified')]
    public function unduh()
    {
        // ...
    }
}

Model Eloquent pun bisa diatur dengan atribut, misalnya #[Table] untuk nama tabel dan #[Fillable] untuk kolom yang boleh diisi. Cara lama lewat properti kelas tetap berlaku, jadi Anda bebas memilih. Seri ini memakai kedua atribut tersebut di materi keempat.

Perbaikan Kecil yang Terasa

  • Rute antrean per kelas. Queue::route(...) menentukan koneksi dan antrean bawaan sebuah job di satu tempat, misalnya Queue::route(KirimFaktur::class, connection: 'redis', queue: 'faktur').

  • Memperpanjang cache. Cache::touch('kunci', 3600) memperpanjang umur data cache tanpa harus membaca lalu menyimpannya ulang.

  • Perlindungan pemalsuan permintaan. Middleware pelindung Cross-Site Request Forgery (CSRF) kini bernama PreventRequestForgery dan ikut memeriksa asal permintaan (origin), tetapi tetap kompatibel dengan token CSRF yang sudah ada.

Yang Akan Kita Bangun

Fitur AI dan pencarian vektor memang menarik, tetapi seri ini berfokus pada dasar yang dipakai hampir semua aplikasi. Kita akan membangun aplikasi perpustakaan kecil berisi tabel buku dengan kolom judul, penulis, dan tahun terbit. Setiap materi menambah satu bagian:

  • Materi 2 memasang Laravel 13 dan menghubungkannya ke MySQL.

  • Materi 3 membuat rute, controller, dan tampilan Blade pertama.

  • Materi 4 membuat tabel buku lewat migrasi beserta model Eloquent-nya.

Tutorial lanjutannya, "Membangun CRUD dengan Laravel 13", memakai proyek yang sama untuk menampilkan, menambah, mengubah, dan menghapus data buku.

Siapkan pemahaman dasar PHP dan HTML. Anda tidak perlu pernah memakai Laravel sebelumnya karena setiap langkah dijelaskan dari awal.
