Pada materi pertama, kita sudah mengenal fitur baru Laravel 13. Sekarang saatnya memasang Laravel di komputer dan menyiapkan proyek perpustakaan yang akan kita kembangkan sampai tutorial lanjutannya.

Contoh di seri ini memakai Laragon di Windows karena PHP, MySQL, Composer, dan Node.js sudah tersedia dalam satu paket. Pengguna macOS atau Linux tetap bisa mengikuti langkahnya asalkan versi PHP dan MySQL-nya sesuai.

Memeriksa Kebutuhan

Buka terminal Laragon lewat Menu > Laragon > Terminal, lalu periksa versi setiap alat:

php -v
composer -V
node -v

PHP harus menunjukkan versi 8.3 atau lebih baru. Jika versinya lebih lama, Composer akan memasang Laravel versi sebelumnya tanpa peringatan yang jelas. Panduan mengganti versi PHP di Laragon ada di artikel Cara Install Laravel 13 di Windows dengan Laragon.

Membuat Proyek Baru

Pindah ke folder kerja Laragon, lalu buat proyek bernama perpustakaan dengan Composer:

cd C:\laragon\www
composer create-project laravel/laravel perpustakaan

Composer mengunduh Laravel beserta semua dependensinya ke folder perpustakaan. Prosesnya memakan waktu beberapa menit, tergantung kecepatan internet. Setelah selesai, masuk ke folder proyek dan pastikan versinya benar:

cd perpustakaan
php artisan --version

Hasilnya harus berawalan Laravel Framework 13. Klik Reload di Laragon agar aplikasi itu membuat alamat http://perpustakaan.test yang mengarah ke folder public proyek.

Mengenal Struktur Folder

Proyek Laravel berisi banyak folder, tetapi seri ini hanya memakai beberapa di antaranya:

  • app/Http/Controllers berisi controller yang menerima permintaan dari peramban.

  • app/Models berisi model Eloquent yang mewakili tabel basis data di kode PHP.

  • database/migrations berisi migrasi, yaitu riwayat perubahan struktur tabel.

  • resources/views berisi templat Blade untuk tampilan.

  • routes/web.php berisi daftar rute, yaitu alamat yang bisa dibuka beserta kode yang menanganinya.

Mengatur Berkas .env

Pengaturan yang berbeda di setiap komputer disimpan di berkas .env. Proyek Laravel baru memakai SQLite secara bawaan, sedangkan seri ini memakai MySQL. Buka .env, hapus tanda # di depan baris DB_, lalu sesuaikan isinya:

APP_NAME=Perpustakaan
APP_URL=http://perpustakaan.test

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=perpustakaan
DB_USERNAME=root
DB_PASSWORD=

Akun bawaan MySQL Laragon adalah root tanpa password, jadi DB_PASSWORD dibiarkan kosong. Biarkan juga APP_DEBUG=true selama pengembangan agar galat tampil lengkap beserta letaknya. Di server produksi, nilai itu wajib false agar detail kode tidak terlihat oleh pengunjung.

Berkas .env menyimpan kredensial, jadi jangan pernah mengunggahnya ke repositori Git. Laravel sudah mencantumkannya di .gitignore. Rekan satu tim cukup menyalin .env.example menjadi .env, lalu mengisi nilainya sendiri.

Menjalankan Migrasi Bawaan

Laravel membawa beberapa migrasi bawaan untuk tabel pengguna, sesi, cache, dan antrean. Jalankan perintah berikut:

php artisan migrate

Jika basis data perpustakaan belum ada, Laravel menawarkan untuk membuatnya. Jawab yes agar migrasi berlanjut. Galat SQLSTATE[HY000] [1045] Access denied berarti nama pengguna atau password di .env tidak cocok. Jika perubahan .env tidak terbaca, jalankan php artisan config:clear.

Membuka Aplikasi di Peramban

Pasang dependensi frontend, lalu bangun asetnya:

npm install
npm run build

Buka http://perpustakaan.test di peramban. Halaman sambutan Laravel akan tampil. Bila tidak memakai Laragon, jalankan php artisan serve, lalu buka http://127.0.0.1:8000.

Saat aktif menulis kode, biarkan npm run dev tetap berjalan agar perubahan CSS dan JavaScript langsung terlihat. Perintah composer run dev menyalakan server PHP, antrean, dan Vite sekaligus bila Anda lebih suka satu perintah saja.

Proyek kini siap. Pada materi berikutnya, kita akan membuat rute, controller, dan halaman Blade pertama untuk daftar buku.
