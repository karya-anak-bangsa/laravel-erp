Data aplikasi seharusnya tersimpan di basis data, bukan tertulis di kode. Materi ini membuat tabel buku di MySQL dengan migrasi, lalu menghubungkannya ke kode PHP lewat model Eloquent.

Apa Itu Migrasi

Migrasi adalah berkas PHP yang mencatat perubahan struktur tabel. Alih-alih membuat tabel lewat phpMyAdmin atau HeidiSQL, Anda menuliskannya di kode. Riwayat perubahannya ikut tersimpan di Git. Rekan satu tim cukup menjalankan satu perintah untuk mendapatkan struktur basis data yang sama.

Membuat Tabel Buku

Buat migrasi baru dengan Artisan:

php artisan make:migration create_buku_table

Laravel membaca nama migrasi dan menebak bahwa kita ingin membuat tabel buku. Buka berkas baru di database/migrations, lalu lengkapi isi method up():

public function up(): void
{
    Schema::create('buku', function (Blueprint $table) {
        $table->id();
        $table->string('judul', 200);
        $table->string('penulis', 100);
        $table->unsignedSmallInteger('tahun_terbit');
        $table->timestamps();
    });
}

id() membuat kolom kunci primer yang bertambah otomatis, sedangkan timestamps() membuat kolom created_at dan updated_at yang diisi Laravel saat data dibuat dan diubah. Tahun terbit memakai unsignedSmallInteger karena nilainya selalu berupa bilangan bulat positif yang kecil.

Method down() berisi kebalikannya, yaitu Schema::dropIfExists('buku'). Laravel menjalankannya saat Anda membatalkan migrasi. Sekarang jalankan migrasinya:

php artisan migrate

Tabel buku kini ada di basis data perpustakaan. Bila ada kolom yang salah, jalankan php artisan migrate:rollback untuk membatalkan migrasi terakhir, perbaiki berkasnya, lalu jalankan php artisan migrate lagi. Setelah tabelnya berisi data sungguhan, jangan mengubah migrasi lama. Buat migrasi baru untuk setiap perubahan, seperti yang akan kita lakukan di tutorial lanjutan saat menambahkan fitur hapus.

Membuat Model Eloquent

Eloquent adalah Object-Relational Mapping (ORM) bawaan Laravel. Setiap tabel diwakili satu kelas model sehingga Anda bisa membaca dan menulis data tanpa menyusun SQL sendiri. Buat modelnya:

php artisan make:model Buku

Ada satu hal yang perlu diperhatikan. Laravel menebak nama tabel dari bentuk jamak bahasa Inggris nama modelnya. Akibatnya, model Buku dianggap memakai tabel bukus, padahal tabel kita bernama buku.

Laravel 13 menyediakan atribut #[Table] untuk menyebut nama tabel secara langsung. Sekalian, tentukan kolom yang boleh diisi lewat #[Fillable]. Ubah isi app/Models/Buku.php menjadi seperti berikut:

<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Attributes\Fillable;
use Illuminate\Database\Eloquent\Attributes\Table;
use Illuminate\Database\Eloquent\Model;

#[Table('buku')]
#[Fillable(['judul', 'penulis', 'tahun_terbit'])]
class Buku extends Model
{
}

Kedua atribut ini sama dengan menulis properti protected $table = 'buku'; dan protected $fillable = [...]; di dalam kelas, cara yang tetap berlaku di Laravel 13. Daftar kolom di #[Fillable] melindungi aplikasi dari pengisian massal (mass assignment): kolom di luar daftar, misalnya id, diabaikan meskipun ikut terkirim dari formulir.

Mencoba Eloquent lewat Tinker

Tinker adalah konsol interaktif untuk menjalankan kode PHP di dalam aplikasi. Buka dengan php artisan tinker, lalu tambahkan tiga buku:

App\Models\Buku::create(['judul' => 'Laskar Pelangi', 'penulis' => 'Andrea Hirata', 'tahun_terbit' => 2005]);
App\Models\Buku::create(['judul' => 'Bumi Manusia', 'penulis' => 'Pramoedya Ananta Toer', 'tahun_terbit' => 1980]);
App\Models\Buku::create(['judul' => 'Ronggeng Dukuh Paruk', 'penulis' => 'Ahmad Tohari', 'tahun_terbit' => 1982]);

Setiap create() menyimpan satu baris dan mengembalikan model yang baru dibuat, lengkap dengan id dan waktu pembuatannya. Coba juga beberapa perintah baca berikut:

App\Models\Buku::count();
App\Models\Buku::find(1);
App\Models\Buku::where('tahun_terbit', '<', 2000)->pluck('judul');

Perintah pertama menghitung jumlah buku, perintah kedua mengambil buku ber-id 1, dan perintah ketiga mengambil judul buku yang terbit sebelum tahun 2000. Eloquent menyusun SQL-nya untuk Anda. Ketik exit untuk keluar dari Tinker.

Bila tabel buku kelak berisi ribuan baris dan pencarian per kolom mulai terasa lambat, baca juga artikel Mengenal Indeks di MySQL agar Query Tidak Lambat.

Tabel dan model sudah siap, begitu pula dasar aplikasi perpustakaan kita. Lanjutkan ke tutorial Membangun CRUD dengan Laravel 13 untuk mengganti daftar judul yang ditulis langsung di controller dengan data asli dari tabel buku, lalu menambah, mengubah, dan menghapusnya.
