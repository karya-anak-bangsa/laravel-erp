Tipe objek yang ditulis langsung pada variabel cepat menjadi panjang dan harus diulang setiap kali dipakai. TypeScript menyediakan dua cara untuk memberi nama pada sebuah tipe, yaitu interface dan type alias. Materi ini memakai contoh data produk toko daring di berkas baru src/produk.ts.

Mendefinisikan Interface

Interface mendeskripsikan bentuk sebuah objek, yaitu properti apa saja yang dimilikinya beserta tipenya:

interface Produk {
  readonly id: number;
  nama: string;
  harga: number;
  stok?: number;
}

const kaus: Produk = { id: 1, nama: 'Kaus Polos', harga: 75000 };
const topi: Produk = { id: 2, nama: 'Topi Rajut', harga: 50000, stok: 8 };

Nama interface lazim diawali huruf kapital. Properti stok bersifat opsional, sedangkan readonly pada id membuatnya tidak bisa diubah setelah objek dibuat.

Kesalahan yang Langsung Tertangkap

Coba tambahkan tiga baris yang salah berikut:

const tas: Produk = { id: 3, nama: 'Tas Kanvas' };
const sepatu: Produk = { id: 4, nama: 'Sepatu Kets', harga: 250000, warna: 'hitam' };
kaus.id = 10;

TypeScript menolak ketiganya. Baris pertama tidak memiliki harga yang wajib ada. Baris kedua memuat properti warna yang tidak dikenal Produk. Baris ketiga mengubah id yang bersifat readonly. Perlu dicatat, readonly hanya dijaga saat kompilasi; JavaScript hasil kompilasinya tetap bisa mengubah nilai itu. Hapus ketiga baris tersebut sebelum melanjutkan.

Memakai Interface pada Fungsi

Setelah didefinisikan, interface bisa dipakai sebagai tipe parameter fungsi:

function formatProduk(produk: Produk): string {
  return `${produk.nama} - Rp${produk.harga}`;
}

console.log(formatProduk(kaus)); // Kaus Polos - Rp75000

Di dalam fungsi, editor langsung menyarankan nama, harga, dan properti lain milik Produk. Interface juga bisa diperluas dengan extends untuk membuat tipe yang lebih khusus:

interface ProdukDigital extends Produk {
  ukuranBerkasMb: number;
}

const panduan: ProdukDigital = { id: 5, nama: 'Panduan TypeScript', harga: 90000, ukuranBerkasMb: 4 };
console.log(formatProduk(panduan)); // Panduan TypeScript - Rp90000

Tipe ProdukDigital memiliki semua properti Produk ditambah ukuranBerkasMb. Objek panduan tetap bisa dikirim ke formatProduk() karena bentuknya mencakup semua yang dibutuhkan Produk.

Memberi Nama Tipe dengan Type Alias

Type alias ditulis dengan kata kunci type dan bisa memberi nama pada tipe apa pun, bukan hanya objek:

type Rupiah = number;

type ItemKeranjang = {
  produk: Produk;
  jumlah: number;
};

function hitungSubtotal(item: ItemKeranjang): Rupiah {
  return item.produk.harga * item.jumlah;
}

const keranjang: ItemKeranjang[] = [
  { produk: kaus, jumlah: 2 },
  { produk: topi, jumlah: 1 },
];

for (const item of keranjang) {
  console.log(`${item.produk.nama}: Rp${hitungSubtotal(item)}`);
}

Tipe Rupiah tetap berupa number, tetapi namanya menjelaskan makna nilainya. Type alias juga bisa menggabungkan beberapa tipe dengan operator &, misalnya type ProdukDiskon = Produk & { persenDiskon: number }.

Memilih Interface atau Type Alias

Keduanya hampir selalu bisa saling menggantikan saat mendeskripsikan bentuk objek. Pegangan sederhana berikut banyak dipakai tim pengembang:

  • Pakai interface untuk bentuk objek, terutama yang akan diperluas dengan extends.

  • Pakai type alias untuk tipe yang bukan objek biasa, seperti gabungan beberapa tipe, tuple, atau nama lain bagi tipe primitif.

Apa pun pilihannya, pakailah secara konsisten dalam satu proyek. Pada materi berikutnya, kita akan memberi tipe pada fungsi secara lebih lengkap serta mengenal union type dan narrowing.
