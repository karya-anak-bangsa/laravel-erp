Pada materi sebelumnya, kita memberi anotasi number pada parameter fungsi hitungTotal(). Materi ini membahas tipe-tipe dasar yang paling sering dipakai, kapan anotasi perlu ditulis, dan kapan TypeScript bisa menyimpulkan tipenya sendiri.

Anotasi Tipe pada Variabel

Anotasi ditulis dengan titik dua setelah nama variabel, diikuti nama tipenya:

let namaProduk: string = 'Kaus Polos';
let harga: number = 75000;
let tersedia: boolean = true;

harga = 'tujuh puluh lima ribu'; // galat

Tipe string menampung teks, number menampung semua jenis angka, baik bilangan bulat maupun pecahan, dan boolean menampung nilai true atau false. TypeScript menolak baris terakhir dengan pesan Type 'string' is not assignable to type 'number' karena harga sudah ditetapkan sebagai angka.

Inferensi Tipe

Anotasi tidak selalu perlu ditulis. Bila variabel langsung diberi nilai awal, TypeScript menyimpulkan tipenya sendiri. Kemampuan ini disebut inferensi tipe (type inference):

let jumlah = 3;
const kategori = 'pakaian';

jumlah = 'tiga'; // galat

Arahkan penunjuk mouse ke nama variabel di VS Code untuk melihat hasil inferensinya. Variabel jumlah bertipe number, sedangkan kategori bertipe 'pakaian', yaitu tipe literal yang hanya menerima teks itu. Nilai const tidak bisa diganti sehingga TypeScript memakai tipe yang paling sempit. Perbedaan kedua kata kunci ini dibahas di artikel Perbedaan var, let, dan const di JavaScript dan Kapan Memakainya.

Dalam praktik, tulis anotasi pada parameter fungsi dan biarkan inferensi bekerja pada variabel yang langsung diberi nilai.

Array dan Tuple

Tipe array ditulis dengan tanda [] setelah tipe isinya. Bentuk lain yang setara adalah Array<string>:

const daftarHarga: number[] = [75000, 120000, 45000];
const daftarUkuran: Array<string> = ['S', 'M', 'L'];
const stokUkuran: [string, number] = ['M', 12];

daftarHarga.push('gratis'); // galat

Variabel daftarHarga hanya boleh berisi angka sehingga push('gratis') ditolak. Adapun stokUkuran adalah tuple, yaitu array yang jumlah isinya tetap dan tipe setiap posisinya sudah ditentukan: posisi pertama teks, posisi kedua angka.

Tipe Objek

Bentuk objek juga bisa dituliskan langsung sebagai anotasi. Tanda ? setelah nama properti berarti properti itu boleh tidak ada:

const kaus: { nama: string; harga: number; diskon?: number } = {
  nama: 'Kaus Polos',
  harga: 75000,
};

console.log(kaus.warna); // galat

TypeScript menolak kaus.warna karena properti itu tidak ada pada tipenya. Salah ketik nama properti, yang di JavaScript hanya menghasilkan undefined, kini langsung ketahuan.

Tipe yang Perlu Diwaspadai

TypeScript juga memiliki beberapa tipe khusus yang perlu dipahami sejak awal:

let bebas: any = 'teks';
bebas.toFixed(2); // lolos kompilasi, tetapi gagal saat berjalan

let masukan: unknown = 'teks';
masukan.toUpperCase(); // galat

if (typeof masukan === 'string') {
  console.log(masukan.toUpperCase());
}

let catatan: string = null; // galat

  • Tipe any mematikan pemeriksaan tipe sepenuhnya: bebas.toFixed(2) lolos kompilasi, tetapi menghentikan program dengan TypeError saat dijalankan. Hindari tipe ini karena manfaat TypeScript ikut hilang.

  • Tipe unknown juga menerima nilai apa saja, tetapi wajib diperiksa dulu sebelum dipakai. Pemeriksaan dengan typeof seperti di atas dibahas lebih dalam pada materi keempat.

  • Nilai null dan undefined tidak bisa diberikan ke tipe lain saat strict aktif. Variabel yang boleh kosong diberi tipe gabungan, misalnya string | null.

Pada materi berikutnya, kita akan merapikan tipe objek yang panjang dengan interface dan type alias agar bisa dipakai ulang.
