TypeScript adalah bahasa pemrograman sumber terbuka buatan Microsoft yang menambahkan sistem tipe ke JavaScript. Kode JavaScript yang sah juga sah secara sintaksis di TypeScript sehingga Anda bisa mempelajarinya sedikit demi sedikit di atas pengetahuan JavaScript yang sudah Anda miliki.

Materi ini menjelaskan manfaat pemeriksaan tipe, cara memasang TypeScript di proyek, dan cara mengompilasi berkas .ts pertama menjadi .js.

Mengapa Tipe Itu Penting

Perhatikan fungsi JavaScript berikut. Fungsi ini menjumlahkan harga barang dan ongkos kirim:

function hitungTotal(harga, ongkir) {
  return harga + ongkir;
}

console.log(hitungTotal('50000', 10000)); // 5000010000

Harga dikirim sebagai string sehingga operator + menyambung teks, bukan menjumlahkan angka. JavaScript tidak menganggapnya salah. Galat seperti ini baru ketahuan saat program berjalan, bahkan bisa jadi pengguna yang pertama kali menemukannya.

TypeScript menangkap kesalahan itu sebelum program dijalankan. Selain itu, ada beberapa manfaat lain:

  • Editor seperti VS Code bisa menyarankan nama properti dan method dengan tepat karena mengetahui tipe setiap variabel.

  • Saat Anda mengganti nama atau bentuk data, kompilator menunjukkan semua bagian kode yang terdampak.

  • Tipe berfungsi sebagai dokumentasi yang selalu sesuai dengan kode.

Peramban hanya memahami JavaScript. Oleh karena itu, kompilator TypeScript yang bernama tsc mengubah kode TypeScript menjadi JavaScript biasa sebelum dijalankan. Bila Anda masih menimbang perlu tidaknya beralih, baca artikel Mengenal TypeScript: Kapan Proyek JavaScript Perlu Beralih?

Memasang TypeScript di Proyek

Pastikan Node.js sudah terpasang; npm ikut terpasang bersamanya. Buka terminal, lalu buat folder proyek baru:

mkdir belajar-typescript
cd belajar-typescript
npm init -y
npm install -D typescript
npx tsc --version

Perintah npm init -y membuat berkas package.json. Opsi -D mencatat TypeScript sebagai devDependencies, yaitu paket yang hanya dibutuhkan selama pengembangan. Perintah npx tsc menjalankan kompilator yang terpasang di folder node_modules proyek ini sehingga setiap proyek bisa memakai versi TypeScript yang berbeda. Perintah terakhir menampilkan nomor versi bila pemasangan berhasil.

Menyiapkan Pengaturan Kompilator

Buat berkas tsconfig.json di folder proyek. Berkas ini memberi tahu tsc letak kode sumber, tempat hasil kompilasi, dan seberapa ketat pemeriksaan tipenya:

{
  "compilerOptions": {
    "target": "es2022",
    "module": "nodenext",
    "strict": true,
    "moduleDetection": "force",
    "rootDir": "src",
    "outDir": "dist"
  },
  "include": ["src"]
}

Opsi target menentukan versi JavaScript hasil kompilasi, sedangkan module bernilai nodenext mengikuti aturan modul Node.js. Opsi strict mengaktifkan pemeriksaan ketat yang sangat dianjurkan untuk proyek baru. Opsi moduleDetection bernilai force membuat setiap berkas berdiri sendiri sehingga nama variabel di berkas yang berbeda tidak saling bentrok. Opsi rootDir dan outDir menetapkan kode sumber di folder src dan hasil kompilasi di folder dist.

Perintah npx tsc --init juga bisa membuat tsconfig.json secara otomatis. Namun, isinya jauh lebih panjang dan berbeda antarversi, jadi kita memakai versi ringkas di atas.

Mengompilasi Berkas Pertama

Buat folder src, lalu tulis berkas src/halo.ts:

function hitungTotal(harga: number, ongkir: number): number {
  return harga + ongkir;
}

const total = hitungTotal(50000, 10000);
console.log(`Total belanja: Rp${total}`);

Tulisan : number setelah parameter dan setelah tanda kurung tutup adalah anotasi tipe. Artinya, harga dan ongkir wajib berupa angka, begitu pula nilai yang dikembalikan fungsi. Kompilasi berkas itu, lalu jalankan hasilnya:

npx tsc
node dist/halo.js

Terminal menampilkan Total belanja: Rp60000. Buka dist/halo.js: isinya JavaScript biasa tanpa anotasi tipe, ditambah beberapa baris dari pengaturan modul yang bisa Anda abaikan.

Membaca Pesan Galat

Ubah pemanggilan fungsi menjadi hitungTotal('50000', 10000), lalu jalankan npx tsc lagi. Kompilator melaporkan galat dengan pesan kurang lebih seperti ini:

src/halo.ts:5:27 - error TS2345: Argument of type 'string' is not assignable to parameter of type 'number'.

Pesan itu menyebut lokasi galat (berkas, baris 5, kolom 27), kode galatnya, dan penjelasannya: argumen bertipe string tidak boleh diberikan ke parameter bertipe number. VS Code menampilkan galat yang sama sebagai garis bawah merah tanpa perlu menjalankan tsc.

Perlu diingat, tsc tetap menulis dist/halo.js meskipun ada galat. Bila Anda ingin tsc tidak menulis berkas apa pun saat ada galat, tambahkan "noEmitOnError": true di dalam compilerOptions. Setelah mencoba, kembalikan argumennya menjadi angka agar kompilasi bersih.

TypeScript sudah terpasang dan siap dipakai. Pada materi berikutnya, kita akan mengenal tipe-tipe dasar TypeScript dan cara menuliskan anotasi tipe.
