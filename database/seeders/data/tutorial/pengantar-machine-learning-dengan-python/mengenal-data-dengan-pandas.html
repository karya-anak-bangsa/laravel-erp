Sebelum melatih model, kita perlu mengenal datanya lebih dulu: berapa banyak barisnya, apa saja kolomnya, dan apakah ada nilai yang kosong. Materi ini memakai pandas, pustaka Python yang paling populer untuk mengolah data berbentuk tabel.

Contohnya adalah dataset iris yang sudah disinggung di materi pertama. Dataset ini berisi ukuran 150 bunga iris dari tiga jenis, yaitu setosa, versicolor, dan virginica.

Memuat Dataset Iris

Buat notebook baru di folder belajar-ml, lalu jalankan kode berikut:

import pandas as pd
from sklearn.datasets import load_iris

iris = load_iris(as_frame=True)
data = iris.frame
data.head()

Argumen as_frame=True membuat scikit-learn mengembalikan data sebagai DataFrame, yaitu tabel milik pandas. Atribut frame berisi empat kolom ukuran bunga dan kolom target yang mencatat jenisnya sebagai angka 0, 1, atau 2. head() menampilkan lima baris pertama. Di Jupyter, nilai pada baris terakhir sel otomatis ditampilkan tanpa print().

Data milik Anda sendiri biasanya tersimpan sebagai berkas Comma-Separated Values (CSV) atau Excel. Muat berkas seperti itu dengan pd.read_csv("penjualan.csv") atau pd.read_excel("penjualan.xlsx") yang memerlukan pustaka openpyxl; hasilnya sama-sama DataFrame. Pengolahan berkas Excel dibahas lebih lengkap di artikel Mengolah Data Excel dengan Python dan pandas untuk Pekerjaan Kantor.

Merapikan Nama Kolom

Nama kolom bawaannya berbahasa Inggris dan memuat spasi, misalnya petal length (cm). Ganti dengan nama yang lebih ringkas, lalu tambahkan kolom berisi nama jenis bunga:

data = data.rename(columns={
    "sepal length (cm)": "panjang_kelopak",
    "sepal width (cm)": "lebar_kelopak",
    "petal length (cm)": "panjang_mahkota",
    "petal width (cm)": "lebar_mahkota",
})
data["jenis"] = data["target"].map({0: "setosa", 1: "versicolor", 2: "virginica"})

rename() mengembalikan DataFrame baru sehingga hasilnya perlu disimpan kembali ke data. map() menerjemahkan setiap angka di kolom target menjadi nama jenis yang mudah dibaca.

Membaca Ringkasan Data

Dua method berikut memberikan gambaran umum isi tabel:

data.info()
data.describe().round(2)

info() menunjukkan jumlah baris, jumlah nilai yang terisi (Non-Null Count), dan tipe data setiap kolom. Keempat ukuran bunga bertipe float64 atau bilangan desimal, target bertipe int64 atau bilangan bulat, sedangkan jenis bertipe teks. describe() menghitung statistik setiap kolom angka:

Baris mean adalah rata-rata, std simpangan baku, dan 50% median. Panjang mahkota berkisar antara 1 dan 6,9 cm dengan sebaran yang lebar. Statistik kolom target tidak bermakna karena angkanya hanya kode jenis.

Menghitung Kategori dengan value_counts()

Kolom kategori seperti jenis paling mudah diperiksa dengan menghitung jumlah setiap nilainya:

data["jenis"].value_counts()

Hasilnya menunjukkan 50 bunga untuk setiap jenis sehingga datanya seimbang. Pada data nyata, satu kategori sering jauh lebih banyak daripada yang lain. Kita juga bisa membandingkan rata-rata ukuran setiap jenis:

data.groupby("jenis")[["panjang_mahkota", "lebar_mahkota"]].mean()

Rata-rata panjang mahkota setosa sekitar 1,5 cm, versicolor 4,3 cm, dan virginica 5,6 cm. Perbedaan sebesar ini menandakan bahwa ukuran mahkota akan menjadi fitur yang kuat untuk membedakan jenis bunga.

Memeriksa Nilai Kosong

Gabungan isna() dan sum() menghitung jumlah sel kosong di setiap kolom:

data.isna().sum()

Hasilnya nol di setiap kolom karena dataset iris sudah bersih. Data nyata hampir selalu memiliki sel kosong, misalnya dari formulir yang tidak diisi lengkap. Banyak model scikit-learn menolak data yang berisi nilai kosong. Oleh karena itu, buang baris tersebut dengan dropna() atau isi sel kosongnya, misalnya dengan median kolomnya: data["panjang_mahkota"].fillna(data["panjang_mahkota"].median()). Membuang baris memang paling mudah, tetapi bisa menghilangkan banyak data bila sel kosongnya tersebar.

Kini kita tahu isi dataset iris: 150 baris, empat fitur ukuran, satu label jenis, dan tanpa nilai kosong. Pada materi berikutnya, kita akan memisahkan fitur dan label, lalu membagi data menjadi data latih dan data uji.
