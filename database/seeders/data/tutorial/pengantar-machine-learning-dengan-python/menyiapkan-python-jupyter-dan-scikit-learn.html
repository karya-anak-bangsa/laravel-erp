Materi sebelumnya membahas konsep machine learning tanpa menjalankan kode. Sekarang kita menyiapkan lingkungan kerjanya, yaitu Python, lingkungan virtual, pustaka pandas dan scikit-learn, serta JupyterLab untuk menulis kode secara interaktif.

Memeriksa Python

Buka terminal, yaitu PowerShell di Windows atau aplikasi Terminal di macOS dan Linux, lalu periksa versi Python:

python --version

Di macOS dan Linux, perintahnya sering bernama python3. Jika Python belum terpasang, ikuti panduan di artikel Belajar Python dari Nol: Instalasi, Virtual Environment, dan Program Pertama. Bila pemasangan pustaka nanti gagal pada versi Python yang baru saja dirilis, pakai satu versi sebelumnya.

Membuat Lingkungan Virtual

Setiap proyek sebaiknya memiliki lingkungan virtual (virtual environment) sendiri, yaitu folder berisi Python beserta pustaka khusus proyek itu. Dengan begitu, versi pustaka di satu proyek tidak bentrok dengan proyek lain. Buat folder proyek dan lingkungan virtualnya:

mkdir belajar-ml
cd belajar-ml
python -m venv .venv

Modul venv membuat folder .venv di dalam proyek. Di macOS dan Linux, ganti python dengan python3 pada perintah terakhir. Aktifkan lingkungan tersebut sesuai sistem operasi Anda:

# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# macOS dan Linux
source .venv/bin/activate

Tulisan (.venv) akan muncul di awal baris terminal sebagai tanda lingkungan sudah aktif. Setelah itu, perintah python juga berlaku di macOS dan Linux. Jika PowerShell menolak menjalankan skrip aktivasi, jalankan Set-ExecutionPolicy RemoteSigned -Scope CurrentUser sekali, lalu ulangi aktivasinya. Perintah deactivate menonaktifkan lingkungan virtual.

Memasang Pustaka dengan pip

Selama lingkungan virtual aktif, pustaka yang dipasang dengan pip hanya masuk ke folder .venv:

python -m pip install --upgrade pip
python -m pip install pandas scikit-learn jupyterlab

Perintah pertama memperbarui pip. Perintah kedua memasang tiga pustaka utama seri ini beserta dependensinya, termasuk NumPy untuk perhitungan angka dan joblib yang kelak dipakai untuk menyimpan model. Bentuk python -m pip memastikan pip yang dipakai berasal dari Python di lingkungan yang sedang aktif.

Simpan daftar pustaka beserta versinya agar proyek mudah dipasang ulang di komputer lain:

python -m pip freeze > requirements.txt

Rekan Anda cukup membuat lingkungan virtualnya sendiri, lalu menjalankan python -m pip install -r requirements.txt.

Menjalankan JupyterLab

JupyterLab adalah editor berbasis peramban untuk menulis notebook, yaitu berkas berekstensi .ipynb yang berisi sel-sel kode beserta hasilnya. Format ini cocok untuk machine learning karena data bisa diperiksa sedikit demi sedikit. Jalankan perintah berikut dari terminal yang lingkungan virtualnya aktif:

jupyter lab

Peramban akan membuka JupyterLab secara otomatis. Di halaman Launcher, klik Python 3 (ipykernel) untuk membuat notebook baru. Ketik kode di sebuah sel, lalu tekan Shift+Enter untuk menjalankannya. Hentikan JupyterLab dengan menekan Ctrl+C dua kali di terminal.

VS Code dengan ekstensi Jupyter juga bisa membuka notebook; pilih Python dari folder .venv sebagai kernel. Google Colab bahkan berjalan di peramban tanpa pemasangan apa pun. Pustaka pandas dan scikit-learn pun sudah tersedia di sana.

Memeriksa Versi Pustaka

Ketik kode berikut di sel pertama notebook:

import sys

import pandas as pd
import sklearn

print(sys.version)
print(pd.__version__)
print(sklearn.__version__)

Ketiga baris print() menampilkan versi Python, pandas, dan scikit-learn. Perhatikan bahwa pustakanya dipasang dengan nama scikit-learn, tetapi diimpor sebagai sklearn. Singkatan pd untuk pandas adalah kebiasaan umum yang juga dipakai dokumentasi resminya.

Galat ModuleNotFoundError berarti notebook tidak memakai Python dari lingkungan virtual. Tutup JupyterLab, aktifkan kembali .venv, lalu jalankan jupyter lab lagi. Rincian lengkap tentang pustaka dan sistem Anda bisa dilihat dengan sklearn.show_versions().

Lingkungan kerja sudah siap. Pada materi berikutnya, kita akan memuat dataset pertama dan mengenal isinya dengan pandas.
