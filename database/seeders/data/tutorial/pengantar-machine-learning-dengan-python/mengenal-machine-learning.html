Aplikasi rekomendasi film, filter email spam, dan fitur pengenal wajah di ponsel bekerja dengan cara yang mirip: komputer menemukan pola dari banyak contoh, bukan dari aturan yang ditulis satu per satu oleh pemrogram. Pendekatan inilah yang disebut machine learning.

Seri ini mengajak Anda mengenal dasar-dasar machine learning dengan Python dan scikit-learn. Materi pertama membahas konsepnya dengan sedikit kode: perbedaan belajar dari data dengan menulis aturan, jenis-jenis machine learning, dan alur kerja sebuah proyek.

Apa Itu Machine Learning

Machine learning adalah cabang kecerdasan buatan yang membuat komputer mampu belajar dari data. Hasil belajarnya disebut model, yaitu fungsi yang menerima data baru dan mengeluarkan prediksi. Model bisa menebak harga rumah dari luas dan lokasinya atau menebak jenis bunga dari ukuran mahkotanya. Semakin banyak dan semakin baik contoh datanya, semakin tepat pula tebakannya.

Belajar dari Data, Bukan dari Aturan Tertulis

Bayangkan Anda diminta menebak jenis bunga iris dari panjang mahkota bunganya. Cara pemrograman biasa adalah menulis aturannya sendiri:

def tebak_jenis(panjang_mahkota):
    if panjang_mahkota < 2.5:
        return "setosa"
    if panjang_mahkota < 5.0:
        return "versicolor"
    return "virginica"

Aturan ini bekerja selama Anda tahu batas angkanya. Masalahnya, batas yang tepat sering tidak diketahui, apalagi bila ada puluhan ukuran yang harus dipertimbangkan sekaligus. Machine learning membalik caranya: kita memberikan contoh data beserta jawabannya, lalu algoritma mencari aturannya sendiri.

from sklearn.tree import DecisionTreeClassifier

X = [[1.4], [1.3], [4.7], [4.5], [6.0], [5.1]]
y = ["setosa", "setosa", "versicolor", "versicolor", "virginica", "virginica"]

model = DecisionTreeClassifier()
model.fit(X, y)
print(model.predict([[4.2]]))

Anda belum perlu menjalankan kode ini karena lingkungan kerjanya baru disiapkan pada materi berikutnya. X berisi panjang mahkota enam bunga, sedangkan y berisi jenisnya. Method fit() melatih model dari contoh tersebut, kemudian predict() menebak jenis bunga baru yang panjang mahkotanya 4,2 cm. Hasilnya ['versicolor'], padahal kita tidak pernah menulis batas angka apa pun.

Supervised Learning dan Unsupervised Learning

Contoh bunga di atas termasuk supervised learning karena setiap contoh sudah dilengkapi jawaban yang benar. Data yang menjadi dasar tebakan disebut fitur, misalnya panjang mahkota. Hal yang ingin ditebak disebut label, misalnya jenis bunga. Model belajar memetakan fitur ke label.

Unsupervised learning bekerja tanpa label. Algoritmanya mencari struktur di dalam data, misalnya mengelompokkan pelanggan toko daring menurut kebiasaan belanjanya tanpa tahu kelompok apa yang seharusnya ada. Teknik ini disebut pengelompokan atau clustering. Seri ini berfokus pada supervised learning karena jenis inilah yang paling banyak dipakai dan paling mudah diukur hasilnya.

Regresi dan Klasifikasi

Supervised learning terbagi lagi menurut jenis labelnya:

  • Regresi menebak angka yang nilainya kontinu, misalnya harga rumah, suhu besok, atau jumlah penjualan bulan depan.

  • Klasifikasi menebak kategori, misalnya jenis bunga, email spam atau bukan, dan pelanggan yang akan berhenti berlangganan atau tidak.

Satu pertanyaan sederhana membantu menentukan jenisnya: apakah jawabannya bisa dirata-ratakan? Harga rumah bisa dirata-ratakan sehingga termasuk regresi. Jenis bunga tidak bisa dirata-ratakan sehingga termasuk klasifikasi.

Alur Kerja Proyek Machine Learning

Hampir semua proyek machine learning mengikuti urutan langkah yang sama:

  1. Merumuskan masalah, yaitu menentukan hal yang ingin ditebak dan jenis tugasnya.

  2. Mengumpulkan dan memahami data, termasuk memeriksa isi, ukuran, dan nilai yang kosong.

  3. Membagi data menjadi data latih untuk belajar dan data uji untuk menilai.

  4. Melatih model dengan data latih.

  5. Mengevaluasi model dengan data uji yang belum pernah dilihatnya.

  6. Memakai model untuk menebak data baru dan melatihnya ulang saat data bertambah.

Langkah kedua sering memakan waktu paling lama. Kualitas model sangat bergantung pada kualitas datanya: data yang berantakan menghasilkan tebakan yang berantakan pula.
