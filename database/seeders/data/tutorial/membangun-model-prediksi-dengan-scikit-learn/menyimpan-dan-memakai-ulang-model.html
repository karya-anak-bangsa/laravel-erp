Model yang dilatih di notebook hanya tersimpan di memori. Begitu kernel dimatikan, model itu hilang dan harus dilatih ulang. Materi terakhir ini membahas cara menyatukan persiapan data dan model dalam satu pipeline, menyimpannya ke berkas, lalu memakainya untuk menebak data baru.

Menggabungkan Langkah dengan Pipeline

Lanjutkan notebook regresi dari materi pertama. Di sana, koefisien belum bisa dibandingkan karena skala fiturnya berbeda-beda. Penyamaan skala fitur (feature scaling) dengan StandardScaler mengatasinya: setiap fitur diubah agar rata-ratanya 0 dan simpangan bakunya 1. Persiapan seperti ini harus diterapkan dengan cara yang sama pada data latih, data uji, dan data baru. Objek Pipeline menyatukannya dengan model:

from sklearn.linear_model import LinearRegression
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

model_harga = Pipeline([
    ("skala", StandardScaler()),
    ("regresi", LinearRegression()),
])
model_harga.fit(X_latih, y_latih)

print(model_harga.score(X_uji, y_uji))

Setiap langkah diberi nama, yaitu skala dan regresi. Saat fit() dipanggil, pipeline menghitung rata-rata dan simpangan baku dari data latih saja, lalu melatih regresinya. Saat predict() atau score() dipanggil, data lain otomatis diubah dengan nilai dari data latih tersebut. Dengan begitu, informasi data uji tidak bocor ke model.

Skor R² tetap sekitar 0,58 karena penyamaan skala tidak mengubah tebakan regresi linear. Bedanya, koefisien di model_harga.named_steps["regresi"].coef_ kini sebanding. Ternyata MedInc, Latitude, dan Longitude adalah fitur yang paling berpengaruh. Pada model yang bergantung pada jarak antardata, seperti k-nearest neighbors, penyamaan skala bahkan mengubah hasil tebakan.

Menyimpan Model ke Berkas

Simpan pipeline yang sudah dilatih dengan joblib:

import joblib

joblib.dump(model_harga, "model_harga.joblib")

Pustaka joblib sudah terpasang bersama scikit-learn. Berkas model_harga.joblib menyimpan seluruh pipeline, termasuk nilai skala dan koefisien hasil pelatihan.

Catat juga versi scikit-learn yang dipakai, misalnya di requirements.txt. Berkas model sebaiknya dimuat dengan versi yang sama. Versi yang berbeda memunculkan peringatan InconsistentVersionWarning dan hasilnya tidak dijamin benar.

Memakai Model untuk Data Baru

Model yang tersimpan bisa dipakai di notebook lain atau di skrip Python biasa. Buat berkas prediksi_harga.py di folder yang sama:

import joblib
import pandas as pd

model_harga = joblib.load("model_harga.joblib")

rumah_baru = pd.DataFrame([{
    "MedInc": 5.0,
    "HouseAge": 20.0,
    "AveRooms": 6.0,
    "AveBedrms": 1.0,
    "Population": 1200.0,
    "AveOccup": 3.0,
    "Latitude": 34.05,
    "Longitude": -118.25,
}])

harga = model_harga.predict(rumah_baru)
print(harga.round(2))

Jalankan dengan python prediksi_harga.py dari terminal yang lingkungan virtualnya aktif. Hasilnya kira-kira [2.44], yaitu sekitar 244.000 dolar untuk blok wilayah di pusat kota Los Angeles dengan median pendapatan 50.000 dolar. Nama dan urutan kolom rumah_baru harus sama dengan data latih karena scikit-learn menolak data yang kolomnya berbeda.

Waspadai Berkas Model dari Sumber Tak Tepercaya

Pustaka joblib menyimpan model dengan format pickle milik Python. Saat dimuat, berkas seperti ini bisa menjalankan kode apa pun yang tersimpan di dalamnya, termasuk kode jahat yang menghapus berkas atau mencuri data. Oleh karena itu, jangan pernah memanggil joblib.load() untuk berkas model dari sumber yang tidak Anda percayai, misalnya lampiran email atau unduhan dari forum. Dokumentasi scikit-learn juga menyebutkan format yang lebih aman untuk berbagi model, seperti skops dan Open Neural Network Exchange (ONNX).
