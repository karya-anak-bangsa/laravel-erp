Aplikasi daftar tugas sudah bisa menambah, mencentang, dan menghapus tugas, tetapi semua perubahan hilang begitu halaman dimuat ulang. Data tersebut hanya hidup di memori selama halaman terbuka. Materi ini menyimpannya di localStorage agar tugas tetap ada saat halaman dibuka kembali.

Mengenal localStorage

localStorage adalah tempat penyimpanan bawaan peramban untuk pasangan kunci dan nilai. Datanya bertahan meskipun peramban ditutup dan hanya bisa dibaca oleh halaman dari situs yang sama. Coba perintah berikut di konsol:

localStorage.setItem('nama', 'Rina');
localStorage.getItem('nama'); // 'Rina'
localStorage.removeItem('nama');
localStorage.getItem('nama'); // null

setItem() menyimpan nilai dengan sebuah kunci, getItem() membacanya kembali, dan removeItem() menghapusnya. Bila kuncinya tidak ada, getItem() mengembalikan null.

Mengubah Data Menjadi String JSON

localStorage hanya bisa menyimpan string. Objek yang disimpan langsung akan berubah menjadi teks yang tidak berguna:

localStorage.setItem('coba', { judul: 'Belajar' });
localStorage.getItem('coba'); // '[object Object]'

Solusinya adalah format JavaScript Object Notation (JSON). JSON.stringify() mengubah objek atau array menjadi string JSON, sedangkan JSON.parse() mengubah string itu kembali menjadi data JavaScript:

const teks = JSON.stringify([{ id: 1, judul: 'Belajar', selesai: false }]);
console.log(teks); // [{"id":1,"judul":"Belajar","selesai":false}]

const dataKembali = JSON.parse(teks);
console.log(dataKembali[0].judul); // Belajar

JSON mirip objek JavaScript, tetapi nama properti dan teksnya wajib memakai tanda petik ganda. Format ini juga lazim dipakai untuk bertukar data dengan server, seperti yang akan kita lakukan di materi terakhir. Hapus kunci percobaan tadi dengan localStorage.removeItem('coba').

Menyimpan dan Memuat Daftar Tugas

Buka app.js, lalu tambahkan konstanta berikut di baris paling atas:

const KUNCI_PENYIMPANAN = 'daftar-tugas';

Setelah itu, ganti seluruh deklarasi const daftarTugas = [...] beserta kedua contoh tugasnya dengan kode berikut:

function muatTugas() {
  const dataTersimpan = localStorage.getItem(KUNCI_PENYIMPANAN);

  if (dataTersimpan === null) {
    return [];
  }

  return JSON.parse(dataTersimpan);
}

function simpanTugas() {
  localStorage.setItem(KUNCI_PENYIMPANAN, JSON.stringify(daftarTugas));
}

const daftarTugas = muatTugas();

muatTugas() membaca data lama dan mengembalikan array kosong saat aplikasi pertama kali dibuka. simpanTugas() menulis seluruh isi daftarTugas ke localStorage. Nama kunci ditulis sekali sebagai konstanta agar tidak salah ketik di dua tempat. Huruf kapital dengan garis bawah lazim dipakai untuk menandai nilai tetap seperti ini.

Menyimpan Setiap Perubahan

Data perlu disimpan setiap kali isinya berubah. Tambahkan simpanTugas(); tepat sebelum tampilkanTugas(); di event listener formulir sehingga isinya menjadi seperti berikut:

formulirTugas.addEventListener('submit', (event) => {
  event.preventDefault();

  const judul = isianTugas.value.trim();
  if (judul === '') {
    return;
  }

  daftarTugas.push({ id: Date.now(), judul, selesai: false });
  formulirTugas.reset();
  isianTugas.focus();
  simpanTugas();
  tampilkanTugas();
});

Lakukan hal yang sama di event listener daftar, tepat sebelum tampilkanTugas(); di bagian akhirnya. Baris tampilkanTugas(); yang paling bawah tidak perlu didahului simpanTugas(); karena saat itu data baru saja dimuat dan belum berubah.

Memeriksa Data di DevTools

Muat ulang halaman, tambahkan beberapa tugas, lalu tutup dan buka kembali halamannya. Tugas Anda masih ada. Di Chrome atau Edge, buka tab Application di DevTools, lalu pilih Local Storage di panel kiri. Kunci daftar-tugas berisi string JSON yang sama persis dengan isi daftarTugas.

Nilai di panel itu juga bisa diubah langsung. Bila isinya diubah hingga tidak lagi berupa JSON yang sah, JSON.parse() akan menghentikan skrip dengan galat SyntaxError. Cara menangani galat seperti ini dibahas di materi berikutnya.

Ingat juga batasannya. Data localStorage hanya tersimpan di peramban dan perangkat itu, kapasitasnya terbatas, dan isinya bisa dibaca oleh skrip apa pun di halaman yang sama. Jangan menyimpan data rahasia seperti kata sandi atau token di sini.

Pada materi berikutnya, kita akan mengambil contoh tugas dari server lain dengan fetch(), lalu menyimpannya bersama tugas buatan Anda.
