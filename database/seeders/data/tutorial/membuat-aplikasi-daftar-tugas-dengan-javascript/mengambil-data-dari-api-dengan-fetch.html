Sejauh ini, semua tugas berasal dari ketikan pengguna. Aplikasi web sungguhan sering mengambil data dari server lewat Application Programming Interface (API). Materi terakhir ini menambahkan tombol untuk mengambil contoh tugas dari API dengan fetch(), menunggu hasilnya dengan async dan await, serta menangani galat dengan try dan catch.

Mengenal API JSONPlaceholder

API adalah pintu yang disediakan sebuah layanan agar program lain bisa meminta datanya. Kita memakai JSONPlaceholder, API contoh gratis yang memang dibuat untuk latihan. Buka alamat berikut di peramban:

https://jsonplaceholder.typicode.com/todos?_limit=5

Peramban menampilkan array JSON berisi lima tugas. Parameter _limit=5 membatasi jumlahnya. Setiap tugas berbentuk seperti berikut:

{
  "userId": 1,
  "id": 1,
  "title": "delectus aut autem",
  "completed": false
}

Nama propertinya berbeda dengan data kita: title setara dengan judul, sedangkan completed setara dengan selesai. Kita akan menyesuaikannya saat data diterima.

Menambahkan Tombol Contoh

Tambahkan tombol berikut di index.html, tepat di bawah formulir:

<button type="button" id="tombol-contoh">Ambil contoh tugas</button>

Di app.js, tambahkan alamat API dan pilih tombol tersebut di bawah pemilihan elemen lainnya:

const ALAMAT_CONTOH = 'https://jsonplaceholder.typicode.com/todos?_limit=5';
const tombolContoh = document.querySelector('#tombol-contoh');

Mengambil Data dengan fetch

Tambahkan fungsi berikut di atas baris tampilkanTugas(); yang paling bawah:

async function ambilContohTugas() {
  tombolContoh.disabled = true;
  elemenRingkasan.textContent = 'Mengambil contoh tugas...';

  try {
    const respons = await fetch(ALAMAT_CONTOH);

    if (!respons.ok) {
      throw new Error(`server membalas dengan status ${respons.status}`);
    }

    const dataContoh = await respons.json();
    const tugasBaru = dataContoh.map((data) => ({
      id: Date.now() + data.id,
      judul: data.title,
      selesai: data.completed,
    }));

    daftarTugas.push(...tugasBaru);
    simpanTugas();
    tampilkanTugas();
  } catch (galat) {
    elemenRingkasan.textContent = `Gagal mengambil contoh tugas: ${galat.message}`;
  } finally {
    tombolContoh.disabled = false;
  }
}

tombolContoh.addEventListener('click', ambilContohTugas);

fetch() mengirim permintaan ke alamat API dan mengembalikan Promise, yaitu objek yang mewakili hasil yang baru tersedia nanti. await menunggu Promise itu selesai tanpa membekukan halaman sehingga pengguna tetap bisa menggulir atau mengetik selama data diambil. Di skrip biasa seperti app.js, await hanya boleh dipakai di dalam fungsi bertanda async. Penjelasan lebih lengkap ada di artikel Memahami Async/Await di JavaScript lewat Contoh Sehari-hari.

Isi jawaban server dibaca dengan respons.json() yang juga perlu ditunggu. Setelah itu, map() mengubah setiap data dari API menjadi objek tugas kita. Objek di dalam arrow function dibungkus tanda kurung agar kurung kurawalnya tidak dianggap sebagai isi fungsi. Date.now() + data.id menjaga kelima id tetap berbeda meskipun dibuat pada milidetik yang sama. Operator spread pada ...tugasBaru memasukkan kelima tugas ke daftarTugas sekaligus.

Menangani Galat dengan try dan catch

Permintaan ke server bisa gagal karena sambungan internet terputus atau alamatnya salah. Kode di dalam try dijalankan seperti biasa. Begitu terjadi galat, JavaScript langsung melompat ke catch dan menerima objek galatnya sebagai parameter galat. Blok finally selalu dijalankan, baik permintaan berhasil maupun gagal. Dengan begitu, tombol pasti aktif kembali.

Perlu diingat, fetch() hanya gagal bila permintaannya tidak sampai ke server. Jawaban dengan status galat seperti 404 atau 500 tetap dianggap berhasil. Oleh karena itu, kode di atas memeriksa respons.ok dan melempar galat sendiri dengan throw bila statusnya di luar rentang 200–299.

Coba ubah ALAMAT_CONTOH menjadi https://jsonplaceholder.typicode.com/salah, lalu klik tombolnya. Ringkasan akan menampilkan Gagal mengambil contoh tugas: server membalas dengan status 404. Kembalikan alamatnya setelah mencoba.

Teknik yang sama bisa melindungi muatTugas() dari data rusak yang disinggung di materi sebelumnya. Ganti baris return JSON.parse(dataTersimpan); di fungsi tersebut dengan kode berikut:

try {
  return JSON.parse(dataTersimpan);
} catch {
  return [];
}

Bila isi localStorage bukan JSON yang sah, aplikasi kini mulai dengan daftar kosong alih-alih berhenti karena galat. Parameter pada catch boleh dihilangkan bila objek galatnya tidak dipakai.

Rangkuman Seri

Selamat, aplikasi daftar tugas Anda kini lengkap. Sepanjang seri ini, Anda sudah memilih dan mengubah elemen DOM, menangani event dengan delegasi, menyimpan data di localStorage dengan bantuan JSON, dan mengambil data dari API dengan fetch().
