Seri ini mengajak Anda membuat aplikasi daftar tugas yang berjalan di peramban tanpa framework, hanya dengan satu berkas index.html dan satu berkas app.js. Anda cukup memahami dasar HTML serta variabel, fungsi, array, dan objek di JavaScript seperti yang dibahas di tutorial Dasar-Dasar JavaScript Modern.

Materi pertama ini menyiapkan kedua berkas tersebut, mengenalkan Document Object Model (DOM), lalu menampilkan daftar tugas dari data di JavaScript.

Menyiapkan Berkas Proyek

Buat folder daftar-tugas, lalu buat berkas index.html di dalamnya:

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Daftar Tugas</title>
  <style>
    .selesai { text-decoration: line-through; color: #6b7280; }
  </style>
  <script src="app.js" defer></script>
</head>
<body>
  <main>
    <h1>Daftar Tugas</h1>
    <p id="ringkasan"></p>

    <form id="formulir-tugas">
      <input type="text" id="isian-tugas" aria-label="Tugas baru" placeholder="Tulis tugas baru" required>
      <button type="submit">Tambah</button>
    </form>

    <ul id="daftar-tugas"></ul>
  </main>
</body>
</html>

Atribut defer membuat peramban menjalankan app.js setelah seluruh HTML selesai dibaca. Tanpa atribut ini, skrip berjalan sebelum formulir dan <ul> terbentuk sehingga kode kita tidak bisa menemukannya. Buat juga berkas app.js yang masih kosong di folder yang sama, lalu buka index.html dengan mengeklik dua kali berkasnya.

Mengenal DOM

Saat membuka halaman, peramban mengubah HTML menjadi pohon objek yang disebut DOM. Setiap elemen HTML menjadi simpul yang bisa dibaca dan diubah lewat JavaScript. Perubahan itu langsung tampil di layar tanpa memuat ulang halaman. Pintu masuknya adalah objek document.

Lihat sendiri pohon tersebut lewat tab Elements di DevTools. Coba juga ketik document.title = 'Halo DOM' di konsol dan perhatikan judul tab peramban yang langsung berubah.

Memilih Elemen

Isi app.js dengan kode berikut:

const formulirTugas = document.querySelector('#formulir-tugas');
const isianTugas = document.querySelector('#isian-tugas');
const elemenDaftar = document.querySelector('#daftar-tugas');
const elemenRingkasan = document.querySelector('#ringkasan');

querySelector() menerima selektor CSS dan mengembalikan elemen pertama yang cocok, atau null bila tidak ada yang cocok. Tanda # berarti mencari elemen berdasarkan atribut id. Selektor lain juga bisa dipakai, misalnya '.selesai' untuk kelas atau 'main h1' untuk elemen bertingkat. Bila membutuhkan semua elemen yang cocok, gunakan querySelectorAll().

Menampilkan Daftar Tugas

Data tugas disimpan sebagai array berisi objek. Tambahkan kode berikut di bawah pemilihan elemen tadi:

const daftarTugas = [
  { id: 1, judul: 'Mempelajari DOM', selesai: true },
  { id: 2, judul: 'Membuat formulir tugas', selesai: false },
];

function tampilkanTugas() {
  elemenDaftar.replaceChildren();

  for (const tugas of daftarTugas) {
    const item = document.createElement('li');
    item.textContent = tugas.judul;
    item.classList.toggle('selesai', tugas.selesai);
    elemenDaftar.append(item);
  }

  const jumlahSelesai = daftarTugas.filter((tugas) => tugas.selesai).length;
  elemenRingkasan.textContent = daftarTugas.length === 0
    ? 'Belum ada tugas.'
    : `${jumlahSelesai} dari ${daftarTugas.length} tugas selesai`;
}

tampilkanTugas();

Simpan berkasnya, lalu muat ulang halaman. Kedua tugas tampil sebagai daftar dan tugas pertama dicoret karena sudah selesai. Berikut peran setiap bagian di dalam tampilkanTugas():

  • replaceChildren() tanpa argumen mengosongkan isi <ul> agar daftar tidak menumpuk setiap kali fungsi dipanggil.

  • document.createElement('li') membuat elemen baru di memori, sedangkan append() menempelkannya ke halaman.

  • classList.toggle('selesai', tugas.selesai) memasang kelas selesai bila argumen kedua bernilai true dan melepasnya bila false. Kelas inilah yang memicu gaya coretan di <style>.

  • Operator kondisional pada ringkasan menampilkan Belum ada tugas. saat daftar kosong.

Mengisi Teks dengan Aman

Properti textContent mengisi elemen dengan teks apa adanya. Anda mungkin pernah melihat innerHTML untuk keperluan yang sama. Properti itu membaca isinya sebagai HTML sehingga judul tugas seperti <img src="x" onerror="alert(1)"> akan menjalankan kode di dalam atribut onerror. Celah ini disebut Cross-Site Scripting (XSS). Selama isinya berasal dari pengguna, selalu gunakan textContent.

Daftar tugas sudah tampil, tetapi datanya masih tertulis di kode. Pada materi berikutnya, kita akan menangani event agar pengguna bisa menambah, mencentang, dan menghapus tugas.
