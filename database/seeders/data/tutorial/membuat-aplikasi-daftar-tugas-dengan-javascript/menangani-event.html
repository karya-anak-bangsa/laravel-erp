Aplikasi daftar tugas dari materi sebelumnya baru bisa menampilkan data. Materi ini membuatnya interaktif: pengguna bisa menambah tugas lewat formulir, mencentang tugas yang selesai, dan menghapus tugas. Semua itu dilakukan dengan menangani event.

Mengenal Event

Event adalah sinyal dari peramban bahwa sesuatu baru saja terjadi, misalnya tombol diklik, tuts papan ketik ditekan, atau formulir dikirim. Method addEventListener() mendaftarkan fungsi yang dijalankan setiap kali event tertentu terjadi:

elemenRingkasan.addEventListener('click', () => {
  console.log('Ringkasan diklik');
});

Tempelkan kode itu sementara di akhir app.js, muat ulang halaman, lalu klik teks ringkasan. Pesan akan muncul di konsol DevTools. Hapus kembali kode percobaan ini sebelum melanjutkan.

Menambah Tugas dari Formulir

Tambahkan kode berikut di atas baris tampilkanTugas(); yang paling bawah:

formulirTugas.addEventListener('submit', (event) => {
  event.preventDefault();

  const judul = isianTugas.value.trim();
  if (judul === '') {
    return;
  }

  daftarTugas.push({ id: Date.now(), judul, selesai: false });
  formulirTugas.reset();
  isianTugas.focus();
  tampilkanTugas();
});

Fungsi ini menerima objek event yang berisi keterangan tentang kejadiannya. Secara bawaan, peramban mengirim formulir dengan memuat ulang halaman. preventDefault() membatalkan perilaku itu agar data di JavaScript tidak hilang.

Atribut required sudah menolak isian kosong, tetapi isian berupa spasi saja tetap lolos. Oleh karena itu, trim() membuang spasi di awal dan akhir teks sebelum diperiksa. Date.now() menghasilkan jumlah milidetik sejak 1 Januari 1970 sehingga cukup unik sebagai id sederhana. Penulisan judul tanpa titik dua di dalam objek adalah singkatan dari judul: judul.

Menambahkan Kotak Centang dan Tombol Hapus

Setiap tugas membutuhkan kotak centang dan tombol hapus. Ubah isi perulangan di tampilkanTugas() menjadi seperti berikut:

for (const tugas of daftarTugas) {
  const item = document.createElement('li');
  item.dataset.id = tugas.id;
  item.classList.toggle('selesai', tugas.selesai);

  const kotakCentang = document.createElement('input');
  kotakCentang.type = 'checkbox';
  kotakCentang.checked = tugas.selesai;

  const label = document.createElement('label');
  label.append(kotakCentang, ` ${tugas.judul}`);

  const tombolHapus = document.createElement('button');
  tombolHapus.type = 'button';
  tombolHapus.className = 'tombol-hapus';
  tombolHapus.textContent = 'Hapus';

  item.append(label, ' ', tombolHapus);
  elemenDaftar.append(item);
}

item.dataset.id menulis atribut data-id pada <li> sebagai penanda tugas. Kotak centang dibungkus <label> agar pengguna cukup mengeklik judulnya untuk mencentang. Teks yang dikirim ke append() juga dimasukkan apa adanya sehingga judul tugas tetap aman seperti saat memakai textContent.

Delegasi Event

Kita bisa saja memasang addEventListener() pada setiap tombol hapus. Namun, tombol itu dibuat ulang setiap kali daftar ditampilkan sehingga pemasangannya harus terus diulang. Cara yang lebih rapi adalah delegasi event, yaitu memasang satu event listener pada <ul>. Cara ini bekerja karena klik pada elemen di dalam <ul> merambat ke atas (bubbling) hingga sampai ke <ul>. Tambahkan kode berikut di bawah event listener formulir:

elemenDaftar.addEventListener('click', (event) => {
  const item = event.target.closest('li');
  if (item === null) {
    return;
  }

  const id = Number(item.dataset.id);
  const indeks = daftarTugas.findIndex((tugas) => tugas.id === id);

  if (event.target.matches('.tombol-hapus')) {
    daftarTugas.splice(indeks, 1);
  } else if (event.target.matches('input[type="checkbox"]')) {
    daftarTugas[indeks].selesai = event.target.checked;
  } else {
    return;
  }

  tampilkanTugas();
});

event.target adalah elemen yang benar-benar diklik. closest('li') mencari <li> terdekat ke arah atas, sedangkan matches() memeriksa apakah elemen yang diklik adalah tombol hapus atau kotak centang. Nilai data-id selalu berupa string, jadi Number() mengubahnya menjadi angka sebelum dibandingkan dengan ===. Terakhir, splice(indeks, 1) membuang satu tugas tepat di indeks tersebut.

Klik pada judul tugas sebenarnya menghasilkan dua klik. Klik pertama mengenai <label> dan diabaikan oleh return di blok else. Setelah itu, peramban meneruskan klik ke kotak centang sehingga klik kedua mengubah status tugas.

Coba tambahkan beberapa tugas, centang sebagian, lalu hapus satu tugas. Ringkasan di atas daftar ikut berubah. Namun, semua tugas kembali seperti semula begitu halaman dimuat ulang. Pada materi berikutnya, kita akan menyimpan daftar tugas di localStorage agar setiap perubahan tetap tersimpan.
