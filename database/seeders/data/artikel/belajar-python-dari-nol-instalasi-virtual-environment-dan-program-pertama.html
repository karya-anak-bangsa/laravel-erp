Banyak orang ingin belajar Python, entah untuk mengolah data kantor, membuat bot, atau sekadar memahami dasar pemrograman, tetapi langsung tersandung pada langkah pertama. Terminal tidak mengenali perintah python, paket terpasang ke tempat yang salah, atau tutorial yang mereka ikuti ternyata sudah usang.

Panduan ini membahas cara memasang Python di Windows sesuai dengan anjuran python.org saat ini, membuat virtual environment, memasang paket dengan pip, menulis program pertama, dan menyiapkan VS Code. Semua langkah mengacu pada kondisi per Juli 2026.

Versi Mana yang Sebaiknya Anda Pasang?

Per awal Juli 2026, rilis stabil terbaru adalah Python 3.14.6 yang terbit pada 10 Juni 2026. Anda memang sudah bisa mengunduh Python 3.15, tetapi versi ini masih berstatus beta dan khusus untuk pengujian, bukan untuk belajar atau proyek sungguhan. Oleh karena itu, pilih seri 3.14.

Anda tidak perlu mengkhawatirkan angka di belakang titik. Rilis seperti 3.14.6 hanya berisi perbaikan bug dan keamanan sehingga materi belajar seri 3.14 berlaku sama untuk semua rilis perbaikannya. Selain itu, install manager memudahkan Anda memperbarui Python ke rilis perbaikan terbaru kapan saja.

Memasang Python dengan Python install manager

Cara memasang Python di Windows berubah sejak seri 3.14. Halaman unduhan python.org kini mengarahkan pengguna Windows ke Python install manager, aplikasi kecil yang mengurus pemasangan dan pembaruan versi Python. Penginstal tradisional berformat .exe masih tersedia selama seri 3.14 dan 3.15, tetapi tidak akan ada lagi mulai Python 3.16.

  1. Buka halaman unduhan python.org, klik Download Python install manager, jalankan berkas MSIX yang terunduh, lalu pilih Install. Anda juga bisa memasang aplikasi yang sama dari Microsoft Store.

  2. Buka PowerShell atau Windows Terminal, lalu ketik python. Bila belum ada versi Python sama sekali, install manager secara otomatis memasang rilis stabil terbaru, kemudian membuka mode interaktif. Ketik exit() untuk keluar.

  3. Jalankan python --version untuk memastikan pemasangan berhasil. Perintah py list menampilkan semua versi yang terpasang, sedangkan py install 3.14 memasang versi tertentu secara eksplisit.

Saat Anda pertama kali memasang sebuah versi, mungkin muncul tawaran untuk menambahkan folder perintah Python ke PATH. Langkah ini opsional dan berguna bila Anda ingin memakai perintah berversi seperti python3.14. Install manager membutuhkan Windows 10 atau versi yang lebih baru. Bila Anda pernah memasang Python dengan penginstal lama, copot Python Launcher bawaannya terlebih dahulu karena Python Launcher dan install manager sama-sama memakai perintah py.

Membuat dan Mengaktifkan Virtual Environment

Virtual environment, atau venv, adalah folder berisi lingkungan Python khusus untuk satu proyek. Paket yang Anda pasang di dalamnya tidak bercampur dengan paket proyek lain. Dengan demikian, proyek A bisa memakai versi pustaka yang berbeda dengan proyek B tanpa saling merusak. Biasakan membuat satu venv untuk setiap proyek sejak hari pertama.

  1. Buat folder proyek dengan mkdir belajar-python, lalu masuk ke dalamnya dengan cd belajar-python.

  2. Buat venv dengan python -m venv .venv. Nama .venv merupakan konvensi yang lazim. VS Code pun mengenali nama ini secara otomatis.

  3. Aktifkan venv di PowerShell dengan .venv\Scripts\Activate.ps1 atau di Command Prompt dengan .venv\Scripts\activate.bat. Bila aktivasi berhasil, awal baris terminal berubah menjadi (.venv).

  4. Setelah selesai bekerja, ketik deactivate untuk keluar dari venv.

Bila PowerShell menolak dengan pesan bahwa menjalankan skrip dinonaktifkan di sistem ini, izinkan skrip lokal untuk akun Anda dengan Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser, lalu ulangi perintah aktivasi. Dokumentasi resmi Python juga menganjurkan pengaturan ini. Pengaturan tersebut hanya berlaku untuk akun Anda sendiri.

Memasang Paket dengan pip

Saat venv aktif, pasang paket lewat pip. Biasakan memakai bentuk python -m pip agar paket pasti masuk ke Python yang sedang aktif. Misalnya, perintah python -m pip install requests memasang requests, pustaka populer untuk mengambil data dari internet.

Catat daftar paket proyek dengan python -m pip freeze > requirements.txt. Rekan kerja, atau Anda sendiri di laptop lain, cukup membuat venv baru, lalu menjalankan python -m pip install -r requirements.txt untuk mendapatkan paket yang sama persis. Anda tidak perlu menyalin folder .venv atau memasukkannya ke Git.

Menulis Program Pertama

Buat berkas bernama halo.py di folder proyek, lalu isi berkas itu dengan dua baris kode. Baris pertama, nama = input("Siapa nama Anda? "), meminta pengguna mengetik nama. Baris kedua, print(f"Halo, {nama}! Selamat belajar Python."), menampilkan sapaan dengan f-string, yaitu cara praktis menyisipkan isi variabel ke dalam teks.

Jalankan program dengan python halo.py dari terminal yang venv-nya aktif. Program akan bertanya, menunggu Anda mengetik, lalu membalas dengan sapaan. Ingat juga bahwa Python memakai indentasi untuk menandai blok kode. Oleh karena itu, biasakan memakai empat spasi sejak awal dan jangan mencampurnya dengan tab.

Buat berkas cek.py berisi baris import requests dan print(requests.get("https://www.python.org").status_code) untuk mencoba paket yang tadi Anda pasang. Bila skrip itu mencetak angka 200, Python berhasil menghubungi situs python.org lewat pustaka requests.

Menyiapkan VS Code

Notepad sebenarnya cukup untuk menulis kode, tetapi editor yang tepat membuat proses belajar jauh lebih nyaman. Visual Studio Code gratis, ringan, dan menjadi pilihan banyak pemrogram Python.

  1. Pasang VS Code, buka panel Extensions, lalu pasang ekstensi Python buatan Microsoft. Ekstensi pendukung seperti Pylance dan Python Debugger ikut terpasang secara otomatis.

  2. Buka folder proyek lewat menu File > Open Folder.

  3. Tekan Ctrl+Shift+P, jalankan Python: Select Interpreter, lalu pilih Python yang berada di folder .venv.

  4. Buka halo.py, lalu klik tombol Run Python File di pojok kanan atas editor. Terminal akan terbuka di bagian bawah dan program langsung berjalan.
