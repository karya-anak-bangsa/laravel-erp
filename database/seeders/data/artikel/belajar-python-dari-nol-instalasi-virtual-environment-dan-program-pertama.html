Banyak orang ingin belajar Python, entah untuk mengolah data kantor, membuat bot, atau sekadar memahami dasar pemrograman, tetapi langsung tersandung di langkah pertama. Perintah python tidak dikenali, paket terpasang ke tempat yang salah, atau tutorial yang diikuti ternyata sudah usang.

Panduan ini membahas cara memasang Python di Windows sesuai cara yang kini dianjurkan python.org, membuat virtual environment, memasang paket dengan pip, menulis program pertama, dan menyiapkan VS Code. Semua langkah ditulis per Juli 2026.

Versi Mana yang Sebaiknya Dipasang?

Per awal Juli 2026, rilis stabil terbaru adalah Python 3.14.6 yang terbit pada 10 Juni 2026. Python 3.15 memang sudah bisa diunduh, tetapi masih berstatus beta dan ditujukan untuk pengujian, bukan untuk belajar atau proyek sungguhan. Jadi, pilih seri 3.14.

Jangan khawatir soal angka di belakang titik. Rilis seperti 3.14.6 hanya berisi perbaikan bug dan keamanan, sehingga materi belajar untuk seri 3.14 berlaku sama di semua rilis perbaikannya. Install manager juga memudahkan Anda memperbarui ke rilis perbaikan terbaru kapan saja.

Memasang Python dengan Python Install Manager

Cara memasang Python di Windows berubah sejak seri 3.14. Halaman unduhan python.org kini mengarahkan pengguna Windows ke Python install manager, aplikasi kecil yang mengurus pemasangan dan pembaruan versi Python. Penginstal tradisional berformat .exe masih tersedia selama seri 3.14 dan 3.15, tetapi tidak akan dibuat lagi mulai Python 3.16.

  1. Buka halaman unduhan python.org, klik Download Python install manager, jalankan berkas MSIX yang terunduh, lalu pilih Install. Alternatifnya, pasang aplikasi yang sama dari Microsoft Store.

  2. Buka PowerShell atau Windows Terminal, lalu ketik python. Bila belum ada versi Python sama sekali, install manager otomatis memasang rilis stabil terbaru, kemudian membuka mode interaktif. Ketik exit() untuk keluar.

  3. Pastikan pemasangan berhasil dengan python --version. Perintah py list menampilkan semua versi yang terpasang, sedangkan py install 3.14 memasang versi tertentu secara eksplisit.

Saat pertama memasang sebuah versi, Anda mungkin ditawari menambahkan folder perintah Python ke PATH. Langkah ini opsional dan berguna bila Anda ingin memakai perintah berversi seperti python3.14. Install manager membutuhkan Windows 10 atau yang lebih baru. Bila sebelumnya pernah memasang Python dengan penginstal lama, copot dulu Python Launcher bawaannya, karena keduanya sama-sama memakai perintah py.

Membuat dan Mengaktifkan Virtual Environment

Virtual environment, atau venv, adalah folder berisi lingkungan Python khusus untuk satu proyek. Paket yang dipasang di dalamnya tidak bercampur dengan proyek lain, sehingga proyek A bisa memakai versi pustaka yang berbeda dari proyek B tanpa saling merusak. Biasakan membuat satu venv untuk setiap proyek sejak hari pertama.

  1. Buat folder proyek dengan mkdir belajar-python, lalu masuk ke dalamnya dengan cd belajar-python.

  2. Buat venv dengan python -m venv .venv. Nama .venv adalah konvensi yang umum dipakai dan dikenali otomatis oleh VS Code.

  3. Aktifkan di PowerShell dengan .venv\Scripts\Activate.ps1, atau di Command Prompt dengan .venv\Scripts\activate.bat. Bila berhasil, awal baris terminal berubah menjadi (.venv).

  4. Setelah selesai bekerja, ketik deactivate untuk keluar dari venv.

Bila PowerShell menolak dengan pesan bahwa menjalankan skrip dinonaktifkan di sistem ini, izinkan skrip lokal untuk akun Anda dengan Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser, lalu ulangi perintah aktivasi. Pengaturan ini juga yang dianjurkan dokumentasi resmi Python, dan hanya berlaku untuk akun Anda sendiri.

Memasang Paket dengan pip

Dengan venv aktif, paket dipasang lewat pip. Biasakan memakai bentuk python -m pip agar paket pasti masuk ke Python yang sedang aktif. Misalnya, python -m pip install requests memasang requests, pustaka populer untuk mengambil data dari internet.

Catat daftar paket proyek dengan python -m pip freeze > requirements.txt. Rekan kerja, atau Anda sendiri di laptop lain, cukup membuat venv baru lalu menjalankan python -m pip install -r requirements.txt untuk mendapatkan paket yang sama persis. Folder .venv sendiri tidak perlu disalin atau dimasukkan ke Git.

Menulis Program Pertama

Buat berkas bernama halo.py di folder proyek, lalu isi dengan dua baris. Baris pertama, nama = input("Siapa nama Anda? "), meminta pengguna mengetik nama. Baris kedua, print(f"Halo, {nama}! Selamat belajar Python."), menampilkan sapaan dengan f-string, cara praktis menyisipkan isi variabel ke dalam teks.

Jalankan dengan python halo.py dari terminal yang venv-nya aktif. Program akan bertanya, menunggu Anda mengetik, lalu membalas dengan sapaan. Ingat juga bahwa Python memakai indentasi untuk menandai blok kode, jadi sejak awal biasakan memakai empat spasi dan jangan mencampurnya dengan tab.

Untuk mencoba paket yang tadi dipasang, buat berkas cek.py berisi baris import requests dan print(requests.get("https://www.python.org").status_code). Bila tercetak angka 200, Python berhasil menghubungi situs python.org lewat pustaka requests.

Menyiapkan VS Code

Notepad sebenarnya cukup untuk menulis kode, tetapi editor yang tepat membuat belajar jauh lebih nyaman. Visual Studio Code gratis, ringan, dan banyak dipakai untuk Python.

  1. Pasang VS Code, buka panel Extensions, lalu pasang ekstensi Python buatan Microsoft. Ekstensi pendukung seperti Pylance dan Python Debugger ikut terpasang otomatis.

  2. Buka folder proyek lewat menu File > Open Folder.

  3. Tekan Ctrl+Shift+P, jalankan Python: Select Interpreter, lalu pilih Python yang berada di folder .venv.

  4. Buka halo.py dan klik tombol Run Python File di pojok kanan atas editor. Terminal akan terbuka di bagian bawah dan program langsung berjalan.

Langkah Berikutnya

Cara belajar paling efektif adalah memecahkan masalah nyata yang Anda temui sehari-hari, misalnya merapikan nama berkas foto, merekap pengeluaran bulanan, atau mengambil data dari sebuah API. Satu proyek kecil yang selesai jauh lebih berharga daripada sepuluh tutorial yang ditonton setengah jalan.
