Banyak pengembang pemula di Windows tersandung bukan saat menulis kode, melainkan saat menyiapkan lingkungan kerja: versi PHP tidak cocok, Composer belum terpasang, atau basis data menolak koneksi. Laragon memangkas sebagian besar kerepotan itu karena PHP, MySQL, Composer, dan Node.js sudah tersedia dalam satu paket yang bisa Anda nyalakan dengan sekali klik.

Panduan ini membahas dua cara memasang Laravel 13 di Laragon, yaitu lewat fitur Quick app dan lewat terminal. Setelah itu, kita akan menyambungkan proyek ke MySQL, menjalankan migrasi, membuka aplikasi di peramban, dan mengenali galat yang paling sering muncul.

Kenali Dulu Kebutuhan Laravel 13

Laravel 13 hadir pada 17 Maret 2026. Versi ini membutuhkan minimal PHP 8.3 dan resmi mendukung PHP 8.3 hingga 8.5. Tim Laravel menjadwalkan perbaikan bug untuk versi ini sampai kuartal ketiga 2027 dan perbaikan keamanan sampai 17 Maret 2028. Dengan demikian, Laravel 13 merupakan pilihan yang aman untuk proyek baru.

Selain PHP, Anda membutuhkan Composer untuk mengelola paket PHP, serta Node.js dan npm untuk membangun aset frontend lewat Vite. Laragon edisi Full sudah membawa semuanya sehingga tugas Anda tinggal memastikan versinya sesuai.

Menyiapkan Laragon

  1. Unduh Laragon edisi Full dari situs resminya, pasang seperti aplikasi biasa, lalu buka dan klik Start All untuk menyalakan Apache dan MySQL.

  2. Buka terminal bawaan Laragon lewat Menu > Laragon > Terminal. Terminal ini sudah mengenali PHP, Composer, dan npm milik Laragon sehingga Anda tidak perlu mengatur PATH sendiri.

  3. Periksa versinya dengan php -v, composer -V, dan node -v. Pastikan PHP menunjukkan versi 8.3 atau lebih baru.

  4. Jika PHP masih di bawah 8.3, tambahkan versi baru lewat Menu > Tools > Quick add, lalu aktifkan di Menu > PHP > Version.

Pengguna sering melewatkan langkah keempat, padahal akibatnya menjebak. Composer selalu memilih versi paket yang cocok dengan PHP yang sedang aktif. Jika PHP yang aktif masih versi 8.2, instalasi tetap berhasil, tetapi yang terpasang justru Laravel 12. Banyak orang baru menyadarinya setelah proyek berjalan beberapa hari.

Membuat Proyek Laravel 13

Cara Tercepat dengan Quick App

Fitur Quick app membuat proyek Laravel hanya dengan beberapa klik. Pilih Menu > Quick app > Laravel, isi nama proyek, misalnya inventaris, lalu tunggu hingga proses unduh selesai.

Di balik layar, Laragon menjalankan composer create-project laravel/laravel inventaris --prefer-dist di folder C:\laragon\www. Laragon juga dapat membuat basis data MySQL bernama sama secara otomatis, sekaligus menyiapkan alamat http://inventaris.test.

Buka alamat itu di peramban. Halaman sambutan Laravel akan tampil karena Laragon mengarahkan virtual host ke folder public milik proyek. Jika alamat .test belum terbuka, klik tombol Reload di Laragon.

Cara Manual lewat Terminal

Bila Anda menginginkan kendali penuh, buat proyek sendiri dari terminal Laragon. Pindah ke folder kerja dengan cd C:\laragon\www, lalu jalankan composer create-project laravel/laravel inventaris.

Alternatifnya, pakai Laravel installer resmi. Pasang sekali dengan composer global require laravel/installer, lalu buat proyek dengan laravel new inventaris. Penginstal ini akan mengajukan beberapa pertanyaan, termasuk pilihan starter kit React, Svelte, Vue, atau Livewire. Semua starter kit itu sudah berisi halaman login dan registrasi. Bila Anda baru mempelajari dasar-dasarnya, memulai tanpa starter kit juga tidak masalah.

Jika terminal tidak mengenali perintah laravel, folder bin global Composer belum masuk PATH. Lihat lokasinya dengan composer global config bin-dir --absolute, lalu tambahkan folder tersebut ke Environment Variables Windows.

Setelah proyek terbentuk, klik Reload agar Laragon membuat alamat http://inventaris.test. Pastikan juga versinya benar dengan menjalankan php artisan --version dari dalam folder proyek. Hasilnya harus berawalan Laravel Framework 13.

Menghubungkan Proyek ke MySQL Laragon

Proyek Laravel baru memakai SQLite secara bawaan. Buka berkas .env di folder proyek untuk beralih ke MySQL. Hapus tanda # di depan baris DB_ yang masih berupa komentar, lalu sesuaikan isinya:

  • DB_CONNECTION=mysql untuk memakai driver MySQL.

  • DB_HOST=127.0.0.1 dan DB_PORT=3306, alamat dan port bawaan MySQL di Laragon.

  • DB_DATABASE=inventaris sebagai nama basis data proyek.

  • DB_USERNAME=root dan DB_PASSWORD= yang tetap kosong, sesuai dengan akun bawaan MySQL Laragon.

Selagi membuka .env, ubah juga APP_URL menjadi http://inventaris.test agar Laravel membuat tautan dengan alamat yang benar. Ingat bahwa berkas .env menyimpan kredensial. Jangan pernah mengunggahnya ke repositori Git. Kebiasaan sederhana ini termasuk dasar dalam menjaga keamanan website.

Menjalankan Migrasi dan Membuka Aplikasi

Jalankan php artisan migrate untuk membuat tabel bawaan seperti users, sessions, dan jobs. Jika basis data inventaris belum ada, Laravel akan menawarkan untuk membuatnya. Jawab yes agar migrasi berlanjut.

Berikutnya, pasang dependensi frontend dengan npm install, lalu bangun asetnya dengan npm run build. Kini Anda bisa membuka aplikasi di http://inventaris.test tanpa server tambahan karena Apache milik Laragon sudah melayaninya.

Saat aktif menulis kode, jalankan npm run dev agar perubahan CSS dan JavaScript langsung terlihat di peramban. Pilihan lainnya adalah composer run dev. Perintah ini menyalakan server PHP, antrean, dan Vite sekaligus. Aplikasinya kemudian tersedia di http://localhost:8000.

Masalah yang Sering Muncul

  • Composer menampilkan pesan bahwa sebuah paket membutuhkan php ^8.3, misalnya saat Anda memasang dependensi proyek milik orang lain: ganti versi PHP di Laragon, lalu buka terminal baru agar perubahannya terbaca.

  • Galat SQLSTATE[HY000] [1045] Access denied: nama pengguna atau password di .env tidak cocok. Akun bawaan MySQL Laragon adalah root tanpa password.

  • Alamat .test tidak terbuka: klik Reload, pastikan folder proyek berada langsung di C:\laragon\www, lalu coba jalankan Laragon sebagai administrator agar aplikasi itu bisa menulis ke berkas hosts Windows.

  • Perubahan .env tidak terbaca: jalankan php artisan config:clear, terutama bila Anda pernah menjalankan config:cache.

  • Muncul galat Vite manifest not found, biasanya pada proyek dengan starter kit: jalankan npm run build atau biarkan npm run dev tetap berjalan.

Langkah Berikutnya

Sampai di sini, Anda sudah memiliki proyek Laravel 13 yang tersambung ke MySQL dan tersedia di alamat .test yang rapi. Langkah logis berikutnya adalah membuat model dan migrasi pertama, misalnya tabel barang untuk aplikasi inventaris, lalu menampilkannya di halaman sederhana.

Simpan juga tautan dokumentasi instalasi Laravel 13 sebagai rujukan karena pertanyaan dari Laravel installer bisa sedikit berubah di versi yang lebih baru. Terakhir, biasakan mencatat setiap perubahan dengan Git sejak hari pertama agar Anda mudah melacak dan membatalkan eksperimen.
