Pemilik toko kue rumahan yang setiap hari ditanya soal jam buka, cara memesan, dan status pesanan lama-lama akan kewalahan membalas satu per satu. Pertanyaan berulang seperti itu sebenarnya bisa dijawab oleh bot Telegram, dan membuat versi sederhananya tidak serumit yang dibayangkan.

Artikel ini memandu Anda membuat bot pertama dengan Python dan pustaka python-telegram-bot: mendaftarkan bot lewat BotFather, menyimpan token dengan aman, menulis perintah /start dan balasan otomatis, memahami beda polling dan webhook, sampai ide pengembangan berikutnya.

Mendaftarkan Bot lewat BotFather

Setiap bot Telegram dibuat lewat BotFather, akun resmi milik Telegram untuk mengelola bot. Prosesnya hanya beberapa menit:

  1. Buka Telegram, cari akun @BotFather, lalu kirim perintah /newbot.

  2. Masukkan nama tampilan bot, misalnya Toko Kue Sari. Nama ini muncul di daftar obrolan dan boleh mengandung spasi.

  3. Masukkan username bot sepanjang 5 sampai 32 karakter, hanya berisi huruf Latin, angka, dan garis bawah, serta wajib berakhiran bot, misalnya TokoKueSariBot atau toko_kue_sari_bot.

  4. BotFather membalas dengan token berupa deretan angka dan huruf yang dipisahkan titik dua. Salin dan simpan baik-baik.

Perlakukan token seperti kata sandi, karena siapa pun yang memegangnya bisa mengendalikan bot Anda. Jangan menaruhnya di kode, tangkapan layar, atau grup diskusi. Bila telanjur bocor, buat token baru dengan perintah /token di BotFather. Penjelasan lengkap fitur BotFather tersedia di dokumentasi resmi Telegram.

Menyiapkan Proyek dan Menyimpan Token

Siapkan folder proyek dengan virtual environment seperti dibahas di panduan belajar Python dari nol, lalu pasang pustakanya dengan python -m pip install python-telegram-bot. Per pertengahan September 2026, rilis terbarunya adalah versi 22.8 yang terbit 12 Juni 2026 dan membutuhkan Python 3.10 atau lebih baru.

Token disimpan di variabel lingkungan, bukan di dalam kode. Di PowerShell, jalankan $env:TELEGRAM_BOT_TOKEN = "token-dari-BotFather" dengan token asli Anda. Di Command Prompt, gunakan set TELEGRAM_BOT_TOKEN=token-dari-BotFather, sedangkan di macOS dan Linux export TELEGRAM_BOT_TOKEN="token-dari-BotFather".

Pengaturan itu hanya berlaku di jendela terminal tempat perintahnya dijalankan. Untuk proyek jangka panjang, Anda bisa memakai berkas .env yang dibaca pustaka python-dotenv. Pastikan berkas tersebut tercantum di .gitignore agar tidak ikut terunggah ke repositori.

Menulis Bot Pertama Langkah demi Langkah

Buat berkas bernama bot.py. Sejak versi 20, python-telegram-bot sepenuhnya memakai asyncio, sehingga fungsi penangan pesan ditulis dengan async def dan setiap pemanggilan ke Telegram diawali await. Konsepnya mirip dengan async/await di JavaScript: program tidak membeku saat menunggu jawaban server.

  1. Di bagian atas berkas, tulis tiga baris impor: import os, from telegram import Update, dan from telegram.ext import Application, CommandHandler, ContextTypes, MessageHandler, filters.

  2. Buat fungsi untuk perintah /start yang diawali baris async def start(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:. Isinya cukup satu baris yang menjorok empat spasi: await update.message.reply_text("Halo! Saya bot pertama Anda. Kirim pesan apa saja.").

  3. Buat fungsi kedua dengan pola yang sama, beri nama balas, lalu isi dengan await update.message.reply_text(f"Anda menulis: {update.message.text}") agar bot memantulkan pesan pengguna.

  4. Di luar kedua fungsi, bangun aplikasinya dengan app = Application.builder().token(os.environ["TELEGRAM_BOT_TOKEN"]).build(). Bila variabel lingkungan belum diisi, baris ini langsung berhenti dengan KeyError, sehingga kesalahan cepat ketahuan.

  5. Daftarkan penangan perintah dengan app.add_handler(CommandHandler("start", start)), lalu penangan pesan teks yang bukan perintah dengan app.add_handler(MessageHandler(filters.TEXT & ~filters.COMMAND, balas)).

  6. Tutup berkas dengan app.run_polling(), kemudian jalankan python bot.py dari terminal yang sudah berisi token.

Buka bot Anda di Telegram dan tekan tombol Start. Bot akan menyapa, lalu membalas setiap pesan teks dengan isi yang sama. Untuk menghentikannya, tekan Ctrl+C di terminal.

Polling atau Webhook?

Bot di atas memakai polling: program terus bertanya ke server Telegram apakah ada pesan baru. Cara ini paling mudah karena bisa berjalan di mana saja, termasuk laptop di jaringan rumah, tanpa alamat publik maupun sertifikat HTTPS. Kekurangannya, program harus terus menyala dan aktif bertanya.

Pada webhook, giliran Telegram yang mengirim setiap pesan ke alamat HTTPS milik Anda. Cara ini lebih cocok untuk bot yang berjalan di server, tetapi membutuhkan domain dengan HTTPS, dan Telegram hanya mendukung port 443, 80, 88, atau 8443. Di python-telegram-bot, webhook dijalankan dengan app.run_webhook dan membutuhkan paket tambahan dari python -m pip install "python-telegram-bot[webhooks]".

Kedua cara ini tidak bisa dipakai bersamaan untuk satu bot. Saat bot sedang mati, Telegram menyimpan pembaruan yang masuk paling lama 24 jam, jadi pesan yang tertunda masih bisa diproses ketika bot kembali menyala. Mulailah dengan polling selama belajar, lalu pertimbangkan webhook ketika bot sudah dipakai banyak orang.

Ide Pengembangan Berikutnya

Setelah bot dasar berjalan, ada banyak arah yang bisa dicoba:

  • Daftarkan daftar perintah lewat /setcommands di BotFather agar muncul sebagai saran ketika pengguna mengetik garis miring.

  • Buat perintah berargumen, misalnya /cek 12345 untuk status pesanan. Kata-kata setelah perintah tersedia di context.args sebagai daftar teks.

  • Kirim pengingat atau laporan terjadwal dengan JobQueue, yang membutuhkan paket tambahan python-telegram-bot[job-queue].

  • Hubungkan bot dengan database atau spreadsheet agar bisa menjawab pertanyaan stok dan status pesanan secara otomatis.

Bila bot dimasukkan ke grup, perlu diingat bahwa secara bawaan ia berjalan dalam privacy mode, kecuali dijadikan admin. Dalam mode ini bot tidak membaca seluruh obrolan; yang diterimanya terbatas pada perintah yang ditujukan kepadanya, balasan atas pesannya, dan pesan layanan seperti kabar anggota baru.

Kesimpulan

Membuat bot Telegram dengan Python hanya butuh tiga bahan: token dari BotFather, pustaka python-telegram-bot, dan beberapa fungsi async untuk menangani pesan. Simpan token di variabel lingkungan, mulai dengan polling, dan tambahkan fitur sedikit demi sedikit sesuai kebutuhan nyata pengguna Anda.

Untuk melangkah lebih jauh, dokumentasi python-telegram-bot menyediakan banyak contoh bot siap pakai, mulai dari tombol pilihan sampai percakapan bertahap, yang bisa Anda pelajari dan modifikasi.
