Pemilik toko kue rumahan yang setiap hari menerima pertanyaan tentang jam buka, cara memesan, dan status pesanan lama-kelamaan kewalahan membalasnya. Bot Telegram sebenarnya bisa menjawab pertanyaan berulang seperti itu. Membuat versi sederhananya pun tidak serumit yang Anda bayangkan.

Artikel ini memandu Anda membuat bot pertama dengan Python dan pustaka python-telegram-bot: mendaftarkan bot lewat BotFather, menyimpan token dengan aman, menulis perintah /start dan balasan otomatis, memahami perbedaan polling dan webhook, serta menjajaki ide pengembangan berikutnya.

Mendaftarkan Bot lewat BotFather

Setiap bot Telegram berawal dari BotFather, akun resmi milik Telegram untuk mengelola bot. Prosesnya hanya memakan waktu beberapa menit:

  1. Buka Telegram, cari akun @BotFather, lalu kirim perintah /newbot.

  2. Masukkan nama tampilan bot, misalnya Toko Kue Sari. Nama ini muncul di daftar obrolan dan boleh mengandung spasi.

  3. Masukkan nama pengguna bot sepanjang 5 sampai 32 karakter. Nama pengguna ini hanya boleh berisi huruf Latin, angka, dan garis bawah, serta wajib berakhiran bot, misalnya TokoKueSariBot atau toko_kue_sari_bot.

  4. BotFather membalas dengan token berupa deretan angka dan huruf yang terpisah oleh titik dua. Salin dan simpan token itu baik-baik.

Perlakukan token seperti kata sandi karena siapa pun yang memegangnya bisa mengendalikan bot Anda. Jangan menaruhnya di kode, tangkapan layar, atau grup diskusi. Bila token telanjur bocor, buat token baru dengan perintah /token di BotFather. Penjelasan lengkap fitur BotFather tersedia di dokumentasi resmi Telegram.

Menyiapkan Proyek dan Menyimpan Token

Siapkan folder proyek dengan virtual environment seperti dalam panduan belajar Python dari nol, lalu pasang pustakanya dengan python -m pip install python-telegram-bot. Per pertengahan September 2026, rilis terbarunya adalah versi 22.8 yang terbit pada 12 Juni 2026. Versi ini membutuhkan Python 3.10 atau versi yang lebih baru.

Simpan token di variabel lingkungan, bukan di dalam kode. Di PowerShell, jalankan $env:TELEGRAM_BOT_TOKEN = "token-dari-BotFather" dengan token asli Anda. Di Command Prompt, gunakan set TELEGRAM_BOT_TOKEN=token-dari-BotFather. Di macOS dan Linux, gunakan export TELEGRAM_BOT_TOKEN="token-dari-BotFather".

Pengaturan itu hanya berlaku di jendela terminal tempat Anda menjalankan perintahnya. Pada proyek jangka panjang, Anda bisa memakai berkas .env dan membacanya dengan pustaka python-dotenv. Pastikan berkas tersebut tercantum di .gitignore agar tidak ikut terunggah ke repositori.

Menulis Bot Pertama Langkah demi Langkah

Buat berkas bernama bot.py. Sejak versi 20, python-telegram-bot sepenuhnya memakai asyncio. Oleh karena itu, tulis fungsi penangan pesan dengan async def dan awali setiap pemanggilan ke Telegram dengan await. Konsepnya mirip dengan async/await di JavaScript: program tidak membeku saat menunggu jawaban server.

  1. Di bagian atas berkas, tulis tiga baris impor: import os, from telegram import Update, dan from telegram.ext import Application, CommandHandler, ContextTypes, MessageHandler, filters.

  2. Buat fungsi untuk perintah /start dengan baris pembuka async def start(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:. Isinya cukup satu baris yang menjorok empat spasi: await update.message.reply_text("Halo! Saya bot pertama Anda. Kirim pesan apa saja.").

  3. Buat fungsi kedua dengan pola yang sama, beri nama balas, lalu isi dengan await update.message.reply_text(f"Anda menulis: {update.message.text}") agar bot memantulkan pesan pengguna.

  4. Di luar kedua fungsi, bangun aplikasinya dengan app = Application.builder().token(os.environ["TELEGRAM_BOT_TOKEN"]).build(). Bila Anda belum mengisi variabel lingkungan tersebut, program langsung berhenti di baris ini dengan KeyError. Dengan demikian, Anda cepat menyadari kesalahannya.

  5. Daftarkan penangan perintah dengan app.add_handler(CommandHandler("start", start)), lalu daftarkan penangan pesan teks yang bukan perintah dengan app.add_handler(MessageHandler(filters.TEXT & ~filters.COMMAND, balas)).

  6. Akhiri berkas dengan app.run_polling(), kemudian jalankan python bot.py dari terminal yang sudah berisi token.

Buka bot Anda di Telegram, lalu tekan tombol Start. Bot akan menyapa, lalu membalas setiap pesan teks dengan isi yang sama. Tekan Ctrl+C di terminal untuk menghentikan bot.

Polling atau Webhook?

Bot di atas memakai polling: program terus bertanya ke server Telegram apakah ada pesan baru. Cara ini paling mudah karena bot bisa berjalan di mana saja, termasuk di laptop dalam jaringan rumah, tanpa alamat publik maupun sertifikat HTTPS. Kekurangannya, program harus terus menyala dan aktif bertanya.

Pada webhook, giliran Telegram yang mengirim setiap pesan ke alamat HTTPS milik Anda. Cara ini lebih cocok untuk bot yang berjalan di server, tetapi membutuhkan domain dengan HTTPS. Selain itu, Telegram hanya mendukung port 443, 80, 88, atau 8443. Di python-telegram-bot, webhook berjalan lewat app.run_webhook dan membutuhkan paket tambahan. Pasang paket tersebut dengan python -m pip install "python-telegram-bot[webhooks]".

Satu bot tidak bisa memakai kedua cara ini bersamaan. Saat bot sedang mati, Telegram menyimpan pembaruan yang masuk paling lama 24 jam. Dengan demikian, bot masih bisa memproses pesan yang tertunda ketika kembali menyala. Mulailah dengan polling selama belajar, lalu pertimbangkan webhook ketika bot sudah melayani banyak orang.

Ide Pengembangan Berikutnya

Setelah bot dasar berjalan, Anda bisa mencoba banyak arah pengembangan:

  • Isi daftar perintah bot lewat /setcommands di BotFather agar daftar itu muncul sebagai saran ketika pengguna mengetik garis miring.

  • Buat perintah berargumen, misalnya /cek 12345 untuk memeriksa status pesanan. Kata-kata setelah perintah tersedia di context.args sebagai daftar teks.

  • Kirim pengingat atau laporan terjadwal dengan JobQueue. Fitur ini membutuhkan paket tambahan python-telegram-bot[job-queue].

  • Hubungkan bot dengan basis data atau spreadsheet agar bot bisa menjawab pertanyaan tentang stok dan status pesanan secara otomatis.

Bila Anda memasukkan bot ke grup, ingat bahwa bot secara bawaan berjalan dalam privacy mode, kecuali Anda menjadikannya admin. Dalam mode ini, bot tidak membaca seluruh obrolan. Bot hanya menerima perintah yang tertuju kepadanya, balasan atas pesannya, dan pesan layanan seperti kabar anggota baru.

Kesimpulan

Membuat bot Telegram dengan Python hanya membutuhkan tiga bahan: token dari BotFather, pustaka python-telegram-bot, dan beberapa fungsi async untuk menangani pesan. Simpan token di variabel lingkungan, mulai dengan polling, dan tambahkan fitur sedikit demi sedikit sesuai dengan kebutuhan nyata pengguna Anda.

Bila Anda ingin melangkah lebih jauh, dokumentasi python-telegram-bot menyediakan banyak contoh bot siap pakai, mulai dari tombol pilihan sampai percakapan bertahap. Anda bisa mempelajari dan memodifikasi contoh-contoh tersebut.
