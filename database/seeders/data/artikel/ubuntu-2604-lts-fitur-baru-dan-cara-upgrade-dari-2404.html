Pengguna Ubuntu 24.04 LTS yang rajin membuka Software Updater mungkin sudah melihat tawaran baru: upgrade ke Ubuntu 26.04 LTS. Jalur upgrade dari 24.04 resmi dibuka pada 29 September 2026, menyusul rilis titik pertama, Ubuntu 26.04.1, yang terbit pada 27 Agustus 2026.

Lompatan dari satu LTS ke LTS berikutnya membawa perubahan dua tahun sekaligus, jadi ada baiknya Anda tahu apa yang akan berubah sebelum menekan tombol upgrade. Artikel ini merangkum fitur baru yang paling terasa, perubahan penting bagi developer, dan langkah upgrade yang aman.

Sekilas Ubuntu 26.04 LTS

Ubuntu 26.04 LTS berkode nama Resolute Raccoon dirilis pada 23 April 2026. Edisi Desktop, Server, Cloud, dan Core mendapat pembaruan keamanan dan perbaikan bug kritis selama lima tahun, hingga 2031. Dengan langganan Ubuntu Pro, cakupan Expanded Security Maintenance (ESM) bisa diperpanjang hingga sepuluh tahun. Flavour seperti Kubuntu dan Xubuntu mendapat dukungan tiga tahun.

Kebutuhan perangkat kerasnya ikut naik. Untuk versi desktop, Canonical merekomendasikan prosesor dual-core 2 GHz, RAM minimal 6 GB, dan ruang penyimpanan 25 GB. Laptop lama dengan RAM 4 GB yang selama ini lancar menjalankan 24.04 perlu dipertimbangkan ulang sebelum di-upgrade.

Fitur Baru yang Paling Terasa

Ubuntu 26.04 memakai kernel Linux 7.0, naik dari 6.8 di 24.04, sehingga dukungan untuk perangkat keras baru ikut membaik. Desktopnya memakai GNOME 50, dan sesi desktop kini hanya berjalan di Wayland. Aplikasi lama berbasis X11 tetap bisa dibuka lewat XWayland.

Beberapa aplikasi bawaan juga berganti. Penampil dokumen kini Papers, penampil gambar Loupe, terminal Ptyxis, pemantau sistem Resources, dan pemutar video Showtime. Aplikasi Software & Updates tidak lagi terpasang secara bawaan, tetapi masih bisa dipasang dengan perintah sudo apt install software-properties-gtk. Aplikasi lain ikut diperbarui, misalnya LibreOffice versi 25.8 dan GIMP 3.2.

Dari sisi keamanan, installer kini mendukung enkripsi disk penuh berbasis TPM. Perintah sudo bawaan diganti sudo-rs, versi yang ditulis ulang dengan bahasa Rust, sedangkan banyak utilitas inti seperti ls kini berasal dari rust-coreutils. Utilitas cp, mv, dan rm masih memakai versi GNU.

AppArmor juga membawa banyak profil baru untuk membatasi akses aplikasi, dan OpenSSL kini menyertakan algoritma kriptografi pascakuantum. Di sisi perangkat keras, Canonical menyebut dukungan untuk prosesor Intel Core Ultra Series 3 (Panther Lake) serta perluasan layanan Livepatch ke arsitektur Arm64.

Perubahan Penting bagi Developer

Bagi developer, paket bawaan yang ikut naik versi bisa memengaruhi proyek yang sedang berjalan. Berikut yang paling perlu dicek sebelum upgrade.

  • Python naik dari 3.12 ke 3.14, GCC ke 15.2, dan OpenJDK bawaan ke versi 25.

  • PHP kini versi 8.5, sedangkan Django di repositori naik ke 5.2 LTS.

  • MySQL naik dari 8.0 ke 8.4 LTS. Akun yang masih memakai mysql_native_password akan terkunci secara bawaan, jadi ubah metode autentikasinya atau aktifkan kembali plugin tersebut.

  • PostgreSQL menjadi versi 18, dan APT 3 menghapus perintah apt-key.

Jika Anda sedang menimbang database untuk proyek baru, perbandingan MySQL vs PostgreSQL bisa menjadi bahan pertimbangan. Selain itu, toolkit NVIDIA CUDA kini bisa dipasang langsung dari repositori Ubuntu, kabar baik bagi Anda yang sedang belajar machine learning.

Pengelola server perlu mencermati dua hal lagi. OpenSSH versi 10.2 tidak lagi mendukung kunci DSA, sehingga kunci lama jenis ini harus diganti. Chrony juga menggantikan systemd-timesyncd sebagai layanan sinkronisasi waktu, tetapi hanya pada instalasi baru; sistem hasil upgrade perlu dipindahkan secara manual bila ingin memakainya.

Kapan Upgrade dari 24.04 Dibuka

Seperti biasa, upgrade otomatis antar-LTS baru dibuka setelah rilis titik pertama. Kali ini prosesnya juga menunggu perbaikan regresi pada rust-coreutils. Pengumuman resmi pada 29 September 2026 menyebut tawaran upgrade dibagikan bertahap lewat Update Manager selama beberapa hari, jadi wajar bila komputer Anda belum menerimanya.

Ubuntu hanya mendukung upgrade berurutan. Pengguna 24.04 bisa langsung naik ke 26.04, sedangkan pengguna 22.04 harus naik dulu ke 24.04.

Persiapan Sebelum Upgrade

  • Cadangkan data pribadi ke drive eksternal. Jika Anda menjalankan MySQL lokal, buat dump database seperti di panduan backup database MySQL otomatis.

  • Pastikan ada ruang kosong beberapa gigabita dan sambungkan laptop ke charger selama proses berlangsung.

  • Catat PPA dan repositori pihak ketiga yang Anda pakai, karena semuanya bisa dinonaktifkan selama upgrade.

Langkah Upgrade dari Ubuntu 24.04

Cara termudah adalah lewat aplikasi Software Updater. Buka aplikasinya, pasang semua pembaruan yang tersedia, lalu restart bila diminta. Setelah itu, buka lagi Software Updater. Jika muncul pemberitahuan bahwa Ubuntu 26.04 tersedia, klik Upgrade dan ikuti wizard-nya.

Jika lebih nyaman di terminal, jalankan perintah berikut secara berurutan.

  1. sudo apt update untuk memperbarui daftar paket.

  2. sudo apt upgrade untuk memasang semua pembaruan 24.04.

  3. systemctl reboot untuk menyalakan ulang komputer bila diperlukan.

  4. sudo do-release-upgrade untuk memulai upgrade ke 26.04.

Prosesnya interaktif dan bisa memakan waktu hingga satu jam, tergantung kecepatan internet dan performa komputer. Jika muncul peringatan tentang paket pihak ketiga, baca dengan teliti sebelum melanjutkan. Setelah komputer menyala ulang, jalankan lsb_release -a untuk memastikan versi yang terpasang sudah 26.04, lalu aktifkan kembali PPA yang masih Anda butuhkan.

Perlu Upgrade Sekarang?

Ubuntu 24.04 LTS masih mendapat dukungan standar hingga 2029, jadi tidak ada keharusan upgrade hari ini. Untuk PC pribadi dan laptop developer, 26.04.1 sudah cukup matang, terutama bila Anda butuh kernel baru, GNOME 50, atau versi Python dan PHP terbaru.

Untuk server produksi, uji dulu aplikasi Anda di mesin virtual atau server terpisah, baca catatan di rilis resmi Ubuntu 26.04, dan jadwalkan upgrade di luar jam sibuk.
