Pengguna Ubuntu 24.04 LTS yang rajin membuka Software Updater mungkin sudah melihat tawaran baru: upgrade ke Ubuntu 26.04 LTS. Canonical resmi membuka jalur upgrade dari 24.04 pada 29 September 2026, menyusul rilis titik pertama, Ubuntu 26.04.1, yang terbit pada 27 Agustus 2026.

Lompatan dari satu LTS ke LTS berikutnya membawa perubahan dua tahun sekaligus. Oleh karena itu, ada baiknya Anda mengetahui apa yang akan berubah sebelum menekan tombol Upgrade. Artikel ini merangkum fitur baru yang paling terasa, perubahan penting bagi pengembang, dan langkah upgrade yang aman.

Sekilas Ubuntu 26.04 LTS

Canonical merilis Ubuntu 26.04 LTS berkode nama Resolute Raccoon pada 23 April 2026. Edisi Desktop, Server, Cloud, dan Core mendapat pembaruan keamanan dan perbaikan bug kritis selama lima tahun hingga 2031. Langganan Ubuntu Pro bisa memperpanjang cakupan Expanded Security Maintenance (ESM) hingga sepuluh tahun. Flavour seperti Kubuntu dan Xubuntu mendapat dukungan tiga tahun.

Kebutuhan perangkat kerasnya ikut naik. Canonical merekomendasikan prosesor dual-core 2 GHz, RAM minimal 6 GB, dan ruang penyimpanan 25 GB untuk versi desktop. Pemilik laptop lama dengan RAM 4 GB yang selama ini lancar menjalankan 24.04 perlu berpikir ulang sebelum naik ke 26.04.

Fitur Baru yang Paling Terasa

Ubuntu 26.04 memakai kernel Linux 7.0, naik dari 6.8 di 24.04. Peningkatan ini membuat dukungan untuk perangkat keras baru ikut membaik. Desktop-nya memakai GNOME 50, dan sesi desktop kini hanya berjalan di Wayland. Aplikasi lama berbasis X11 tetap bisa berjalan lewat XWayland.

Beberapa aplikasi bawaan juga berganti. Penampil dokumen kini adalah Papers, penampil gambar Loupe, terminal Ptyxis, pemantau sistem Resources, dan pemutar video Showtime. Aplikasi Software & Updates tidak lagi terpasang secara bawaan, tetapi Anda masih bisa memasangnya dengan perintah sudo apt install software-properties-gtk. Aplikasi lain ikut naik versi, misalnya LibreOffice 25.8 dan GIMP 3.2.

Dari sisi keamanan, penginstal kini mendukung enkripsi disk penuh berbasis TPM. Perintah sudo bawaan berganti menjadi sudo-rs, hasil penulisan ulang sudo dengan bahasa Rust. Banyak utilitas inti seperti ls kini juga berasal dari rust-coreutils. Utilitas cp, mv, dan rm masih memakai versi GNU.

AppArmor juga membawa banyak profil baru untuk membatasi akses aplikasi, dan OpenSSL kini menyertakan algoritma kriptografi pascakuantum. Di sisi perangkat keras, Canonical menyebut dukungan untuk prosesor Intel Core Ultra Series 3 (Panther Lake) serta perluasan layanan Livepatch ke arsitektur Arm64.

Perubahan Penting bagi Pengembang

Paket bawaan yang ikut naik versi bisa memengaruhi proyek pengembangan yang sedang berjalan. Berikut hal yang paling perlu Anda cek sebelum upgrade.

  • Python naik dari 3.12 ke 3.14, GCC ke 15.2, dan OpenJDK bawaan ke versi 25.

  • PHP kini menjadi versi 8.5, sedangkan Django di repositori naik ke 5.2 LTS.

  • MySQL naik dari 8.0 ke 8.4 LTS. Akun yang masih memakai mysql_native_password akan terkunci secara bawaan. Oleh karena itu, ubah metode autentikasinya atau aktifkan kembali plugin tersebut.

  • PostgreSQL menjadi versi 18, dan APT 3 menghapus perintah apt-key.

Jika Anda sedang menimbang basis data untuk proyek baru, perbandingan MySQL vs PostgreSQL bisa menjadi bahan pertimbangan. Selain itu, Anda kini bisa memasang toolkit NVIDIA CUDA langsung dari repositori Ubuntu. Hal ini menjadi kabar baik bagi Anda yang sedang belajar machine learning.

Pengelola server perlu mencermati dua hal lagi. OpenSSH versi 10.2 tidak lagi mendukung kunci DSA sehingga Anda harus mengganti kunci lama jenis ini. Chrony juga menggantikan systemd-timesyncd sebagai layanan sinkronisasi waktu, tetapi hanya pada instalasi baru. Pengguna sistem hasil upgrade yang ingin memakai Chrony perlu beralih secara manual.

Kapan Upgrade dari 24.04 Tersedia

Seperti biasa, Canonical baru membuka upgrade otomatis antar-LTS setelah rilis titik pertama. Kali ini prosesnya juga menunggu perbaikan regresi pada rust-coreutils. Pengumuman resmi pada 29 September 2026 menyebut bahwa Canonical membagikan tawaran upgrade secara bertahap lewat Update Manager selama beberapa hari. Oleh karena itu, wajar bila komputer Anda belum menerimanya.

Ubuntu hanya mendukung upgrade berurutan. Pengguna 24.04 bisa langsung naik ke 26.04, sedangkan pengguna 22.04 harus naik dulu ke 24.04.

Persiapan Sebelum Upgrade

  • Cadangkan data pribadi ke drive eksternal. Jika Anda menjalankan MySQL lokal, buat dump basis data seperti pada panduan pencadangan basis data MySQL otomatis.

  • Pastikan ada ruang kosong beberapa gigabita dan sambungkan laptop ke pengisi daya selama proses berlangsung.

  • Catat PPA dan repositori pihak ketiga yang Anda pakai karena proses upgrade bisa menonaktifkan semuanya.

Langkah Upgrade dari Ubuntu 24.04

Cara termudah adalah lewat aplikasi Software Updater. Buka aplikasinya, pasang semua pembaruan yang tersedia, lalu nyalakan ulang komputer bila sistem memintanya. Setelah itu, buka lagi Software Updater. Jika muncul pemberitahuan bahwa Ubuntu 26.04 tersedia, klik Upgrade dan ikuti wizard-nya.

Jika Anda lebih nyaman memakai terminal, jalankan perintah berikut secara berurutan.

  1. sudo apt update untuk memperbarui daftar paket.

  2. sudo apt upgrade untuk memasang semua pembaruan 24.04.

  3. systemctl reboot untuk menyalakan ulang komputer bila perlu.

  4. sudo do-release-upgrade untuk memulai upgrade ke 26.04.

Prosesnya interaktif dan bisa memakan waktu hingga satu jam, bergantung pada kecepatan internet dan performa komputer. Jika muncul peringatan tentang paket pihak ketiga, bacalah dengan teliti sebelum melanjutkan. Setelah komputer menyala ulang, jalankan lsb_release -a untuk memastikan versi yang terpasang sudah 26.04, lalu aktifkan kembali PPA yang masih Anda butuhkan.

Perlu Upgrade Sekarang?

Ubuntu 24.04 LTS masih mendapat dukungan standar hingga 2029 sehingga Anda tidak harus melakukan upgrade hari ini. Versi 26.04.1 sudah cukup matang untuk PC pribadi dan laptop pengembang, terutama bila Anda membutuhkan kernel baru, GNOME 50, atau versi Python dan PHP terbaru.

Jika Anda mengelola server produksi, uji dulu aplikasi Anda di mesin virtual atau server terpisah, baca catatan rilis resmi Ubuntu 26.04, dan jadwalkan upgrade di luar jam sibuk.
