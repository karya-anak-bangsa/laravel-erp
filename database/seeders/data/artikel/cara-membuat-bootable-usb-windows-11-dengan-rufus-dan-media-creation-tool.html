Ada banyak alasan untuk menyiapkan flashdisk instalasi Windows 11: laptop yang makin lambat dan memerlukan instalasi bersih, SSD baru yang masih kosong, atau PC rakitan yang belum memiliki sistem operasi. Flashdisk seperti ini juga berguna sebagai alat darurat ketika Windows gagal menyala.

Pengguna paling sering memakai dua alat, yaitu Media Creation Tool buatan Microsoft dan Rufus. Artikel ini membahas persiapannya, langkah memakai keduanya, opsi khusus di Rufus, serta beberapa peringatan yang sering luput dari perhatian.

Yang Perlu Anda Siapkan

  • Flashdisk minimal 8 GB sesuai dengan syarat Microsoft. Kapasitas 16 GB lebih lega. Pembuatan media akan menghapus seluruh isi flashdisk. Oleh karena itu, pindahkan dulu berkas penting di dalamnya.

  • PC Windows dengan koneksi internet untuk membuat media. Anda harus menjalankan Media Creation Tool dengan hak administrator, sedangkan Rufus memerlukan Windows 8 atau yang lebih baru.

  • Lisensi Windows 11 atau perangkat Windows 10 yang memenuhi syarat upgrade. PC yang sebelumnya sudah aktif dengan lisensi digital biasanya teraktivasi otomatis setelah instalasi ulang.

  • Cadangan data dari PC tujuan karena instalasi bersih menghapus isi partisi tempat Anda memasang Windows.

Perhatikan bahwa Media Creation Tool hanya membuat media untuk PC berprosesor x64, bukan untuk PC berbasis Arm. Laptop Snapdragon memakai arsitektur Arm, seperti penjelasan dalam artikel Intel, AMD, atau Snapdragon. Microsoft menyediakan ISO Arm64 untuk perangkat seperti ini di halaman terpisah.

Cara Pertama: Media Creation Tool

Media Creation Tool adalah cara paling sederhana karena alat ini mengunduh Windows 11 sekaligus menuliskannya ke flashdisk. Alat ini tersedia di halaman unduhan resmi Windows 11 pada bagian Create Windows 11 Installation Media.

  1. Unduh lalu jalankan Media Creation Tool, kemudian setujui lisensinya dengan memilih Accept.

  2. Jika alat ini menanyakan apa yang ingin Anda lakukan, pilih Create installation media for another PC, lalu klik Next.

  3. Pilih bahasa, edisi, dan arsitektur 64-bit, atau biarkan opsi rekomendasi untuk PC ini.

  4. Pilih USB flash drive, tentukan flashdisk yang akan Anda pakai, lalu klik Next.

  5. Tunggu hingga proses pengunduhan dan penulisan selesai. Lamanya bergantung pada kecepatan internet Anda.

Cara Kedua: Rufus

Rufus adalah aplikasi sumber terbuka berukuran kecil yang bisa langsung berjalan tanpa instalasi. Saat artikel ini terbit, versi terbarunya adalah Rufus 4.15 yang meluncur pada 30 Juni 2026 untuk Windows x64, x86, dan ARM64. Unduh hanya dari situs resmi Rufus atau halaman GitHub proyeknya, bukan dari situs kumpulan perangkat lunak. Situs semacam itu bisa saja menyisipkan penginstal tambahan.

Berbeda dengan Media Creation Tool, Rufus memerlukan berkas ISO. Unduh ISO Windows 11 dari halaman resmi Microsoft yang sama pada bagian Download Windows 11 Disk Image (ISO) for x64 devices. Hindari ISO modifikasi dari sumber tak jelas karena pembuatnya bisa saja menyisipkan malware.

  1. Colokkan flashdisk, buka Rufus, lalu pilih flashdisk tersebut di kolom Device.

  2. Pada Boot selection, klik SELECT dan pilih berkas ISO Windows 11.

  3. Pastikan Partition scheme bernilai GPT dan Target system bernilai UEFI (non CSM) untuk PC modern. Biarkan kolom lain sesuai bawaan.

  4. Klik START, pilih opsi di jendela Windows User Experience yang muncul, lalu klik OK.

  5. Setujui peringatan bahwa Rufus akan menghapus semua data di flashdisk, lalu tunggu hingga status berubah menjadi READY.

Memahami Opsi Windows User Experience

Jendela inilah yang membuat Rufus populer di kalangan teknisi. Opsi-opsinya mengatur instalasi Windows 11 agar lebih ringkas. Semua opsi ini baru muncul setelah Anda menekan tombol START.

  • Remove requirement for 4GB+ RAM, Secure Boot and TPM 2.0 melewati pemeriksaan syarat perangkat keras saat instalasi.

  • Remove requirement for an online Microsoft account dan Create a local account with username memungkinkan Anda memakai akun lokal saat instalasi.

  • Disable data collection (Skip privacy questions) melewati rangkaian pertanyaan privasi saat penyiapan awal.

  • Disable BitLocker automatic device encryption mencegah enkripsi perangkat aktif secara otomatis.

FAQ Rufus menyarankan Anda memutus koneksi internet saat instalasi sampai di halaman pembuatan akun agar Windows tidak memaksa penggunaan akun Microsoft. Sejak versi 4.14, Rufus juga memiliki opsi instalasi senyap yang memasang Windows ke disk pertama tanpa konfirmasi. Jangan mencentangnya kecuali Anda benar-benar memahami risikonya.

Peringatan Sebelum Memakai Opsi Bypass

Melewati syarat TPM dan Secure Boot memang membuat Windows 11 bisa terpasang di PC lama, tetapi ada konsekuensinya. Microsoft menyatakan tidak mendukung PC yang tidak memenuhi syarat minimum dan tidak menjamin PC tersebut menerima pembaruan, termasuk pembaruan keamanan. Microsoft juga menegaskan bahwa garansi pabrikan tidak menanggung kerusakan akibat ketidakcocokan. Selain itu, Windows akan menampilkan tanda air di desktop.

Ada pula batas yang tidak bisa Anda lewati. Sejak versi 24H2, Windows 11 benar-benar mewajibkan prosesor yang mendukung instruksi POPCNT dan SSE4.2. FAQ Rufus menegaskan bahwa tidak ada cara untuk mengakali batasan ini sehingga PC yang sangat tua tetap tidak bisa menjalankan Windows 11 versi terbaru.

Terakhir, berhati-hatilah saat memilih partisi di layar instalasi. Menghapus atau memformat partisi yang salah bisa melenyapkan data yang belum Anda cadangkan.

Booting dari Flashdisk

Jika Windows di PC tujuan masih berjalan, buka Settings > System > Recovery, klik Restart now di bagian Advanced startup, lalu pilih Use a device dan tentukan flashdisk. Di Windows 10, menu tersebut berada di Settings > Update & Security > Recovery.

Jika PC tidak bisa masuk ke Windows, tekan tombol boot menu sesaat setelah Anda menyalakan PC. Tombolnya berbeda pada setiap merek, umumnya F12, F11, F8, atau Esc. Bila flashdisk tidak muncul, periksa pengaturan boot di BIOS/UEFI.

Pilih yang Mana?

Pilih Media Creation Tool jika Anda menginginkan cara paling resmi dan sederhana untuk PC yang memenuhi syarat Windows 11. Pilih Rufus jika Anda membutuhkan fleksibilitas lebih, misalnya ingin memakai akun lokal, melewati pertanyaan privasi, atau menulis ISO Arm64 ke flashdisk.

Apa pun alatnya, simpan flashdisk yang sudah jadi di tempat yang mudah Anda temukan. Saat Windows bermasalah suatu hari nanti, Anda tidak perlu panik mencari PC lain untuk membuatnya.
