Ada banyak alasan untuk menyiapkan flashdisk instalasi Windows 11: laptop yang makin lambat dan ingin diinstal bersih, SSD baru yang masih kosong, atau PC rakitan yang belum punya sistem operasi. Flashdisk seperti ini juga berguna sebagai alat darurat ketika Windows gagal menyala.

Dua alat yang paling sering dipakai adalah Media Creation Tool buatan Microsoft dan Rufus. Artikel ini membahas persiapannya, langkah memakai keduanya, opsi khusus di Rufus, serta beberapa peringatan yang sering diabaikan.

Yang Perlu Disiapkan

  • Flashdisk minimal 8 GB, sesuai syarat Microsoft. Kapasitas 16 GB lebih lega. Seluruh isinya akan dihapus, jadi pindahkan dulu file penting di dalamnya.

  • PC Windows dengan koneksi internet untuk membuat media. Media Creation Tool harus dijalankan dengan hak administrator, sedangkan Rufus memerlukan Windows 8 atau yang lebih baru.

  • Lisensi Windows 11, atau perangkat Windows 10 yang memenuhi syarat upgrade. PC yang sebelumnya sudah aktif dengan lisensi digital biasanya teraktivasi otomatis setelah instal ulang.

  • Cadangan data dari PC tujuan, karena instal bersih menghapus isi partisi tempat Windows dipasang.

Perlu dicatat, Media Creation Tool hanya membuat media untuk PC berprosesor x64 dan tidak bisa dipakai untuk PC berbasis Arm. Laptop Snapdragon memakai arsitektur Arm, seperti dibahas di artikel Intel, AMD, atau Snapdragon. Untuk perangkat seperti ini, Microsoft menyediakan ISO Arm64 di halaman terpisah.

Cara Pertama: Media Creation Tool

Media Creation Tool adalah cara paling sederhana karena alat ini mengunduh Windows 11 sekaligus menuliskannya ke flashdisk. Alat ini tersedia di halaman unduhan Windows 11 resmi, pada bagian Create Windows 11 Installation Media.

  1. Unduh lalu jalankan Media Creation Tool, kemudian setujui lisensinya dengan memilih Accept.

  2. Jika alat menanyakan apa yang ingin Anda lakukan, pilih Create installation media for another PC, lalu Next.

  3. Pilih bahasa, edisi, dan arsitektur 64-bit, atau biarkan opsi yang direkomendasikan untuk PC ini.

  4. Pilih USB flash drive, tentukan flashdisk yang dipakai, lalu klik Next.

  5. Tunggu proses unduh dan penulisan selesai. Lamanya bergantung pada kecepatan internet Anda.

Cara Kedua: Rufus

Rufus adalah aplikasi open source berukuran kecil yang bisa langsung dipakai tanpa instalasi. Versi terbarunya saat artikel ini ditulis adalah Rufus 4.15 yang dirilis 30 Juni 2026, tersedia untuk Windows x64, x86, dan ARM64. Unduh hanya dari situs resmi Rufus atau halaman GitHub proyeknya, bukan dari situs kumpulan software yang bisa saja menyisipkan installer tambahan.

Berbeda dengan Media Creation Tool, Rufus memerlukan file ISO. Unduh ISO Windows 11 dari halaman resmi Microsoft yang sama, pada bagian Download Windows 11 Disk Image (ISO) for x64 devices. Hindari ISO modifikasi dari sumber tak jelas karena bisa saja disisipi malware.

  1. Colokkan flashdisk, buka Rufus, lalu pilih flashdisk tersebut di kolom Device.

  2. Pada Boot selection, klik SELECT dan pilih file ISO Windows 11.

  3. Untuk PC modern, pastikan Partition scheme bernilai GPT dan Target system bernilai UEFI (non CSM). Kolom lain bisa dibiarkan sesuai bawaan.

  4. Klik START, pilih opsi di jendela Windows User Experience yang muncul, lalu klik OK.

  5. Setujui peringatan bahwa semua data di flashdisk akan dihapus, lalu tunggu hingga status berubah menjadi READY.

Memahami Opsi Windows User Experience

Jendela inilah yang membuat Rufus populer di kalangan teknisi. Opsi-opsinya mengatur instalasi Windows 11 agar lebih ringkas, dan baru muncul setelah tombol START ditekan.

  • Remove requirement for 4GB+ RAM, Secure Boot and TPM 2.0 melewati pemeriksaan syarat perangkat keras saat instalasi.

  • Remove requirement for an online Microsoft account dan Create a local account with username memungkinkan instalasi memakai akun lokal.

  • Disable data collection (Skip privacy questions) melewati rangkaian pertanyaan privasi saat penyiapan awal.

  • Disable BitLocker automatic device encryption mencegah enkripsi perangkat aktif secara otomatis.

FAQ Rufus menyarankan agar koneksi internet diputus saat instalasi sampai di halaman pembuatan akun, supaya Windows tidak memaksa penggunaan akun Microsoft. Sejak versi 4.14, Rufus juga punya opsi instalasi senyap yang memasang Windows ke disk pertama tanpa konfirmasi. Jangan mencentangnya kecuali Anda benar-benar paham risikonya.

Peringatan Sebelum Memakai Opsi Bypass

Melewati syarat TPM dan Secure Boot memang membuat Windows 11 bisa terpasang di PC lama, tetapi ada konsekuensinya. Microsoft menyatakan PC yang tidak memenuhi syarat minimum tidak didukung, tidak dijamin menerima update termasuk update keamanan, dan kerusakan akibat ketidakcocokan tidak ditanggung garansi pabrikan. Desktopnya juga akan diberi tanda air.

Ada pula batas yang tidak bisa dilewati. Sejak versi 24H2, Windows 11 benar-benar mewajibkan prosesor yang mendukung instruksi POPCNT dan SSE4.2. FAQ Rufus menegaskan batasan ini tidak bisa diakali, sehingga PC yang sangat tua tetap tidak bisa menjalankan Windows 11 versi terbaru.

Terakhir, berhati-hatilah saat memilih partisi di layar instalasi. Menghapus atau memformat partisi yang salah bisa melenyapkan data yang belum dicadangkan.

Booting dari Flashdisk

Jika Windows di PC tujuan masih berjalan, buka Settings > System > Recovery, klik Restart now di bagian Advanced startup, lalu pilih Use a device dan tentukan flashdisk. Di Windows 10, menunya ada di Settings > Update & Security > Recovery.

Jika PC tidak bisa masuk Windows, tekan tombol boot menu sesaat setelah PC dinyalakan. Tombolnya berbeda di tiap merek, umumnya F12, F11, F8, atau Esc. Bila flashdisk tidak muncul, periksa pengaturan boot di BIOS/UEFI.

Jadi, Pilih yang Mana?

Pilih Media Creation Tool jika Anda ingin cara paling resmi dan sederhana untuk PC yang memenuhi syarat Windows 11. Pilih Rufus jika butuh fleksibilitas lebih, misalnya ingin memakai akun lokal, melewati pertanyaan privasi, atau menulis ISO Arm64 ke flashdisk.

Apa pun alatnya, simpan flashdisk yang sudah jadi di tempat yang mudah ditemukan. Saat Windows bermasalah suatu hari nanti, Anda tidak perlu panik mencari PC lain untuk membuatnya.
